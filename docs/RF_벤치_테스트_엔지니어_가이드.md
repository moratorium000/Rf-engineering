# 1. 문서 개요와 적용 범위

## 1.1 이 문서가 다루는 것

이 문서는 **RF 벤치 테스트 엔지니어(RF Bench Test Engineer)** 가 실험실 벤치에서 수행하는 측정 항목을 항목별로 정리한 실무 참고서다. 각 항목은 다음의 동일한 골격으로 기술한다.

| 절 구성 | 내용 |
|---|---|
| 목적 | 이 측정이 무엇을 보증하는가 |
| 정의 · 이론 | 정의식, 판정 지표, 물리적 배경 |
| 셋업 | 필요한 계측기와 결선, 교정 |
| 절차 | 재현 가능한 단계별 수행 순서 |
| 판정 · 전형값 | 규격 근거와 실무에서 흔히 보는 수치 |
| 실패 시 디버깅 | 결과가 나쁠 때 좁혀 들어가는 순서 |
| 함정 | 오측정을 만드는 전형적 실수 |

## 1.2 범위 경계 — "IC 단은 만지지 않는다"

본 문서의 작업 경계는 다음과 같이 정의한다.

| 구분 | 포함 여부 | 설명 |
|---|---|---|
| IC 내부 회로 설계, 레이아웃, 소자 모델링 | **제외** | 설계 엔지니어 영역 |
| 온-웨이퍼 프로브 측정, ATE 웨이퍼 소트 | **제외** | 반도체 시험 영역 |
| 패키지 부품 · 모듈 단품의 벤치 특성 측정 | **포함** | 커넥터/픽스처 기준면 |
| 평가보드(EVB) 및 양산 PCBA 측정 | **포함** | 핵심 업무 |
| 생산용 트림/캘리브레이션 시퀀스 개발 | **포함** | 4.1절 |
| 시스템/세트 레벨(단말, 기지국, 모듈 탑재 제품) 검증 | **포함** | 4.17~4.20절 |
| 규격 인증 사전시험(Pre-compliance) | **포함** | 4.19절 |
| 공인 인증기관 최종 인증시험 | 부분 | 사전시험 및 대응까지 |

즉, 본 문서의 기준면(reference plane)은 **커넥터, 픽스처, 안테나 포트**이며 트랜지스터 게이트나 IC 패드가 아니다. 다만 **Load Pull(4.11절)** 처럼 IC/트랜지스터의 최적 부하를 찾는 측정도, 패키지 단품을 벤치 픽스처에서 다루는 한 벤치 엔지니어의 업무에 포함되므로 함께 기술한다.

> **약어 해석에 대한 주의** — 의뢰서의 "LP"는 본 문서에서 **Load Pull**로 해석하여 4.11절에 상세 기술한다. 다만 하모닉 측정 시의 **LPF(Low Pass Filter)** 역시 벤치에서 "LP 필터"로 통칭되므로 4.5절에서 별도로 다룬다.

## 1.3 제품 수명주기와 테스트 단계

동일한 "출력 전력 측정"이라도 단계마다 목적과 허용 시간이 다르다. 어떤 단계의 측정인지 먼저 확정해야 셋업과 한계선이 정해진다.

| 단계 | 목적 | 표본 수 | 1 DUT 소요 | 대표 활동 |
|---|---|---|---|---|
| Bring-up | 동작 여부 확인 | 1~2 | 수 시간~수 일 | 전원/클럭 확인, 첫 캐리어 송출, S11 확인 |
| Characterization | 성능 지도 작성 | 3~10 | 수 시간 | 전력/온도/전압/주파수 스윕, Load Pull |
| Design Validation (DVT) | 설계 규격 충족 입증 | 10~30 | 수십 분 | 전 항목 코너 시험, 통계 확보 |
| Pre-compliance | 인증 통과 가능성 확인 | 1~3 | 수 시간 | 하모닉/스퓨리어스/대역외 방사 |
| Production (FT/Cal) | 개체별 트림 + 양품 선별 | 전수 | 수 초~수십 초 | Trim, 축약 측정, 한계선 판정 |
| Sustaining | 수율/필드 이슈 대응 | 가변 | 가변 | 상관성 분석, 골든유닛 재확립 |

## 1.4 측정을 신뢰할 수 있게 만드는 3원칙

1. **모든 측정은 기준면(reference plane)의 선언에서 시작한다.** 어디에서 잰 값인지 정의되지 않은 dBm은 숫자가 아니다.
2. **불확도를 모르는 합격 판정은 판정이 아니다.** 한계선 대비 여유(guardband)는 불확도로부터 계산된다(3.6절).
3. **반복성이 없으면 정확도는 의미가 없다.** 커넥터 체결 토크, 케이블 굽힘, 온도 안정화가 먼저다(2.3절).

# 2. 벤치 인프라 — 측정 이전에 갖춰야 할 것

## 2.1 표준 벤치 계측기 구성

| 계측기 | 역할 | 주요 선정 기준 |
|---|---|---|
| 신호 발생기 (SG / VSG) | 자극 신호 생성, Rx 입력 | 주파수 범위, 출력 레벨 정확도, 위상잡음, 변조 대역폭, ALC |
| 스펙트럼/신호 분석기 (SA / VSA) | 전력·스펙트럼·변조 품질 | DANL, TOI, 위상잡음, 해석 대역폭, 표준 측정 옵션 |
| 벡터 회로망 분석기 (VNA) | S-파라미터, 정합, 군지연 | 다이내믹 레인지, 포트 수, 방향성, 교정 키트 |
| 전력계 + 센서 (Power Meter) | 절대 전력의 기준 | 센서 종류(열전대/다이오드/평균/피크), 비디오 대역폭, Cal Factor |
| 잡음지수 분석기 / 잡음원 | NF 측정 | ENR 확도, 주파수 범위 |
| 위상잡음 분석기 | 위상잡음, 지터, VCO | 교차상관 채널, 오프셋 범위 |
| 오실로스코프 | 전력 램프, 제어 타이밍, 전원 리플 | 대역폭, 샘플레이트, 프로브 |
| DC 전원 / SMU | 바이어스, 소비전류 | 전류 측정 분해능, 리모트 센싱, 트랜지언트 응답 |
| 온도 챔버 / 열풍기 | 온도 코너 | 온도 범위, 안정화 시간, RF 관통구 |
| 차폐 박스 / 무향 챔버 | 격리, OTA | 차폐량, 흡수체, 반복성 |
| 통신 테스터 (Callbox) | 프로토콜 기반 Tx/Rx | 지원 표준/릴리스 |

## 2.2 소모품과 부속

- **감쇠기(Attenuator)**: 계측기 보호와 정합 개선. 3~10 dB 패드를 소스/분석기 입력에 상시 부착하면 정재파에 의한 리플이 줄어 재현성이 향상된다.
- **DC 블록, 바이어스 티**: DC 경로 분리·주입. 삽입손실과 저주파 차단 주파수를 반드시 확인.
- **리미터**: 고출력 DUT를 다룰 때 분석기 입력 앞단의 최후 보호막.
- **필터(LPF/HPF/노치)**: 하모닉/스퓨리어스 측정 시 기본파 억제용(4.5절).
- **디렉셔널 커플러**: 순방향/반사 전력 동시 감시. 결합도와 방향성(directivity)이 측정 오차를 좌우.
- **위상 안정 케이블**: 굽힘에 따른 위상 변동이 작은 시험용 케이블. VNA 교정 후 케이블을 움직이면 교정이 무효화되므로 필수 [26].
- **50 Ω 종단, 표준 부하**: 미사용 포트는 반드시 종단한다.

## 2.3 커넥터 · 케이블 관리 (측정 반복성의 80%)

계측 결과의 산포 대부분은 DUT가 아니라 접속부에서 나온다. 제조사 권고 사항은 다음과 같이 일관된다 [9][22].

| 항목 | 권고 사항 |
|---|---|
| 체결 절차 | 손가락으로 가볍게(약 2 in-lb 이하) 접촉 → 규정 토크 렌치로 마무리. 본체가 아닌 **너트만** 회전 |
| 토크 값 | SMA / 3.5 mm / 2.92 mm 계열은 통상 **8 in-lb(≈0.9 N·m)**, N형은 통상 12 in-lb. 반드시 해당 커넥터 제조사 규격 확인 |
| 토크 렌치 관리 | 연 1회 또는 과사용 시 교정 |
| 게이징(Gauging) | 최초 사용 전, 육안검사 불합격 시, 그리고 **약 100회 체결마다** 핀 깊이 측정 |
| 세정 | 순도 100% 이소프로필 알코올 + 무진 스왑(면봉 금지). 완전 건조 후 청정 건조공기로 이물 제거 |
| 케이블 취급 | 최소 굽힘 반경 준수, 교정 후 경로 고정, 반복 굽힘 지점 관리 |
| 어댑터 | 어댑터 수를 최소화하되, 값비싼 계측기 포트에는 **희생용 어댑터**를 상시 장착 |

> **과토크·부족토크의 결과** — 부족 토크는 간헐 접촉과 S-파라미터 변동을, 과토크는 계면 변형과 반사손실 열화를 일으킨다 [9][22]. 두 경우 모두 "DUT 불량"으로 오판되기 쉽다.

## 2.4 경로 손실 교정 (Path Loss Calibration)

벤치 측정의 기본 작업이며, 사실상 모든 절대 전력 측정의 전제다.

**절차**

1. DUT를 제거하고 **DUT 기준면끼리 직결(through)** 한다. 커넥터 성별이 맞지 않으면 특성이 알려진 어댑터를 사용하고 그 손실을 별도 관리한다.
2. 측정 주파수 목록 전체에 대해 경로 손실 `L(f)` 를 확보한다.
   - 방법 A(권장): VNA 2포트 교정 후 `S21(f)` 측정 → 진폭·주파수 의존성까지 확보
   - 방법 B: SG + Power Meter 조합으로 주파수별 실측
3. `L(f)` 를 자동화 스크립트의 보정 테이블(또는 SA의 amplitude correction, SG의 user flatness)에 적용한다.
4. **검증**: 알려진 기준(예: 교정된 소스 출력, 표준 감쇠기)을 넣어 보정 후 값이 기댓값과 일치하는지 확인한다.

**갱신 주기** — 케이블 교체·이동, 픽스처 교체, 온도 변화, 정기 점검(통상 주 1회 이상 또는 매 시프트) 시 재수행. 경로 손실 이력을 기록하면 케이블 열화를 조기에 발견할 수 있다 [40].

## 2.5 픽스처와 차폐

양산 및 반복 측정에서는 픽스처가 곧 측정 시스템이다.

- **RF 접촉**: 포고핀(스프링 접촉)은 DC 및 저주파 RF(대략 6 GHz 이하)에서 실용적이지만 인덕턴스가 부가되어 밀리미터파에는 부적합하다. 고주파에서는 동축 커넥터 또는 도파관 전이 구조를 사용한다.
- **차폐 박스**: 외부 RF 유입 차단과 DUT 방사 억제. 내부 흡수체를 라이닝하면 공동 공진(cavity resonance)에 의한 측정 리플이 줄어 반복성이 개선된다.
- **접촉 수명**: 커넥터/포고핀은 삽입 횟수 기준(예: 2,000회)으로 교체 주기를 관리한다.
- **누설 검증**: 박스를 닫고 DUT 송신을 켠 상태에서 외부 안테나로 누설을 확인하고, 반대로 외부 강신호에 대한 내부 유입량을 확인한다.

## 2.6 계측기 보호 규칙

| 위험 | 대응 |
|---|---|
| 분석기 입력 과전력 | 최대 입력 사양 확인 → 패드/리미터 상시 부착 → 전력계로 먼저 개략 확인 |
| DC 유입 | DC 블록 사용. 특히 바이어스 티, 액티브 DUT 출력 |
| 정전기(ESD) | 접지 손목띠, 도전성 매트, 커넥터 접촉 전 방전 |
| 핫 스위칭 | 전력이 인가된 상태에서의 스위치 절환·커넥터 탈착 금지 |
| VNA 포트 과입력 | 액티브 DUT 측정 시 출력 경로에 감쇠기 삽입, 포트 파워 하향 |

## 2.7 계측기 교정 관리와 소급성

측정 결과가 조직 밖에서 신뢰받으려면 계측기가 **국가 표준으로 소급(traceable)** 되어야 한다.

| 항목 | 관리 내용 |
|---|---|
| 교정 주기 | 통상 12개월. 사용 강도·환경·이력에 따라 조정. 교정 만료 계측기의 데이터는 판정 근거로 쓸 수 없다 |
| 교정 성적서 | 측정 불확도, 교정 전(as-found)·후(as-left) 값 보관. as-found가 규격을 벗어났다면 **그 기간에 수행한 측정을 소급 검토**해야 한다 |
| 소급성 | 교정기관 → 국가표준기관(KRISS, NIST 등)으로 이어지는 사슬 확인 |
| 부속품 | 감쇠기, 커플러, 교정 키트, 잡음원(ENR), 토크 렌치도 교정 대상 |
| 중간 점검 | 골든 유닛·표준 감쇠기를 이용한 일상/주간 점검으로 교정 주기 사이의 드리프트를 감시 |
| 이력 관리 | 계측기별 교정 일자·만료일·시리얼 관리, 모든 측정 로그에 계측기 시리얼 기록 |

## 2.8 벤치 안전

- **RF 노출**: 고전력(수 W 이상) 측정 시 인체 노출 한계를 확인한다. 안테나가 개방된 상태로 송신하지 말고, 부하 또는 안테나가 연결된 상태에서만 전력을 인가한다.
- **열**: PA·종단 부하·감쇠기는 화상 온도까지 상승한다. 정격 전력을 초과하는 종단 사용 금지, 방열 확보.
- **전기**: 고전압 바이어스 소자(GaN/LDMOS 등)는 전원 인가 순서(게이트 먼저, 드레인 나중)와 차단 순서를 반드시 지킨다.
- **커넥터**: 전력이 인가된 상태에서의 탈착(핫 스위칭) 금지.
- **정전기**: 반도체 DUT 취급 시 접지 손목띠와 도전성 매트 사용.

# 3. 핵심 계측기의 원리와 설정

## 3.1 전력계(Power Meter)와 전력 센서

### 3.1.1 왜 전력계가 "기준"인가

스펙트럼 분석기는 주파수 축 정보를 주지만 절대 진폭 확도는 통상 전력계보다 낮다. 전력계는 광대역 전력을 열 또는 정류 기반으로 직접 검출하므로, 벤치에서 **절대 전력의 1차 기준**으로 사용되며 NIST 소급성 있는 교정 체계를 갖는다 [1][55].

### 3.1.2 센서 종류

| 종류 | 원리 | 강점 | 한계 |
|---|---|---|---|
| 서미스터(볼로미터) | RF 가열에 의한 저항 변화, DC 치환 | 소급성 표준으로 사용 | 좁은 다이내믹 레인지, 느림 |
| 열전대(Thermocouple) | RF 가열 → 열기전력 | 완전한 제곱 법칙, 넓은 레인지, 변조 무관 진짜 평균전력 | 저전력 감도 한계, 느린 응답 |
| 다이오드(정류형) | 다이오드 검파 | 높은 감도(저전력), 빠름 | 제곱법칙 영역 밖에서는 파형 의존 |
| 광대역 다이오드(평균, CW형) | 다이오드 + 보정 | 광 다이내믹 레인지 | 높은 크레스트 팩터 신호에서 오차 |
| 피크(Peak/Average) 센서 | 고속 비디오 검출 | 펄스/버스트 파형 해석, CCDF | 비디오 대역폭 제한 |

열전대 센서는 1970년대 초 도입되어 제곱 법칙 변환과 넓은 다이내믹 레인지로 전력 측정의 확도를 크게 개선했고, 다이오드 센서는 이후 저전력 영역 감도를 확장하는 방향으로 발전했다 [1].

### 3.1.3 평균 전력 vs 피크 전력

- **평균 전력(Average Power)**: 여러 변조 주기에 걸친 시간 평균. 열전대 또는 RMS 검출 다이오드 센서 사용.
- **피크 전력(Peak Power)**: 순시 포락선의 최대치. 상승시간을 재현할 만큼의 **비디오 대역폭(대략 > 1/상승시간)** 을 가진 피크 검출 다이오드 센서 필요 [18].
- 펄스 신호의 관계식:

`P_avg = P_peak × Duty Cycle`, `P_pulse(burst avg) = P_avg / Duty Cycle`

- **크레스트 팩터(Crest Factor)** = 피크/평균 비. OFDM, 다중반송파 신호처럼 크레스트 팩터가 큰 신호를 CW용 센서로 재면 다이오드가 제곱법칙 영역을 벗어나 판독값이 파형에 의존하게 되어 **체계적으로 잘못된 값**이 나온다 [18].
- **CCDF(상보 누적분포함수)**: 신호가 평균 대비 특정 dB 이상일 확률 곡선. PA 입·출력에서 CCDF를 비교하면 압축이 시작되는 지점을 통계적으로 볼 수 있다 [18].

### 3.1.4 실무 절차

1. **예열**: 제조사 권고 시간(통상 30분 이상) 대기.
2. **제로잉(Zeroing)**: RF 입력이 없는 상태에서 영점 조정. 저전력 측정일수록 필수.
3. **교정(Calibration)**: 전력계의 기준 출력(통상 50 MHz, 0 dBm) 또는 내장 기준으로 센서 감도 보정.
4. **Cal Factor 적용**: 센서의 주파수별 교정계수를 측정 주파수에 맞게 적용(자동 인식 센서는 내부 EEPROM 사용).
5. **평균화 설정**: 저전력·잡음 많은 신호에서는 평균 횟수를 늘려 산포를 줄인다(측정 시간과 트레이드오프).
6. **경로 손실 오프셋 입력**: 2.4절의 `L(f)` 를 오프셋으로 등록.
7. **측정**: 안정화 후 판독. 버스트 신호는 게이트/트리거 설정을 사용.

> **함정** — ① 제로잉 없이 −40 dBm대를 측정, ② CW 센서로 OFDM 평균전력 측정, ③ 주파수별 Cal Factor 미적용, ④ 센서 앞단 감쇠기 값을 오프셋에 반영하지 않음. 넷 다 수 dB 오차를 만든다.

## 3.2 벡터 회로망 분석기(VNA)

### 3.2.1 측정하는 것

VNA는 입사파·반사파·전달파의 **크기와 위상**을 측정하여 S-파라미터를 산출한다. 벤치에서 이로부터 얻는 실용 지표는 다음과 같다 [16].

| 지표 | S-파라미터 | 의미 |
|---|---|---|
| 반사손실(Return Loss) | −20log\|S11\| | 정합 품질 |
| VSWR | (1+\|Γ\|)/(1−\|Γ\|) | 정재파비, Γ = S11 |
| 삽입손실(Insertion Loss) | −20log\|S21\| | 통과 손실 |
| 이득(Gain) | 20log\|S21\| | 능동소자 소신호 이득 |
| 격리도(Isolation) | −20log\|S21\| (OFF 상태) | 스위치·듀플렉서 누설 |
| 군지연(Group Delay) | −dφ(S21)/dω | 위상 선형성 |
| 안정성 계수 | K, μ (S-파라미터로 계산) | 증폭기 발진 위험 |

### 3.2.2 오차 모델과 교정

VNA 확도는 **체계적 오차의 수학적 제거(error correction)** 에 의존한다. 2포트 완전 교정은 통상 12항 오차 모델을 사용하며, 방향성(directivity), 소스 정합, 부하 정합, 반사·전달 추적, 크로스토크 항으로 구성된다 [5].

| 교정법 | 표준 | 특징 |
|---|---|---|
| SOLT | Short-Open-Load-Thru | 가장 보편적. 표준 정의(모델)의 품질에 의존하며, 특히 **Load 표준이 취약 고리** |
| SOLR (Unknown Thru) | Short-Open-Load-호혜적 Thru | 성별이 안 맞는 포트, 비정형 Thru에 유용 |
| TRL / LRL | Thru-Reflect-Line | Load 표준 불필요. Line은 중심주파수에서 Thru보다 약 1/4파장 길게. 픽스처·온웨이퍼에서 최고 확도 |
| LRM / LRRM | Line-Reflect-Match(-Reflect) | 광대역, 프로브 스테이션에서 널리 사용 |
| ECal (전자 교정) | 반도체 스위칭 표준 | 빠르고 반복성 우수, 커넥터 체결 횟수 감소 |

**교정 실무 체크리스트**

- 교정 전 **주파수 범위, 포인트 수, IF 대역폭, 포트 파워, 평균 횟수**를 확정한다. 교정 후 이들을 바꾸면 확도가 저하되거나 교정이 무효가 된다.
- 사용할 교정 키트의 **정의(cal kit definition)** 가 계측기에 올바르게 로드되었는지 확인한다.
- 교정 직후 **검증(verification)**: 교정에 쓰지 않은 표준(예: 다른 Load, 알려진 감쇠기, 에어라인)을 측정해 기대치와 비교한다.
- 교정 후 케이블 위치를 고정한다. 케이블 굽힘은 위상을 바꾸어 교정을 무너뜨린다 [26].
- **IF 대역폭**을 줄이면 잡음층이 내려가 다이내믹 레인지가 개선되지만 스윕 시간이 늘어난다. 고격리도(예: 100 dB 이상) 측정에는 좁은 IF BW가 필수다.

### 3.2.3 픽스처 제거 — 포트 확장 vs 디임베딩

- **포트 확장(Port Extension)**: 지연(및 선택적 손실)만큼 기준면을 이동. PCB 선로가 거의 50 Ω일 때 위상 오차를 제거하는 간편한 방법. **정합 오차는 제거하지 못한다** [20].
- **디임베딩(De-embedding)**: 픽스처의 S-파라미터 모델을 측정 결과에서 수학적으로 제거. 동축-마이크로스트립 전이부의 정합 효과까지 제거 가능하므로 정확도가 높다 [20][57].
- **2단 교정(Two-tier)**: 1차로 동축면 교정, 2차로 픽스처면 교정 후 픽스처 파라미터를 디임베딩.
- **자동 픽스처 제거(AFR)** 기능을 제공하는 VNA도 있으며, 대칭 Thru 구조를 이용해 픽스처 절반을 추출한다.

### 3.2.4 액티브 DUT 측정 시 주의

증폭기를 VNA로 측정할 때는 **포트 파워를 낮춰 소신호 조건**을 만들고, 출력 포트에는 감쇠기를 삽입해 수신 포트 과입력을 방지한다. 압축 특성이 필요하면 VNA의 **게인 컴프레션(gain compression) 애플리케이션**을 사용해 파워 스윕과 S21/S11을 동시에 취득하는 것이 SG+SA 방식보다 빠르고 정확하다 [8].

## 3.3 스펙트럼 / 신호 분석기

### 3.3.1 핵심 설정과 상호작용

| 설정 | 영향 |
|---|---|
| RBW (분해능 대역폭) | 주파수 분해능과 잡음층을 동시에 결정. RBW를 10배 좁히면 표시 잡음층은 약 10 dB 내려감. 좁을수록 스윕 시간 증가 |
| VBW (비디오 대역폭) | 포락선 검출 후 평활화. **감도(잡음층 자체)를 개선하지 않으며 주파수 분해능도 바꾸지 않음**. 평활화 정도는 VBW/RBW 비로 결정 [7][10] |
| 검출기(Detector) | Peak(스퓨리어스 탐색), Sample/RMS-Average(잡음·변조 전력), Negative Peak, Quasi-peak(EMC, CISPR 16-1) |
| 트레이스 평균 | 여러 스윕을 점별 평균. 스윕 시간에는 큰 영향 없음 [7] |
| 입력 감쇠기 | 믹서 입력 레벨 결정. 낮추면 감도↑·왜곡↑, 높이면 감도↓·왜곡↓ |
| 프리앰프 | DANL 개선, 대신 최대 입력 저하 |
| 기준 레벨 | 표시 범위 및 내부 이득 배분 결정 |

**DANL(Displayed Average Noise Level)** 은 가장 좁은 RBW에서의 내부 잡음 레벨로 규정되며, 실제 측정 잡음층은 선택한 RBW에 따라 오르내린다 [10].

### 3.3.2 왜곡인지 실제 신호인지 구분하는 법

스펙트럼에 나타난 하모닉·인터모드가 **DUT의 것인지 분석기 내부에서 생긴 것인지** 반드시 구분해야 한다.

> **판별 절차** — 입력 감쇠기를 10 dB 올린다. ① 화면상 성분 레벨(dBm)이 그대로면 → DUT의 실제 신호. ② 성분이 내려가면(2차는 약 10 dB, 3차는 약 20 dB) → 분석기 내부에서 생성된 왜곡. 이 경우 감쇠를 더 올리거나 외부 필터를 쓴다.

분석기의 2차/3차 왜곡 사양(SHI, TOI)은 특정 믹서 입력 레벨(관례적으로 −30 dBm 부근)을 기준으로 규정되므로, 믹서 레벨 = 입력전력 − 입력감쇠 를 항상 계산하며 측정한다.

### 3.3.3 벡터 신호 분석(VSA)

디지털 변조 신호의 EVM, ACLR, 스펙트럼 마스크, 복조 결과를 얻으려면 I/Q 캡처 기반 해석이 필요하다. 표준별 측정 애플리케이션(5G NR, LTE, WLAN, Bluetooth 등)은 규격이 정한 필터, 동기, 등화 방식을 내장하므로, **자체 구현보다 표준 애플리케이션 사용을 우선**한다 [14][15].

## 3.4 신호 발생기

- **레벨 확도**: 절대 레벨이 중요한 시험(특히 Rx 감도)에서는 SG 표시값을 신뢰하지 말고 **전력계로 실측 보정**한다.
- **ALC(Automatic Level Control)**: 버스트/펄스 신호에서 ALC가 오동작할 수 있으므로 필요 시 ALC Off + 파워 서치를 사용한다.
- **위상잡음과 하모닉**: SG 자체의 하모닉이 DUT 하모닉 측정을 오염시킬 수 있다. 필요하면 SG 출력에 LPF를 삽입한다.
- **User Flatness 보정**: 경로 손실 테이블을 SG에 등록하면 DUT 입력면 기준 레벨을 직접 지정할 수 있다.
- **다중 소스 동기**: 10 MHz 기준 클럭을 모든 계측기에 공유(공통 기준)해야 주파수 오차 측정이 의미를 갖는다.

## 3.5 잡음지수 측정 계측 (원리)

### 3.5.1 Y-factor(Hot/Cold) 법

교정된 잡음원을 DUT 입력에 연결하고 ON(hot)/OFF(cold) 두 상태의 출력 잡음전력비 Y를 측정한다 [2][3].

- 잡음원은 잡음 최적화된 애벌런치 다이오드와 정합 개선용 감쇠기로 구성된다. 무바이어스(cold) 상태에서는 상온 종단과 동등한 잡음을, 바이어스 인가(hot) 시에는 큰 잡음을 발생시킨다 [3].
- `Y = N_hot / N_cold`
- `NF = ENR − 10·log10(Y − 1)` (dB)
- 2단 보정(Friis): `F_total = F1 + (F2 − 1)/G1` → 계측기(2단) 기여를 제거해 DUT 단독 NF를 얻는다.

### 3.5.2 Cold Source(Direct Noise) 법

잡음원 대신 **알려진 종단(통상 50 Ω, 상온)** 만을 입력에 두고, DUT의 이득을 별도로(VNA 등) 정확히 알고 있는 상태에서 출력 잡음전력으로 NF를 산출한다 [3]. VNA 기반 시스템에서 S-파라미터와 함께 측정할 수 있어 정합 보정이 용이하다.

### 3.5.3 주요 오차원

- ENR 불확도(잡음원 교정)
- 정합 불확도(잡음원↔DUT, DUT↔계측기) — 가장 지배적인 항목 중 하나
- 계측기 자체 NF와 2단 보정의 정확도
- 잡음원 ON/OFF 시 출력 반사계수 변화
- 주변 간섭 유입, 온도 변화
- 이득 측정 오차(Cold source 법에서 직접 전파됨)

## 3.6 측정 불확도와 가드밴드

### 3.6.1 정합(Mismatch) 불확도

RF 전력 측정에서 정합 오차는 통상 **가장 큰 단일 불확도 기여원**이다. 소스 반사계수 Γs 와 부하 반사계수 Γl 가 있을 때 불확도 한계는 근사적으로

`M_dB ≈ 20·log10(1 ± |Γs||Γl|)`

로 표현된다. 예를 들어 양쪽 VSWR이 각 1.5(|Γ|≈0.2)이면 약 ±0.35 dB의 불확도가 발생한다. 대책은 ① 양단에 감쇠 패드 삽입, ② 잘 정합된 센서/어댑터 사용, ③ 복소 반사계수를 측정해 수치적으로 보정하는 것이다 [1][55].

### 3.6.2 불확도 예산(Uncertainty Budget)

허용 불확도를 기여원별로 배분한 공학적 분석이며, 통상 다음 항목을 포함한다.

| 기여원 | 전형적 성격 |
|---|---|
| 정합(mismatch) | 체계적, 주파수 의존 |
| 센서 Cal Factor / 선형성 | 교정 성적서 기반 |
| 계측기 절대 진폭 확도 | 사양서 기반 |
| 온도 계수 | 환경 의존 |
| 경로 손실 보정 잔차 | 교정 품질 |
| 반복성(접속, 잡음) | 통계적(Type A) |
| 경년 변화(drift/aging) | 교정 주기 의존 |

각 성분을 표준불확도로 환산해 RSS 합성하고 확장계수(k=2, 약 95%)를 적용하는 절차는 GUM(JCGM 100:2008)을 따른다 [61].

### 3.6.3 가드밴드와 판정

측정 불확도 U가 있는 상태에서 규격 한계 L에 대해 무조건 합격 판정을 하면 오합격이 발생한다. 일반적으로 시험 한계선을 `L − U`(합격 보수적) 로 당기는 가드밴드를 적용하며, 양산에서는 수율 손실과 오합격 위험을 균형시켜 결정한다.

### 3.6.4 반복성 · 재현성 (Gauge R&R)

- **반복성(Repeatability)**: 동일 작업자·동일 장비·동일 DUT 반복 측정의 산포.
- **재현성(Reproducibility)**: 작업자·장비·시점이 바뀔 때의 산포.
- **골든 유닛(Golden Unit)**: 규격 내로 검증된 기준 DUT. 여러 대(통상 3대 이상)를 사용해 상관 파라미터의 표준편차가 사전 정의된 범위 내인지 확인하고, 신규 테스터 도입 시 GR&R 분석의 기준으로 사용한다 [31].
- **일상 점검(Daily Check)**: 매 시프트 시작 시 골든 유닛을 측정해 시스템 드리프트를 감시한다.

# 4. 테스트 항목 상세

## 4.1 Trim Test (트림 / 생산 캘리브레이션)

### 4.1.1 목적

동일 설계라도 개체마다 수정(XO) 편차, 부품 공차, PCB 편차, 반도체 공정 산포로 인해 주파수·전력·이득이 달라진다. **Trim test**는 개체별 오차를 측정하고 보정값을 비휘발성 메모리에 기록해, 이후 제품이 스스로 규격 안에서 동작하도록 만드는 공정이다 [34][35][36]. 규격을 "선별"하는 것이 아니라 규격을 "만들어 넣는" 시험이라는 점에서 다른 시험과 성격이 다르다.

### 4.1.2 트림 대상 항목

| 트림 항목 | 무엇을 보정하나 | 측정 수단 | 보정 파라미터 |
|---|---|---|---|
| 주파수 트림 (XO / TCXO) | 수정 초기 공차, 부하용량 편차 | 주파수 카운터, SA, 통신 테스터 | 내부 커패시터 뱅크 코드 (CL 조정) |
| 송신 전력 트림 | PA 이득 산포, 정합 편차, 경로 손실 | 전력계 / SA | 전력 인덱스별 이득 오프셋 |
| 전력 검출기 트림 | 내장 파워 디텍터의 오프셋·기울기 | 전력계 기준 비교 | 디텍터 보정 계수 |
| 수신 이득 / RSSI 트림 | LNA·믹서 이득 산포 | 교정된 SG 입력 | RSSI 오프셋 |
| DC 오프셋 / LO 누설 트림 | I/Q 경로 DC 불균형 | SA에서 캐리어 누설 관측 | I/Q DC 보정 DAC |
| I/Q 진폭·위상 불균형 트림 | 이미지 억압 열화 | SA에서 이미지 톤 관측 | 이득·위상 보정 계수 |
| PA 바이어스 트림 | 정지전류(Idq) 산포 | DC 전류 측정 | 바이어스 DAC 코드 |
| 온도 보상 계수 | 온도에 따른 전력/주파수 이동 | 챔버 다점 측정 | 온도 계수 테이블 |

### 4.1.3 주파수(XO) 트림 — 가장 보편적인 트림

**배경** — 수정의 부하용량 CL이 변하면 병렬 공진 주파수가 이동한다. 이 민감도를 **트림 감도(trim sensitivity, ppm/pF)** 라 하며, 블랭크 크기·전극 형상·주파수·CL에 따라 대략 1~100 ppm/pF 범위를 가진다 [37]. 최신 무선 SoC는 내장 커패시터 뱅크로 이 CL을 디지털 제어한다.

**절차**

1. DUT를 시험 모드로 진입시켜 **무변조 캐리어(CW)** 를 송출하거나, 클럭 출력 핀으로 발진 주파수를 내보낸다.
2. 주파수 오차를 측정한다.
   - 방법 A: SA/주파수 카운터로 CW 캐리어 주파수 측정 → 목표 대비 편차(Hz) → ppm 환산
   - 방법 B: 통신 테스터에서 규격 정의 주파수 오차(예: Bluetooth carrier frequency offset) 측정
3. 트림 코드를 조정(이분 탐색 또는 감도 기반 1~2회 반복)하여 오차를 목표 범위로 수렴시킨다.
4. 최종 코드를 **OTP / eFuse / 플래시**에 기록하고, 리셋 후 재판독하여 적용됨을 확인한다.
5. 검증 측정으로 최종 주파수 오차를 재측정하고 로그에 기록한다. 반도체 제조사들은 이 절차를 자사 SoC 기준으로 문서화하고 있으므로 해당 부품의 캘리브레이션 응용 노트를 함께 참조한다 [34][36].

**요구 확도** — 트림 후 수 ppm 이내(예: ±2~3 ppm)로 수렴시키는 것이 일반적이며, 이를 위해 계측 장비의 주파수 측정 확도는 최소 **±0.5 ppm 수준**이 요구된다 [37]. 계측기 기준 클럭(10 MHz)은 GPSDO 또는 루비듐 기준에 잠금하거나 최소한 최근 교정된 OCXO를 사용해야 한다.

> **함정** — 수정 단자나 부하 커패시터에 오실로스코프 프로브를 직접 대면 프로브 용량이 부하용량에 더해져 발진 주파수를 바꾼다. 직접 프로빙 대신 **클럭 출력 핀 또는 RF 캐리어**로 측정하라 [37].

### 4.1.4 송신 전력 트림

**원리** — 개루프(open-loop) 전력 제어 구조에서는 설정 코드와 실제 출력의 매핑이 개체마다 다르다. 폐루프(closed-loop) 구조라면 내장 검출기 자체를 트림한다 [27].

**절차**

1. 경로 손실 교정(2.4절) 완료 및 검증.
2. DUT를 지정 채널·지정 전력 인덱스로 연속 송신시킨다.
3. **전력계**로 출력 전력을 측정(변조 신호면 평균전력 센서 또는 표준 애플리케이션 사용).
4. 목표 대비 오차 = 측정값 − 목표값 을 계산하고, 이득 오프셋(dB 또는 코드 단위)을 적용한다.
5. 다수 채널(저·중·고)과 다수 전력 레벨에서 반복하여 **보정 테이블**을 구성한다. 채널 간은 보간한다.
6. 보정값 저장 → 리셋 → 전 채널 검증 측정. 이득 오프셋 조정으로 특정 채널의 평균 송신 채널 전력을 올리거나 내리는 방식이 일반적이다 [35].

**전형 목표** — 트림 후 채널·레벨 전반에서 목표 대비 ±0.5~±1.0 dB 이내. 제품 규격에 따라 다르다.

### 4.1.5 I/Q 불균형 · LO 누설 트림

직접변환(Zero-IF) 송신기는 세 가지 결함이 스펙트럼에 직접 드러난다 [→ 4.9절과 연계].

- 베이스밴드에 단일 톤(예: +1 MHz)을 인가하면 출력에는 **① 원하는 신호(LO+1 MHz), ② LO 누설(LO 위치, DC 오프셋 기인), ③ 이미지(LO−1 MHz, I/Q 불균형 기인)** 의 세 성분이 나타난다.
- **DC 오프셋 보정**: I/Q 베이스밴드에 DC 보정값을 더해 LO 위치 성분을 최소화한다.
- **진폭 불균형 보정**: I·Q 경로 이득비를 보정.
- **위상 불균형 보정**: 한쪽 경로에 소량의 위상 오프셋을 추가.
- 판정 지표는 **이미지 억압비(IRR)** `IRR = 10·log10(P_desired / P_image)` [dB] 이다.

**절차** — SA를 이미지/LO 주파수에 마커로 고정하고, 보정 코드를 2차원(진폭·위상) 또는 순차적 1차원 탐색으로 최소점을 찾는다. 최소점 근방은 평탄하므로 탐색 스텝과 SA 평균화 설정이 수렴 품질을 좌우한다.

**한계** — 관측 수신기(또는 SA)의 다이내믹 레인지, 보정 DAC 분해능, 보정의 온도·주파수 안정성이 최종 성능의 상한을 결정한다.

### 4.1.6 트림값 저장과 무결성

| 저장매체 | 특징 |
|---|---|
| OTP / 안티퓨즈 eFuse | 1회 기록. 위변조 곤란, 패키징 전후 여러 단계에서 트림 가능 |
| 플래시 / EEPROM | 재기록 가능, 필드 재보정 가능. 소거 위험 관리 필요 |
| 외부 NVM (모듈 내) | 모듈 단위 보정 테이블 저장 |

**필수 확인** — ① 기록 후 **리셋 → 재판독 → 값 일치** 검증, ② 체크섬/CRC 부여, ③ 트림 이력(장비 ID, 시각, 원시 측정값, 최종 코드)의 데이터베이스 저장. 트림값은 사후 필드 이슈 분석의 가장 중요한 단서다.

### 4.1.7 실패 시 디버깅

| 증상 | 우선 확인 |
|---|---|
| 트림 코드가 한계값(rail)에 붙음 | 부품 오실장, 잘못된 수정 CL, PCB 기생용량, 잘못된 목표값 |
| 트림 후 검증에서 벗어남 | 리셋 후 코드 미적용, 온도 미안정, 측정 순서상 자기가열 |
| 로트 전체가 한쪽으로 치우침 | 경로 손실 교정 오류, 픽스처 변경, 골든 유닛 드리프트 |
| 산포가 갑자기 커짐 | 커넥터/포고핀 마모, 케이블 손상, 차폐 박스 접촉 불량 |

## 4.2 VNA 기반 수동 특성 시험

### 4.2.1 필터 · 듀플렉서 · 다이플렉서

**측정 항목**: 통과대역 삽입손실, 반사손실/VSWR, 대역폭, 저지대역 억압(rejection), 군지연·군지연 리플, 포트 간 격리도.

**절차**

1. 2포트(또는 다포트) 완전 교정. 저지대역 억압이 큰 소자는 **IF 대역폭을 좁히고 평균화**하여 다이내믹 레인지를 확보한다.
2. 미사용 포트는 50 Ω로 종단한다(듀플렉서 3포트 측정 시 필수).
3. S21 크기로 통과손실·억압, S11/S22로 정합, S21 위상으로 군지연을 본다.
4. **군지연 애퍼처(aperture)** 는 통과대역폭의 약 0.5~2%로 설정한다. 너무 좁으면 잡음이 크고, 너무 넓으면 대역 가장자리 구조가 뭉개진다.

### 4.2.2 RF 스위치

| 항목 | 정의 · 측정 |
|---|---|
| 삽입손실 | ON 경로의 S21 |
| 격리도 | OFF 경로의 S21(누설) |
| 반사손실 | 각 상태에서의 S11/S22 |
| 스위칭 시간 | 제어 펄스 50% 지점 기준, RF 포락선이 90%(on) / 10%(off)에 도달하는 시간. 상승/하강 시간은 10–90% 구간으로 별도 정의 [25] |
| 비디오 피드스루 | RF 신호가 없어도 절환 시 출력에 나타나는 전압 트랜지언트 [25] |

**스위칭 시간 측정 셋업**: SG로 CW 인가 → DUT 출력을 검파기 또는 광대역 오실로스코프에 연결 → 제어 신호와 RF 포락선을 2채널로 동시 관측 → 제어 펄스와의 시간차 판독 [25].

### 4.2.3 안테나 정합과 튜닝

**절차** [33]

1. 안테나 급전점(또는 정합 회로 입력)에서 **1포트 교정**을 수행한다. 교정 표준은 안테나가 연결될 바로 그 지점에 체결한다.
2. S11을 스미스 차트와 로그 크기로 동시에 표시한다.
3. 필요 시 안테나 단독 S11과 정합회로 포함 S11을 각각 측정하고, 디임베딩으로 정합회로의 S-파라미터를 분리한다 [33].
4. 스미스 차트에서 직렬/병렬 소자 이동 궤적을 이용해 L-형 정합 소자 값을 결정하고, 실장 후 재측정한다.
5. 세트 조립 상태(케이스, 배터리, 인체 근접 등)에서 재확인한다. 안테나는 주변 환경에 따라 정합이 크게 이동한다.

**판정 기준(일반)** — 소비자 무선기기에서 통상 |S11| ≤ −10 dB(VSWR ≤ 2.0)를 목표로 하며, 광대역·다중대역에서는 −6 dB(VSWR ≈ 3.0)를 실용 한계로 두기도 한다. 요구값은 제품 규격을 따른다.

> **주의** — 케이블이 달린 소형 안테나 측정에서는 케이블 외부 도체를 타고 흐르는 공통모드 전류가 측정을 왜곡한다. 페라이트 클램프 또는 슬리브 발룬으로 억제하고, 케이블 위치를 바꿔 결과가 변하는지 확인하라.

### 4.2.4 케이블 어셈블리 · 커넥터

- 삽입손실, 반사손실, 위상, 시간영역 반사(TDR 변환)로 불연속 위치를 특정.
- 굽힘·온도 변화 전후의 위상 변동(phase stability)을 확인. 시험용 케이블은 이 값이 관리되어야 한다 [26].

## 4.3 출력 전력 측정 (Power Meter 중심)

### 4.3.1 목적과 지표

송신기가 규정 전력을 내는지 확인한다. 지표는 파형에 따라 다르다.

| 신호 유형 | 사용 지표 | 권장 계측 |
|---|---|---|
| CW | 평균 = 피크 | 열전대/다이오드 평균 센서 |
| 펄스/버스트(예: TDMA) | 버스트 내 평균, 듀티 보정 | 피크 센서 + 게이팅, 또는 SA 게이트 측정 |
| 연속 변조(OFDM 등) | 평균 전력 + PAPR/CCDF | RMS 검출 센서, 표준 측정 애플리케이션 |
| 다중 캐리어 | 채널별 채널파워 | SA의 Channel Power 측정 |

### 4.3.2 절차

1. 경로 손실 교정 및 오프셋 등록(2.4절).
2. 전력계 제로잉 및 교정, 주파수별 Cal Factor 설정(3.1.4절).
3. DUT를 목표 채널·전력 설정으로 송신.
4. 안정화 대기(자기가열로 인해 수 초~수십 초 사이 값이 이동할 수 있음). **측정 시점을 규정에 명시**한다.
5. 판독 및 기록. 채널(저·중·고), 전력 레벨, 온도, 전압 코너로 확장.

### 4.3.3 SA로 전력을 잴 때

SA의 **Channel Power** 측정을 사용하고, 적분 대역폭·RBW·검출기(RMS 평균)·평균 횟수를 규격에 맞춰 설정한다. 절대 확도가 필요한 지점에서는 **전력계 값과 상호 검증(cross-check)** 을 습관화한다. 두 값이 1 dB 이상 다르면 경로 손실 보정, 감쇠 설정, 센서 종류를 먼저 의심한다.

### 4.3.4 소비전류와 효율

출력 전력과 항상 함께 측정한다.

- `PAE(%) = 100 × (P_out − P_in) / P_DC`
- `Drain/Collector Efficiency(%) = 100 × P_out / P_DC`
- DC 전원은 **리모트 센싱**으로 케이블 강하를 보상하고, 전류는 고속 트랜지언트까지 필요한 경우 전류 프로브 또는 션트+스코프를 사용한다.

## 4.4 이득 · 이득 평탄도 · P1dB · AM-AM / AM-PM

### 4.4.1 정의

- **소신호 이득**: 압축이 없는 저입력 조건에서의 `S21`.
- **이득 평탄도**: 관심 대역 내 이득 최대–최소 편차(dB p-p).
- **P1dB(1 dB 압축점)**: 이득이 소신호 값 대비 1 dB 감소하는 지점의 **출력** 전력(입력 기준으로 표기할 때는 IP1dB로 구분).
- **AM-AM 왜곡**: 입력 진폭에 따른 이득(진폭) 변화 특성.
- **AM-PM 왜곡**: 입력 진폭에 따른 **위상** 변화 특성. 압축 영역 진입 시 위상 회전이 발생하며, 변조 신호의 EVM·ACLR을 직접 악화시킨다 [8][19].

### 4.4.2 셋업 A — SG + SA/Power Meter (스칼라)

1. 경로 손실 교정: SG→DUT 입력면, DUT 출력면→계측기.
2. 낮은 입력(예상 P1dB보다 충분히 낮은, 통상 −20~−10 dBm 수준)에서 소신호 이득을 확정.
3. 입력을 **1 dB 스텝**으로 상승시키며 출력 전력을 기록. 압축 근방에서는 0.25~0.5 dB 스텝으로 세분화한다.
4. `Gain(P_in) = P_out − P_in` 곡선을 그려 소신호 이득 대비 1 dB 낮아지는 지점을 보간으로 구한다.
5. 매 스텝에서 DC 전류를 함께 기록하면 PAE 곡선을 동시에 얻는다.

### 4.4.3 셋업 B — VNA 게인 컴프레션 (벡터, 권장)

VNA의 파워 스윕 모드에서 S21(크기·위상)과 S11을 동시에 취득한다. 이득이 소신호 대비 1 dB 떨어지는 지점을 계측기가 자동 판정하며, **동시에 S21 위상 변화로부터 AM-PM을 얻는다** [8]. SG+SA 방식보다 빠르고 정합 보정이 되어 정확하다.

### 4.4.4 펄스/변조 조건에서의 압축

CW 압축점과 변조 신호에서의 실제 동작점은 다르다. 피크 전력계 기반 방법은 **변조 포락선의 피크와 평균을 동시에 취득**하여 실제 파형 조건에서의 압축을 평가할 수 있다 [19]. 열 시상수가 긴 소자에서는 CW 측정이 지나치게 비관적일 수 있으므로 펄스 조건 측정을 병행한다.

### 4.4.5 함정

- 소신호 이득을 이미 압축된 레벨에서 정의 → P1dB가 실제보다 높게 나온다.
- 출력 경로 감쇠 부족 → **계측기가 먼저 압축**되어 DUT 압축으로 오판.
- 입력 정합 변화 무시 → 압축 영역에서 S11이 변해 실제 인가 전력이 표시값과 달라진다.
- 자기가열 미고려 → 스윕 방향(상승/하강)에 따라 곡선이 달라지는 히스테리시스 발생.

## 4.5 Harmonics Test (하모닉 측정)

### 4.5.1 목적과 정의

비선형 소자(PA, 믹서, 스위치, 심지어 포화된 로직)는 기본파 f0의 정수배 성분 2f0, 3f0, …을 생성한다. 하모닉은 ① 규제 한계(스퓨리어스 방사)를 위반하고, ② 다른 대역의 수신기를 방해하며, ③ 필터/듀플렉서 설계 부담을 만든다.

표기는 두 가지를 병용한다.
- **절대값**: dBm (규제 한계와 직접 비교)
- **상대값**: dBc = 하모닉 레벨 − 기본파 레벨 (설계 지표)

### 4.5.2 측정 셋업 — 필터 사용이 핵심

가장 흔한 오측정은 **분석기 내부에서 생성된 하모닉을 DUT의 하모닉으로 읽는 것**이다. 이를 막는 표준적 셋업은 다음과 같다.

```
DUT --> [ATT] --> [HPF or NOTCH : fundamental reject] --> SPECTRUM ANALYZER
```
- **ATT** = 감쇠기(계측기 보호 및 정합 개선), **HPF / NOTCH** = 기본파 억제 필터

- **HPF(고역통과) 또는 노치 필터**로 기본파를 수십 dB 억제한 뒤 하모닉만 분석기에 넣으면, 분석기 믹서가 압축·왜곡을 일으키지 않는다.
- 필터의 **통과대역 손실을 하모닉 주파수별로 측정하여 보정**해야 한다(VNA로 필터의 S21을 사전 측정).
- 반대로 **LPF(저역통과, 흔히 "LP 필터")** 는 신호원 쪽에 넣어 **SG 자체 하모닉이 DUT에 입력되는 것**을 막는 데 사용한다. 두 필터의 용도를 혼동하지 않는다.
- 고출력 DUT는 디렉셔널 커플러의 결합 포트를 사용해 측정하고, 커플러의 주파수별 결합도를 보정한다(커플링은 주파수에 따라 변한다).

### 4.5.3 절차

1. 기본파 전력을 먼저 측정·기록(필터 없이, 충분한 감쇠 상태에서).
2. 필터를 삽입하고 필터의 삽입손실 보정 테이블을 적용.
3. 2f0부터 규정된 차수까지 순차 측정. **FCC 관할에서는 통상 최고 기본 주파수의 10차 하모닉까지 또는 40 GHz 중 낮은 쪽까지** 측정 범위를 잡는다(디지털 회로가 포함되면 그 이상이 요구되는 경우도 있다) [32].
4. 각 차수에서 마커 피크 탐색, 필요 시 좁은 RBW로 재확인.
5. 채널(저·중·고), 최대 전력 설정, 온도 코너에서 반복한다. **하모닉은 최대 출력에서 최악**이 되는 것이 일반적이다.

### 4.5.4 분석기 설정

| 설정 | 권장 |
|---|---|
| 입력 감쇠 | 내부 왜곡이 사라질 때까지 올린다(3.3.2절 판별법 적용) |
| RBW | 신호 대역폭보다 넓게 두어 전력을 놓치지 않도록. 잡음층이 문제면 좁히고 채널파워 적분 |
| 검출기 | Peak(탐색) → RMS/Average(정량) |
| 프리앰프 | 하모닉이 잡음층에 가까울 때만 ON. ON 시 최대 입력 재확인 |
| 스팬 | 각 하모닉 주변으로 좁은 스팬 확대 측정 |

### 4.5.5 판정 기준(대표 규제)

| 규제 | 대표 한계 |
|---|---|
| FCC §15.209 (일반 방사 한계) | 960 MHz 초과에서 3 m 거리 500 µV/m → EIRP 환산 약 −41 dBm |
| FCC §15.247(d) (DTS/FHSS 대역외) | 대역 밖 임의 100 kHz 대역에서, 대역 내 최대 100 kHz 대역 전력 대비 **20 dB 이상 낮을 것**. 제한대역(restricted band)에서는 §15.209 한계 적용 |
| ETSI EN 300 328 (2.4 GHz) | 송신기 스퓨리어스 도메인 한계(대표값): 30 MHz~1 GHz ≤ −36 dBm, 1 GHz~12.75 GHz ≤ −30 dBm. **수신 상태의 스퓨리어스 한계는 별도로 더 엄격하게 규정**되므로 송신·수신 상태를 구분해 측정한다. 정확한 값은 적용 판본의 표를 확인 |
| 3GPP (단말/기지국) | 대역별 스퓨리어스 방출 한계 및 대역외 방출 마스크가 규격에 표로 정의됨 |

> **중요** — 위 수치는 규제 문서의 구조를 이해하기 위한 예시이며, 실제 판정은 **적용 판본(edition/version)의 원문 표**를 근거로 해야 한다. 규제 한계는 개정된다 [29][32][46][47].

### 4.5.6 하모닉이 높을 때의 디버깅 순서

1. **측정계 검증**: 감쇠 +10 dB → 값이 따라 내려가면 내부 왜곡. 필터 삽입 여부와 필터 손실 보정 재확인.
2. **소스 오염 확인**: SG 하모닉이 DUT를 통과해 나오는 것은 아닌지 LPF로 확인.
3. **동작점 확인**: PA가 과도 압축인지(입력 백오프), 바이어스가 규정 밖인지.
4. **정합 확인**: 하모닉 주파수에서의 출력 정합. 기본파에서 정합되어도 하모닉에서는 아닐 수 있다.
5. **필터/레이아웃**: 출력 정합회로의 하모닉 억압 성능, 접지 비아, 전원 디커플링, 케이스 누설.
6. **전원 경로**: DC-DC 스위칭 하모닉이나 전원 리플이 변조되어 나타나는지 확인.

## 4.6 스퓨리어스 방출 (Spurious Emission)

### 4.6.1 정의

기본파와 그 변조 대역을 제외한 **모든 불요 방출**. 하모닉, 믹서 상호변조 산물, 클럭 하모닉, LO 누설, 전원 스위칭 산물이 포함된다.

### 4.6.2 전도(Conducted) 측정

안테나 단자가 있으면 전도 측정이 기본이다. ETSI EN 300 328의 대부분 항목도 안테나 단자에서 직접 측정할 수 있다면 전도 측정으로 수행한다 [46].

**절차**

1. DUT 안테나 포트 → 감쇠기 → (필요 시 기본파 억제 필터) → SA.
2. 규정 시작 주파수부터 종료 주파수(예: 30 MHz ~ 10차 하모닉 또는 40 GHz)까지 세그먼트로 나누어 스윕한다.
3. 세그먼트마다 규정 RBW/VBW/검출기를 설정(EMC 계열은 CISPR 16-1의 peak/quasi-peak/average 방식 적용) [6].
4. 발견된 피크를 좁은 스팬으로 재측정하여 정량화하고, 케이블·필터 손실을 보정한다.
5. **비송신(대기) 상태**의 방출도 별도로 측정한다(수신 모드 LO 누설 등).

> **핵심 요구 조건** — 스퓨리어스 측정은 스펙트럼 분석기의 **다이내믹 레인지가 규제 한계보다 충분히 넓어야** 성립한다. 잡음층이 한계선보다 최소 6~10 dB 아래에 있어야 판정 가능한 측정이다.

### 4.6.3 방사(Radiated) 측정

- 반무향실(SAC) 또는 무향실, 규정 거리(3 m / 10 m), 교정된 수신 안테나·프리앰프·저손실 케이블 사용.
- 안테나 팩터, 케이블 손실, 프리앰프 이득을 합산하여 전계강도로 환산.
- DUT를 3축 회전, 수평/수직 편파, 안테나 높이 스캔으로 최대치를 탐색.
- 사내 사전시험은 정확도보다 **재현성과 상대 비교**에 목적을 두고, 최종 판정은 공인 시험소 결과를 기준으로 한다.

### 4.6.4 스펙트럼 방출 마스크(SEM)

규격이 정의한 주파수 오프셋별 전력 한계 템플릿에 측정 스펙트럼을 겹쳐 판정한다. 최신 신호·스펙트럼 분석기는 ACLR/SEM/EVM을 하나의 I/Q 캡처에서 병렬 산출하는 측정 옵션을 제공하여 시험 시간을 크게 줄인다 [14].

## 4.7 상호변조 왜곡 (IMD) 과 IP3 / IP2

### 4.7.1 정의

두 개의 근접 톤 f1, f2를 동시에 인가하면 비선형성에 의해 다음이 생성된다.

- **3차 IM(IM3)**: `2f1 − f2`, `2f2 − f1` — 신호 대역 안 또는 바로 옆에 떨어져 필터로 제거하기 어렵다.
- **2차 IM(IM2)**: `f1 ± f2` — 광대역·직접변환 수신기에서 중요.
- **차단점(Intercept Point)**: 기본파와 IM 성분의 외삽 직선이 만나는 가상의 전력. 입력 기준 IIP3, 출력 기준 OIP3.

`IIP3 [dBm] = P_in [dBm] + ΔP [dB] / 2`  (ΔP = 기본파 − IM3, 각 톤 기준)
`OIP3 [dBm] = P_out [dBm] + ΔP [dB] / 2`

### 4.7.2 셋업

```
  SG1 --[BPF]--[PAD/ISOLATOR]--+
                               +--[COMBINER]--> DUT --[ATT]--> SA
  SG2 --[BPF]--[PAD/ISOLATOR]--+
```
- **BPF** = 신호원의 하모닉·잡음 제거, **PAD / ISOLATOR** = 신호원 상호 주입 차단, **ATT** = 분석기 보호

**Mini-Circuits AN00-008이 지적하는 2대 오류** [24]

1. **두 신호원 간 격리 부족**: 한쪽 SG 출력이 다른 SG의 출력단으로 역주입되어 SG 내부에서 IM이 생성된다. → 각 SG 뒤에 **아이솔레이터 또는 6~10 dB 패드**를 넣고, 결합기의 격리도를 확인한다.
2. **입력 신호의 필터링 부족**: SG의 하모닉·잡음이 그대로 들어가면 결과가 오염된다. → 각 경로에 대역통과/저역통과 필터.

격리가 부족하면 **최대 20 dB에 이르는 오차**가 발생할 수 있다 [24].

### 4.7.3 절차

1. 두 톤의 전력을 각각 정확히 설정한다. **한쪽 SG를 끄는 것이 아니라 50 Ω로 대체**한 상태에서 다른 쪽을 조정해야 결합기 정합 조건이 유지된다 [24].
2. 톤 간격은 DUT 대역폭과 응용에 맞춘다(예: 1 MHz, 5 MHz, 20 MHz).
3. SA에서 기본파와 IM3 각각에 마커를 놓고 ΔP를 읽는다.
4. **측정계 검증**: DUT를 제거하고 동일 셋업에서 IM3를 측정한다. 시스템 자체 IM3가 DUT 값보다 최소 10 dB 이상 낮아야 신뢰할 수 있다.
5. 입력 전력을 바꾸며 IM3가 **입력 1 dB당 3 dB 기울기**로 움직이는지 확인한다. 기울기가 3이 아니면 측정계 왜곡이거나 이미 압축 영역이다.

### 4.7.4 관련 시험

- **수신기 상호변조 저지(Intermodulation Rejection)**: 원하는 신호 + 두 개의 방해파를 인가해 IM 산물이 수신 대역에 떨어지도록 만들고, 감도 열화량을 측정(4.10.6절).
- **ADC/믹서의 IMD**: 시스템 수준에서는 각 단의 IP3를 캐스케이드 계산하여 병목을 찾는다 [30].

## 4.8 ACLR / ACPR (인접 채널 누설비)

### 4.8.1 정의

변조 신호의 **대역외 확산(spectral regrowth)** 을 정량화한다. 주 채널 전력 대비 인접 채널 대역 내 전력의 비(dBc). 이동통신 규격에서는 오프셋과 적분 대역폭이 규격에 명시된다.

### 4.8.2 절차

1. SA/VSA에서 해당 표준의 ACLR 측정 애플리케이션을 선택하거나, 규격이 정한 **중심 오프셋·적분 대역폭·측정 필터(예: RRC)** 를 수동 설정한다.
2. 검출기는 RMS 평균, 평균 횟수는 규격/반복성 요구에 맞춘다.
3. DUT를 규정 파형(예: 규격 정의 테스트 모델/신호)으로 최대 전력 송신.
4. 상·하 인접 채널(±1, ±2 …)의 ACLR을 판독.
5. 채널·전력·온도 코너에서 반복.

### 4.8.3 확도 확보

- **분석기 자체의 ACLR 성능(잡음 및 왜곡)** 이 DUT보다 충분히 좋아야 한다. 분석기 입력 감쇠를 바꾸며 ACLR 값이 변하지 않는지 확인한다(변하면 분석기 왜곡이 섞인 것).
- **잡음 보정(noise correction)** 기능을 사용하면 분석기 잡음 기여를 보정할 수 있다.
- 최신 계측기는 I/Q 기반 멀티스레드 연산으로 ACLR/SEM/EVM을 동시 산출하여 측정 시간을 단축한다 [14].

### 4.8.4 나쁠 때의 원인

PA 압축(AM-AM/AM-PM), 바이어스 부족, 전원 임피던스(메모리 효과), DPD 미적용/오설정, 과도한 입력 전력, 정합 불량, 열.

## 4.9 EVM (변조 정확도)

### 4.9.1 정의

**EVM**은 이상적 성상점(reference)과 실측 성상점 사이 오차 벡터 크기의 RMS를, 통상 기준 신호 전력으로 정규화한 값(% 또는 dB)이다 [13][28].

`EVM_rms(%) = 100 × sqrt( Σ|S_meas − S_ref|² / Σ|S_ref|² )`

측정은 표준이 정의한 **동기, 등화(equalization), 기준 필터** 절차를 따라야 하며, 이 조건이 다르면 같은 DUT에서도 값이 달라진다. 채널 추정 등화는 평탄한 채널 응답을 가정하고 진폭·위상 응답을 제거한다.

### 4.9.2 EVM을 악화시키는 요인

| 요인 | 성상도상의 증상 |
|---|---|
| 열잡음 / 낮은 SNR | 성상점 주위 등방성 확산 |
| 위상잡음 | 성상점의 원주 방향 번짐(회전) |
| I/Q 진폭·위상 불균형 | 이미지 성분, 성상도 타원 왜곡 |
| LO 누설 / DC 오프셋 | 성상도 전체가 원점에서 이동 |
| PA 압축(AM-AM/AM-PM) | 외곽 성상점이 안쪽으로 말리고 회전 |
| 주파수 오차 | 시간에 따른 성상도 회전 |
| 타이밍/샘플링 오차 | 심볼 간섭, 외곽점 확산 |

이 표는 EVM 디버깅의 출발점이다. 성상도 형태만으로도 원인 계열을 좁힐 수 있다.

### 4.9.3 절차

1. 표준 측정 애플리케이션에서 프로파일(대역폭, 변조, 프레임 구조, 트리거)을 설정.
2. 입력 레벨을 분석기 최적 범위에 맞춘다. **너무 높으면 분석기 압축, 너무 낮으면 잡음**으로 EVM이 나빠진다. 입력 감쇠를 ±5 dB 바꿔가며 EVM 최소점을 찾는 "레벨 스윕"을 습관화한다.
3. 캡처 → 복조 → EVM(rms / peak), 주파수 오차, I/Q 오프셋, 이득 불균형, 구적 오차를 함께 기록. 이 부가 지표들이 원인 규명의 열쇠다.
4. 필요 시 **스펙트럼 평탄도(spectral flatness)** 도 함께 확인. 예를 들어 802.11a에서는 부반송파 −16~+16에 대해 ±2 dB, 전 부반송파에 대해 +2/−4 dB 이내가 요구된다 [48].

## 4.10 Rx Test (수신기 시험)

수신 시험은 "얼마나 약한 신호를 받을 수 있는가(감도)"와 "방해가 있을 때도 받을 수 있는가(선택도·차단)"의 두 축으로 구성된다.

### 4.10.1 기본 셋업

```
  VSG (wanted signal) --[ATT]--+
                               +--[COMBINER]--[ATT]--> DUT ANTENNA PORT
  SG  (interferer)    --[BPF]--+

  DUT <--- UART / USB ---> PC   (PER / BER counter, test-mode control)
```
- 방해파 경로의 **BPF**는 방해파 신호원의 광대역 잡음이 수신 대역에 떨어지는 것을 막는다(4.10.4절 함정 참조).
- 전체 경로는 **차폐 박스** 안에 두고, DUT 입력면 기준의 경로 손실을 사전 교정한다.

- **경로 손실 보정이 감도 측정의 정확도를 그대로 결정한다.** 감도 −100 dBm대를 재면서 경로 손실을 0.5 dB 틀리면 결과가 0.5 dB 틀린다.
- SG의 낮은 출력 영역 확도가 부족하므로, **고정 감쇠기를 넣어 SG를 상대적으로 높은 출력에서 동작**시키는 것이 정확하다.
- 차폐 박스 필수. 외부 Wi-Fi/셀룰러 신호가 −100 dBm 측정을 오염시킨다.

### 4.10.2 감도(Sensitivity)

**정의** — 규정된 품질 기준을 만족하는 최소 수신 입력 전력. 품질 기준은 표준마다 다르다.

| 표준 계열 | 품질 기준 |
|---|---|
| GSM / W-CDMA 계열 | BER (예: 0.1%) [49] |
| LTE / 5G NR | 규정 기준 측정 채널에서 **최대 처리율의 95%** 이상 (REFSENS) [49] |
| Bluetooth | BER 또는 PER (릴리스별 RF-PHY.TS 정의) [39][58] |
| 독자 프로토콜 / IoT | PER (예: 1% 또는 10%) |

**절차**

1. 경로 손실 교정 및 검증.
2. DUT를 수신 시험 모드로 진입(연속 수신, 패킷 카운터 리셋 가능해야 함).
3. VSG에서 규정 파형을 충분히 큰 레벨로 송신 → 정상 수신 확인(연결성 sanity check).
4. 레벨을 내리며 이분 탐색 또는 고정 스텝(1 dB, 최종 0.2~0.5 dB)으로 품질 기준 경계를 찾는다.
5. 각 레벨에서 **통계적으로 충분한 패킷 수**를 보낸다. 예: PER 1% 판정에 최소 수천 패킷(경험칙: 목표 오류율의 역수 × 10~100배 패킷).
6. 채널(저·중·고), 온도·전압 코너에서 반복.

**감도의 이론 하한**

`P_sens(dBm) = −174 + 10·log10(BW_Hz) + NF(dB) + SNR_req(dB)`

측정값이 이 계산 대비 크게 나쁘면 NF, 정합, 자기간섭(4.17절)을 순서대로 의심한다.

### 4.10.3 잡음지수(NF)

원리는 3.5절 참조. 벤치 실무 포인트는 다음과 같다.

1. 측정 전 **계측기 단독 교정(cal)** 을 반드시 수행하여 2단 잡음 기여를 제거한다.
2. 잡음원과 DUT 사이 어댑터·케이블 손실은 **입력측 손실로 NF에 1:1로 더해진다.** 손실 보정을 정확히 입력한다.
3. 이득이 낮은 DUT(예: 필터+믹서)는 2단 보정 오차가 커진다. 필요하면 저잡음 프리앰프를 계측기 앞에 두고 그 특성을 보정한다.
4. 정합 불확도가 지배적이므로, 가능하면 **아이솔레이터/패드**로 정합을 안정화한다 [4].
5. 주변 간섭 유입 여부를 스펙트럼으로 먼저 확인한다(잡음 측정은 협대역 간섭에 매우 취약).

### 4.10.4 인접채널 선택도(ACS) / 차단(Blocking)

- **ACS**: 원하는 신호가 규정 레벨(통상 감도 + 3 dB 등)로 있고, 인접 채널에 방해파가 있을 때 성능을 유지하는 능력. 규격상 "할당 채널에서의 수신 필터 감쇠 대 인접 채널에서의 수신 필터 감쇠의 비"로 정의된다 [49].
- **Blocking**: 인접·비인접 주파수의 강한 방해파가 있어도 규정 성능(예: BER ≤ 0.1%)을 유지하는 능력 [49].
- **셋업**: 두 대의 신호원을 **전력 결합기(combiner)** 로 합쳐 DUT에 인가한다 [49]. 각 경로에 아이솔레이션 패드를 넣어 상호 주입을 막는다.
- **절차**: 원하는 신호를 규정 레벨에 고정 → 방해파를 규정 오프셋에 두고 레벨을 올리며 품질 기준이 깨지는 지점을 찾는다(또는 규정 레벨에서 합/불 판정).
- **함정**: 방해파 신호원의 **광대역 잡음(broadband noise floor)** 이 원하는 채널에 떨어져 DUT가 아니라 SG 때문에 실패하는 경우가 매우 흔하다. 방해파 경로에 대역통과 필터를 넣어 확인하라.

### 4.10.5 이미지 억압 (Image Rejection)

슈퍼헤테로다인 수신기에서 이미지 주파수(`f_image = f_LO ± IF` 중 원하지 않는 쪽)의 신호가 얼마나 억제되는지 측정한다. 원하는 주파수와 이미지 주파수에서 각각 동일 품질을 얻는 입력 레벨 차이(dB)로 정의한다.

### 4.10.6 상호변조 저지 (Intermodulation Rejection)

두 방해파를 `f1 = f0 + Δ`, `f2 = f0 + 2Δ` 에 배치하면 IM3가 정확히 수신 채널 f0에 떨어진다. 이 상태에서 감도 열화를 측정한다. 셋업 주의사항은 4.7.2절과 동일하며, **신호원 간 격리와 방해파 잡음층 관리**가 결과를 좌우한다.

### 4.10.7 최대 입력 레벨 (Maximum Input Level)

강한 신호에서도 규정 성능을 유지하는지 확인한다. AGC 동작, 수신단 압축, ADC 클리핑을 검증하는 시험이다. 레벨을 규정 최대치까지 올리며 BER/PER과 EVM(복조 품질)을 함께 본다.

### 4.10.8 RSSI 확도

DUT가 보고하는 수신 강도 지표를 교정된 입력 레벨과 비교한다.

1. 입력 레벨을 −100 dBm ~ −20 dBm 등 넓은 범위에서 5 dB 스텝으로 스윕.
2. 각 레벨에서 DUT 보고값을 다수 회 취득해 평균·표준편차를 기록.
3. 선형성(기울기)과 절대 오프셋을 분리해 평가하고, 필요하면 4.1절의 RSSI 트림으로 보정.
4. 채널·온도 의존성을 확인한다. RSSI는 온도에 따라 쉽게 수 dB 이동한다.

### 4.10.9 Rx 시험 실패 시 디버깅 순서

1. **경로 손실 보정 재검증** (가장 흔한 원인). 기준 DUT 또는 교정된 수신기로 실제 인가 레벨을 확인.
2. **차폐 확인**: 박스를 닫고 SG를 끈 상태에서 DUT가 패킷을 수신하는지 확인(누설 검사).
3. **SG 잡음층 확인**: SG 출력을 SA로 보고 수신 대역의 광대역 잡음 확인.
4. **DUT 정합**: 안테나 포트 S11.
5. **NF 측정**으로 수신 전단 자체를 분리 평가.
6. **자기간섭 탐색**: DUT의 다른 서브시스템을 하나씩 끄며 감도 변화 관찰(4.17절).
7. **주파수 오차**: 송·수신 주파수 오차가 크면 감도가 열화된다. 4.1.3절 트림 상태 확인.

## 4.11 Load Pull (LP)

### 4.11.1 목적

S-파라미터는 **소신호** 특성이다. 전력 증폭기는 대신호·비선형 영역에서 동작하므로, 최대 출력이나 최대 효율을 주는 부하 임피던스는 소신호 켤레정합(conjugate match)과 다르다. Load Pull은 DUT가 보는 **부하 임피던스를 의도적으로 변화("pull")시키며** 성능을 측정하여, 최적 정합 회로 설계의 근거를 제공한다 [17][50][51][52].

### 4.11.2 구성

```
  SG --> [SOURCE TUNER] --> [COUPLER] --> DUT --> [COUPLER] --> [LOAD TUNER] --> [LOAD / PWR METER]
              ^                 |                     |               ^
          source pull       a/b waves             a/b waves       load pull
                             (VNA RX)              (VNA RX)

  DC SUPPLY (V, I monitor) --------> P_DC   =>   PAE
```
- **SOURCE TUNER / LOAD TUNER**: DUT가 보는 소스·부하 반사계수를 스미스 차트 상에서 이동시킨다.
- **COUPLER + VNA RX**: DUT 기준면의 입사파(a)·반사파(b)를 벡터로 측정한다.
- **DC SUPPLY**: 전류를 함께 측정해야 PAE 등고선을 그릴 수 있다.

| 구성요소 | 역할 |
|---|---|
| 임피던스 튜너 | 슬라이드-스크류(기계식) 수동 튜너가 표준. 자동 슬라이드-스크류 튜너 기반 자동 Load Pull은 1987년 Maury Microwave가 상용화 [50] |
| 능동/하이브리드 튜너 | 반사파를 능동적으로 주입해 \|Γ\| = 1 근방까지 도달. 손실이 큰 온웨이퍼·고전력에 유리 [56] |
| VNA / 벡터 수신기 | DUT 기준면에서 a-파·b-파를 측정. 스칼라 전력계 대신 벡터 수신기를 쓰면 튜너 디임베딩 없이 기준면 전력을 직접 얻는다 [50] |
| 커플러 | 입사/반사파 추출 |
| DC 전원 + 전류계 | PAE 계산 |

### 4.11.3 튜너 교정과 기준면

- 튜너는 **모터 위치 ↔ 반사계수(Γ)** 의 대응표를 사전에 VNA로 측정해 둔다(튜너 교정).
- 튜너와 DUT 사이의 어댑터·픽스처 손실은 **디임베딩**하여 Γ를 DUT 기준면으로 환산한다. 이 손실이 크면 DUT가 실제로 볼 수 있는 |Γ| 범위가 줄어든다(고전력·온웨이퍼에서 능동 튜너를 쓰는 이유).
- 벡터 수신기 방식은 DUT 기준면에서 직접 교정하므로 안정성과 확도가 높다 [50].

### 4.11.4 절차

1. DUT를 안전한 바이어스·입력 전력에서 켜고 안정성을 확인한다(발진 여부를 스펙트럼으로 확인).
2. 소스 튜너를 고정(또는 소스 풀로 입력 정합 최적화)하고, 부하 튜너로 스미스 차트상의 격자점을 스윕한다.
3. 각 격자점에서 P_in, P_out, I_DC 를 측정하여 **Gain, P_out, PAE, DE** 를 계산한다.
4. 결과를 스미스 차트 위에 **등고선(contour)** 으로 그린다. 통상 P_out 등고선과 PAE 등고선은 **중심이 서로 다르며**, 설계자는 그 절충점을 선택한다 [51].
5. 필요하면 **하모닉 Load Pull**: 2f0, 3f0의 부하 임피던스도 함께 제어하여 효율을 추가로 끌어올린다(클래스-F 등) [50].
6. **Source Pull**: 소스 임피던스를 스윕하여 이득·잡음 최적점을 찾는다. 잡음 파라미터(F_min, Γ_opt, R_n) 추출도 소스 풀 기반이다 [52].

### 4.11.5 주의점

- **안정성**: 튜너가 만드는 큰 |Γ|는 DUT를 불안정 영역으로 밀어 넣어 발진을 유발할 수 있다. 매 격자점에서 스펙트럼을 감시하거나 발진 검출 로직을 넣는다.
- **열**: 고전력 스윕은 자기가열로 결과를 이동시킨다. 펄스 구동 또는 격자점별 안정화 시간을 규정한다.
- **압축 조건 통일**: "고정 입력전력"과 "고정 압축(예: 3 dB 압축)" 조건의 등고선은 전혀 다르다. 조건을 명시하지 않은 Load Pull 데이터는 비교 불가능하다.
- **반복성**: 튜너 위치 재현성, 커넥터 체결, 케이블 위치가 모두 |Γ| 확도에 들어간다.

## 4.12 위상잡음 · 주파수 안정도

### 4.12.1 정의

`L(f)` [dBc/Hz] — 캐리어에서 오프셋 f 만큼 떨어진 곳의, 1 Hz 대역 내 단측파대 잡음 전력을 캐리어 전력 대비로 표현한 값.

### 4.12.2 측정 방법

| 방법 | 원리 | 특징 |
|---|---|---|
| 직접 스펙트럼법 | SA로 캐리어 전력 측정 후, 오프셋에서 1 Hz 대역 잡음 전력 측정 → 차이 [11] | 가장 간단. **분석기 자체 위상잡음이 DUT보다 좋아야** 유효 |
| PLL / 위상검출기법 | 기준원과 DUT를 직각 위상으로 잠금하고 위상 오차를 검출 | 감도 우수, 기준원 품질에 의존 |
| 교차상관법 | 두 개의 독립 기준 경로로 동시 측정 후 상관 → 비상관 잡음(계측기 자체) 제거 | 감도가 **약 5·log10(N) dB** 개선(N=상관 횟수). 측정 시간 증가 [12] |
| 지연선 판별법 | 지연선 + 믹서로 주파수 판별 | 기준원 불필요, 감도는 지연 길이에 의존 |

### 4.12.3 절차와 함정

1. DUT 출력 레벨을 계측기 권장 범위로 맞춘다(과입력은 계측기 위상잡음 열화·손상).
2. 캐리어 주파수와 오프셋 범위(예: 100 Hz ~ 10 MHz)를 설정.
3. 스퍼(spur)와 잡음층을 구분해 기록한다. 전원 리플(50/60 Hz 및 그 하모닉), DC-DC 스위칭 주파수의 스퍼는 흔한 발견이다.
4. **전원과 진동**: 위상잡음 측정은 전원 잡음과 기계적 진동에 매우 민감하다. 리니어 전원, 방진, 케이블 고정이 필요하다.
5. **레퍼런스 확인**: 계측기 자체 잡음층(instrument noise floor)을 먼저 측정해 DUT 값이 그보다 충분히 위에 있는지 확인한다.

### 4.12.4 관련 지표

- **주파수 오차/안정도**: ppm 단위. 4.1.3절과 연계.
- **주파수 드리프트**: 워밍업 시간, 온도 변화에 따른 이동.
- **인테그레이티드 지터/위상오차**: 위상잡음을 오프셋 구간에서 적분해 산출.
- **스퓨리어스(스퍼)**: 캐리어 근방 이산 성분. dBc로 규정.

## 4.13 부정합 내성 (VSWR Ruggedness / Load Mismatch)

### 4.13.1 목적

안테나가 인체·금속에 근접하거나 커넥터가 개방/단락되면 PA는 큰 반사를 겪는다. 이때 **파손 없이(ruggedness), 그리고 규격 위반 없이(performance)** 견디는지 검증한다.

### 4.13.2 셋업과 절차

1. DUT 출력에 **가변 위상 부정합 부하(sliding mismatch / 튜너)** 를 연결한다. 규정 VSWR(예: 3:1, 6:1, 10:1, 또는 개방·단락)을 만든다.
2. 위상을 0~360° 전 범위로 회전시키며(전 반사 위상 각도 스윕) 다음을 감시한다.
   - 출력 전력, 소비전류, 소자 온도
   - 스펙트럼(발진·스퍼 발생 여부)
   - 보호 회로 동작(전력 백오프, 셧다운)
3. 규정 시간 유지 후 정상 부하로 복귀시켜 **성능이 원상 복구되는지** 확인(비가역 열화 여부).
4. 최대 전력·고온 조건에서 수행하는 것이 최악 조건이다.

> **안전** — 부정합 시험 중에는 절대 핫 스위칭(전력 인가 상태에서 커넥터 탈착)을 하지 않는다. 반사파가 계측기와 DUT 모두를 파괴할 수 있다.

## 4.14 수동 상호변조 (PIM)

### 4.14.1 정의와 중요성

커넥터, 케이블, 안테나, 필터 같은 **수동 부품**도 금속 접촉면의 비선형성(산화, 이물, 이종금속, 접촉 불량)으로 인해 상호변조를 만든다. 기지국처럼 송·수신이 동시에 동작하는 시스템에서 IM3가 수신 대역에 떨어지면 감도를 심각하게 파괴한다.

### 4.14.2 측정 (IEC 62037 계열)

- **시험 신호**: 통상 **두 개의 +43 dBm(20 W) 톤**을 사용한다 [45][21].
- **주파수 선택**: IM3 산물이 해당 시스템의 수신 대역에 떨어지도록 f1, f2를 고른다.
- **역방향(Reverse) 측정**: 입력단으로 되돌아오는 IM을 측정. 현장 측정 방식은 IEC 62037-7에 규정 [45].
- **순방향(Forward) 측정**: DUT를 통과해 저PIM 종단으로 나가는 IM을 측정.
- **판정**: 통상 −150 dBc 이하(3차)를 요구하는 응용이 많다 [45].
- **기준선 검증**: 측정 전 저PIM 기준 부하로 시스템 자체 PIM(잡음 하한)을 확인해야 한다. 시스템 PIM이 DUT보다 낮지 않으면 측정이 성립하지 않는다.

### 4.14.3 실무 포인트

- 커넥터 청결·토크가 결과를 좌우한다(2.3절). 손가락 지문 하나로 PIM이 수십 dB 나빠질 수 있다.
- 케이블을 두드리거나 흔들며 PIM 변동을 보는 "탭 테스트"로 불량 접점을 찾는다.
- 시험 중 부품에 기계적 응력을 가하며 측정하는 방식이 규격에 포함되기도 한다.

## 4.15 시간영역 · 트랜지언트 시험

| 항목 | 측정 대상 | 방법 |
|---|---|---|
| 전력 램프(Power ramp) / 버스트 마스크 | 송신 온/오프 램프가 규정 템플릿 내인지 | 피크 전력계 또는 SA 제로스팬 + 트리거 |
| 송신 온/오프 시간 | 제어 신호 대비 RF 출력 지연 | 2채널 스코프(제어 + 검파 출력) |
| 주파수 세틀링 | 채널 변경 후 주파수가 규정 오차로 수렴하는 시간 | VSA 주파수 vs 시간, 또는 주파수 판별기 |
| PLL 록 타임 | 록 신호 및 주파수 수렴 | 스코프 + VSA |
| AGC 응답 | 입력 급변 시 수신 이득 안정화 | VSG 레벨 스텝 + 복조 품질 관측 |
| 전원 트랜지언트 | 송신 개시 시 전원 강하 | 스코프 + 전류 프로브 |

**제로스팬(Zero Span) 활용** — SA를 중심주파수 고정·스팬 0으로 두면 시간축 전력 파형을 볼 수 있다. RBW를 신호 대역보다 넓게, 트리거를 RF 버스트에 맞추면 버스트 마스크 판정에 유용하다.

## 4.16 온도 · 전압 코너 시험

### 4.16.1 왜 필요한가

RF 성능은 온도·공급전압에 강하게 의존한다. 상온·정격전압에서만 통과하는 설계는 필드에서 실패한다. 전기적 특성 시험은 통상 **동작 범위의 저온·상온·고온 3점** 이상에서 수행한다 [38].

### 4.16.2 셋업

- 온도 챔버 + RF 관통 포트(feedthrough). 챔버 벽을 통과하는 케이블의 손실이 **온도에 따라 변한다**는 점을 반드시 고려한다. 가능하면 각 온도에서 경로 손실을 재교정하거나, 온도별 보정 테이블을 만든다.
- 결로 방지: 저온 시험 시 질소 퍼지 또는 건조 공기.
- 열 안정화: 챔버 표시 온도 도달 후에도 내부 물체가 안정화되려면 추가 시간이 필요하다. 실무에서는 **설정 도달 후 수십 분~2시간** 수준의 안정화(soak) 시간을 규정한다.
- DUT 온도는 챔버 온도가 아니라 **케이스/다이 온도**가 실제 지표다. 열전대 또는 내장 온도 센서로 확인한다.

### 4.16.3 코너 매트릭스 예

| 축 | 대표 점 |
|---|---|
| 온도 | −40 °C / −20 °C / +25 °C / +55 °C / +85 °C (제품 규격에 따름) |
| 공급 전압 | V_min / V_nom / V_max (예: 3.0 / 3.6 / 4.2 V) |
| 주파수 채널 | 저 / 중 / 고 |
| 전력 설정 | 최대 / 중간 / 최소 |
| 부하 조건 | 정합 / 부정합(4.13절) |

전 조합을 다 도는 것은 비현실적이므로 **위험 기반**으로 축소한다(온도×전압 전 조합 + 나머지는 최악 코너에서만).

### 4.16.4 열 특성 측정

PA의 접합부 온도와 열저항 평가에는 IR 현미경 기반 표면 온도 측정법이 쓰이며, 온도 제어 스테이지에서 케이스 온도를 규정값(예: 80~125 °C)으로 유지한 채 RF 전력을 인가해 최대 표면 온도로 열저항을 산출한다 [38].

## 4.17 자기간섭 · Desense · 공존(Coexistence)

### 4.17.1 현상

디지털 클럭, 고속 데이터 버스(DDR, MIPI, USB), DC-DC 스위칭 컨버터의 하모닉이 수신 대역에 떨어져 **수신 감도를 떨어뜨리는(desense)** 현상. 전도 경로(RF IC 전원)와 방사 경로(비차폐 메모리 등) 모두를 통해 결합한다 [53][54].

### 4.17.2 특성화 절차 (3단계 접근)

1. **기준 감도 확보**: 다른 서브시스템을 모두 정지시킨 상태에서 감도(또는 잡음층)를 측정한다.
2. **원인 분리**: 서브시스템을 하나씩 켜며 감도 변화(Δ dB)를 기록한다. 가장 큰 Δ를 만드는 블록이 주범이다.
3. **결합 경로 규명**: 근접장 프로브(E/H), RF 전류 프로브, 근접 안테나를 이용해 방사 결합 경로를 추적하고, 전원 라인 잡음은 오실로스코프/스펙트럼 분석기로 전도 경로를 확인한다 [53].

### 4.17.3 스퍼 탐색(Spur Hunting) 실무

- 수신 대역을 SA로 스윕하며 이산 스퍼를 찾는다. 프리앰프·좁은 RBW·최대 유지(max hold)를 사용한다.
- **주파수 역산**: 발견된 스퍼 주파수를 클럭 주파수로 나누어 어떤 클럭의 몇 번째 하모닉인지 특정한다.
- 클럭 주파수를 의도적으로 약간 바꿔(spread spectrum 또는 다른 분주비) 스퍼가 함께 이동하는지 확인하면 확정할 수 있다.
- 신호의 모양·대역폭·시간 거동(드리프트, 진폭 변화, 주파수 호핑)을 관찰하면 발생원 추정에 도움이 된다 [23].

### 4.17.4 대책 방향

차폐 캔, 접지 강화, 클럭 스프레드 스펙트럼, 전원 필터링/LDO 분리, 배치·레이아웃 변경, 클럭 주파수 재선정, 안테나 위치 변경.

### 4.17.5 공존 시험

동일 기기 내 Wi-Fi/Bluetooth/LTE 등이 동시 동작할 때의 상호 열화를 측정한다. 각 조합에 대해 처리율·PER·감도를 측정하고, 시간 분할 제어(coexistence arbitration)가 의도대로 동작하는지 확인한다.

## 4.18 OTA (Over-The-Air) 시험

### 4.18.1 대상

내장 안테나 제품은 커넥터가 없거나, 있어도 최종 성능은 안테나를 포함한 전체 시스템에서 결정된다. OTA는 **안테나를 포함한 종단 성능**을 측정한다.

### 4.18.2 핵심 지표

| 지표 | 의미 |
|---|---|
| **TRP** (Total Radiated Power) | 전 방향으로 방사되는 총 전력 |
| **TIS** (Total Isotropic Sensitivity) | 전 방향에서의 수신 감도를 통합한 값 |
| EIRP / EIS | 특정 방향에서의 등가 등방성 방사전력 / 감도 |
| 안테나 효율, 이득 패턴 | 방사 특성 |

### 4.18.3 셋업

- **무향실(Anechoic Chamber)**: 모든 내벽을 전파 흡수체로 처리해 반사를 제거하고 자유공간 조건을 근사한다. 이를 통해 외부 전파와 내부 반사의 영향 없이 DUT 안테나 특성을 평가할 수 있다 [43].
- DUT를 구면 좌표계에서 회전(θ, φ)시키며 두 편파(θ 편파, φ 편파)를 측정하고 구면 적분으로 TRP/TIS를 산출한다.
- **기준 측정(reference measurement)**: 이득이 알려진 기준 안테나로 경로 손실, 수신 안테나 이득, 케이블 손실을 포함한 레인지 특성을 사전 교정한다 [43][44].
- 시험 계획(측정점 개수, 자세, 편파, 산출식)은 CTIA 시험 계획 문서가 표준적으로 규정한다 [43][44].

### 4.18.4 실무 포인트

- TIS 측정은 각 측정점마다 감도 탐색이 필요해 **매우 오래 걸린다**. 측정점 수 축소, 이분 탐색 최적화, 부분 구면 측정 등의 기법을 사용한다.
- DUT의 배터리·발열·자세 유지 지그가 결과에 영향을 준다. 지그는 저유전율·저반사 재료를 쓴다.
- 케이블을 연결한 상태로 측정하면 케이블이 안테나로 동작해 패턴이 왜곡된다. 무선 제어(광섬유 링크, 배터리 동작 + 무선 제어)를 사용한다.

## 4.19 규격 인증 사전시험 (Pre-compliance)

### 4.19.1 목적

공인 시험소에 보내기 전에 사내에서 위험을 제거한다. 정확도는 시험소를 따라갈 수 없지만, **실패 항목을 미리 찾는 것**이 목적이다.

### 4.19.2 대표 항목

| 규제 체계 | 대표 항목 |
|---|---|
| FCC Part 15 (미국, 비면허) | 최대 출력/PSD, 대역외 방출, 제한대역 스퓨리어스, 6 dB 대역폭, 주파수 호핑 요건, 안테나 요건 |
| ETSI EN 300 328 (유럽 2.4 GHz) | 최대 EIRP, 전력 스펙트럼 밀도, 점유대역폭, 매체 접근(Adaptivity/LBT), 대역외·스퓨리어스 방출, 수신기 차단 |
| ETSI EN 301 893 (유럽 5 GHz) | 위 항목 + DFS, TPC |
| 3GPP (셀룰러) | 최대 출력, ACLR, SEM, 스퓨리어스, in-band emission, EVM, 감도, 차단 등 [41] |
| EMC (EN 55032/CISPR 32 등) | 전도·방사 방해, 검출기(peak/quasi-peak/average) |

### 4.19.3 3GPP 단말 RF 적합성 시험의 구조

3GPP 단말 RF 적합성 시험 규격(예: 5G NR의 **TS 38.521-1**, LTE의 TS 36.521-1)은 송신기·수신기 항목을 절 번호 체계로 규정하고 각 항목의 시험 조건, 시험 신호, 최소 요구값을 표로 제시한다 [41]. 요구값 자체의 근거가 되는 핵심 규격은 별도 문서(5G NR FR1의 경우 TS 38.101-1)에 정의되므로 두 문서를 함께 본다 [42]. 계측기 제조사는 이 규격의 각 절과 대응되는 측정 설정을 제공하는 응용 노트를 발간한다 [14][15]. 벤치 엔지니어는 사내 시험 항목을 이 절 번호에 매핑해 두면 인증 단계에서의 누락을 줄일 수 있다.

### 4.19.4 사내 사전시험 팁

- 사내 셋업과 시험소 결과의 **오프셋을 이력으로 관리**한다. 절대값보다 "우리 셋업에서 X dB면 시험소에서 통과"라는 상관 관계가 실용적이다.
- 최악 조건(최대 출력, 최고 온도, 최악 채널)을 우선 측정한다.
- DUT의 시험 모드(연속 송신, 특정 채널 고정)를 미리 확보해 둔다. 시험소에서 이것이 없어 시간을 낭비하는 일이 매우 흔하다.

# 5. 시험 자동화

## 5.1 계층 구조

| 계층 | 역할 | 대표 기술 |
|---|---|---|
| 물리 버스 | 계측기 연결 | GPIB, USB-TMC, LAN(VXI-11 / HiSLIP / raw socket), RS-232, PCIe |
| I/O 추상화 | 버스에 무관한 통신 API | **VISA** (NI-VISA, Keysight IO Libraries, pyvisa-py) |
| 명령 계층 | 계측기 명령 문법 | **SCPI** (표준화된 명령 트리) |
| 기능 추상화 | 계측기 종류별 공통 API | **IVI** 클래스 드라이버(스코프, DMM, 스펙트럼 분석기, RF 신호원, 전력계 등) [60] |
| 시험 시퀀스 | 측정 순서, 한계 판정, 리포팅 | Python, LabVIEW, TestStand, 사내 프레임워크 |

VISA는 "어느 버스로 말할 것인가"를, IVI는 "어떤 기능을 부를 것인가"를 담당한다. 이 분리 덕분에 LAN 소켓으로 개발한 프로그램을 USB-TMC로 바꿀 때 **VISA 리소스 문자열만 교체**하면 된다 [59][60].

## 5.2 Python + PyVISA 기본 골격

```
import pyvisa

rm = pyvisa.ResourceManager()
with rm.open_resource("TCPIP0::192.168.0.11::hislip0::INSTR") as sa:
    sa.timeout = 20000                 # ms, 긴 스윕 대비
    sa.write("*RST")                   # 알려진 상태에서 시작
    sa.write("*CLS")
    sa.write(":FREQ:CENT 2.44GHz")
    sa.write(":FREQ:SPAN 10MHz")
    sa.write(":BAND 30kHz")            # RBW
    sa.write(":DET RMS")
    sa.write(":INIT:CONT OFF")
    sa.query("*OPC?")                  # 설정 완료 동기
    sa.write(":INIT:IMM")              # 단발 스윕
    sa.query("*OPC?")                  # 스윕 완료 대기
    peak = float(sa.query(":CALC:MARK1:Y?"))
    err = sa.query(":SYST:ERR?")       # 매 단계 에러 큐 확인
```

## 5.3 실무 규칙

- **알려진 상태에서 시작**: 시퀀스 시작 시 `*RST` 후 필요한 설정을 명시적으로 모두 지정한다. "이전 상태에 의존하는 스크립트"는 반드시 언젠가 잘못된 값을 낸다.
- **동기화**: `*OPC?`, `*WAI`, 상태 바이트 폴링 중 하나로 측정 완료를 확실히 대기한다. 고정 `sleep()` 은 느리고 불안정하다.
- **에러 큐 확인**: 각 논리 단계 후 `SYST:ERR?` 를 읽어 무시된 명령을 잡는다.
- **세션 관리**: VISA 세션을 반드시 닫는다(`with` 구문 권장). 누수된 세션은 "resource busy"로 계측기를 잠근다.
- **타임아웃**: 긴 스윕·평균·NF 측정에는 넉넉한 타임아웃을 준다. 타임아웃 예외는 반드시 처리한다.
- **전송 형식**: 대량 트레이스는 ASCII 대신 바이너리(REAL,32/REAL,64) 전송으로 시간을 크게 줄인다.
- **보정의 코드화**: 경로 손실, 필터 손실, 커플러 결합도를 코드 상수로 흩어 놓지 말고 **버전 관리되는 교정 파일**로 분리한다.
- **드라이버 계층 분리**: 계측기별 SCPI를 얇은 드라이버 클래스로 감싸고, 시험 시퀀스는 그 인터페이스만 호출하도록 한다. 계측기 교체 비용이 급감한다.
- **재현성 메타데이터**: 모든 측정 레코드에 계측기 모델·시리얼·펌웨어, 교정 파일 버전, 소프트웨어 커밋 해시, 시각, 온도를 남긴다.

## 5.4 데이터와 통계

- 원시 측정값(raw)과 보정 후 값(corrected)을 **모두** 저장한다. 보정 오류를 사후에 되돌릴 수 있는 유일한 방법이다.
- 합/불 판정과 별개로 **연속 측정값 자체**를 저장한다. 합/불만 남기면 드리프트 분석이 불가능하다.
- 공정능력 지수: `Cp = (USL − LSL)/(6σ)`, `Cpk = min[(USL − μ), (μ − LSL)]/(3σ)`. 양산에서는 통상 Cpk ≥ 1.33을 목표로 한다.
- 관리도(control chart)로 시프트 간·테스터 간 드리프트를 감시한다.

# 6. 생산 시험 플로우

## 6.1 전형적 순서

1. **DC / 기본 검사** — 전원 인가, 소비전류, 통신 링크 확인. 여기서 죽은 보드를 먼저 걸러야 RF 시간을 낭비하지 않는다.
2. **Trim / Calibration** — 주파수, 송신 전력, RSSI, DC 오프셋 트림 후 NVM 기록(4.1절).
3. **Tx 검증** — 출력 전력(다채널), 주파수 오차, 변조 품질 또는 축약 지표, 하모닉(샘플링 또는 전수).
4. **Rx 검증** — 규정 레벨에서의 PER/BER(고정 레벨 합·불 방식이 전수 감도 탐색보다 훨씬 빠르다).
5. **최종 확인** — 트림값 재판독·체크섬, 시리얼/MAC 기록, 결과 업로드.

## 6.2 시험 시간 단축 기법

| 기법 | 효과 |
|---|---|
| 고정 레벨 합·불(Rx) | 감도 탐색 대신 규정 레벨 1점 판정 |
| 병렬 측정(멀티 DUT) | 다중 포트 계측기 또는 다중 사이트 픽스처 |
| 단일 캡처 다중 분석 | 하나의 I/Q 캡처에서 ACLR/SEM/EVM 동시 산출 [14] |
| 채널 축소 | 저·중·고 3채널 + 상관성으로 나머지 추정 |
| 샘플링 검사 | 하모닉·스퓨리어스 등 안정적 항목은 로트 샘플링 |
| 계측기 리스트 모드 | 주파수/레벨 시퀀스를 계측기 내부에 미리 적재해 통신 오버헤드 제거 |

## 6.3 한계선 설정

1. 특성화 단계에서 충분한 표본(예: 30~50대)을 코너 조건에서 측정해 분포를 확보한다 [31].
2. 제품 규격(외부 규격, 고객 요구)을 상한으로 두고, 측정 불확도만큼 가드밴드를 적용한다(3.6.3절).
3. 초기에는 느슨하게 두고 데이터가 쌓이면 조인다. 처음부터 조이면 정상 제품을 버린다.
4. 한계선 변경은 반드시 변경 관리(이력, 승인, 적용 일시)를 남긴다.

## 6.4 골든 유닛과 상관성 관리

- 골든 유닛은 규격 내로 검증된 기준 DUT이며, 통상 계측이 더 정밀한 R&D 환경에서 확립한다.
- **복수 대(예: 3대)** 를 두고 각 상관 파라미터의 표준편차가 사전 정의된 범위 내인지 확인한다. 파라미터마다 별도의 허용 공차를 정의한다.
- 신규 테스터를 라인에 투입할 때 GR&R 분석의 기준으로 사용하고, 값이 서로 다른 여러 개체를 포함시키면 측정 시스템의 레벨 의존성까지 볼 수 있다.
- 골든 유닛 자체도 노후화한다. 봉인 보관, 사용 횟수 제한, 정기 재검증이 필요하다.

# 7. 트러블슈팅 체크리스트

## 7.1 "값이 이상하다" — 계측계부터 의심하는 순서

1. **DUT 없이 측정**: 경로만 연결한 상태의 결과가 기대치인가.
2. **알려진 기준 삽입**: 표준 감쇠기, 골든 유닛, 교정된 소스로 시스템을 검증.
3. **재접속 반복성**: 커넥터를 5회 재체결하며 산포 확인. 0.3 dB 이상 흔들리면 접속부 문제.
4. **감쇠 스윕**: 입력 감쇠를 ±10 dB 바꿔 결과가 변하면 계측기 왜곡 또는 압축.
5. **케이블 흔들기**: 케이블을 움직였을 때 값이 변하면 케이블/커넥터 불량.
6. **다른 계측기로 교차 확인**: 전력계 ↔ SA, VNA ↔ SG+SA.
7. **교정 유효성**: VNA 교정 상태, 전력계 제로/교정 시각, 경로 손실 테이블 갱신 시각 확인.

## 7.2 증상별 1차 원인 지도

| 증상 | 먼저 볼 곳 |
|---|---|
| 출력 전력이 전 채널에서 일정하게 낮음 | 경로 손실 보정, 감쇠기 값, 케이블 손실 |
| 특정 채널에서만 낮음 | 정합/필터 응답, 안테나 스위치 |

## 8.1 자주 쓰는 공식

| 항목 | 식 |
|---|---|
| dBm ↔ W | `P[dBm] = 10·log10(P[mW])`, `P[mW] = 10^(P[dBm]/10)` |
| 50 Ω에서 dBm ↔ Vrms | `V_rms = sqrt(0.05 × 10^(P[dBm]/10))` (P in dBm) |
| 반사계수 ↔ VSWR | `VSWR = (1+\|Γ\|)/(1−\|Γ\|)`, `\|Γ\| = (VSWR−1)/(VSWR+1)` |
| 반사손실 | `RL[dB] = −20·log10\|Γ\|` |
| 반사 전력 비율 | `P_ref/P_inc = \|Γ\|²` |
| 열잡음 전력 | `N[dBm] = −174 + 10·log10(BW[Hz])` (290 K) |
| 잡음지수(Y-factor) | `NF = ENR − 10·log10(Y − 1)` |
| 캐스케이드 잡음지수 | `F = F1 + (F2−1)/G1 + (F3−1)/(G1·G2) + …` |
| IIP3 (2톤) | `IIP3 = P_in + ΔP/2` (ΔP = 기본파 − IM3) |
| OIP3 | `OIP3 = P_out + ΔP/2` |
| 캐스케이드 IP3 | `1/IIP3_tot = 1/IIP3_1 + G1/IIP3_2 + …` (선형 스케일) |
| PAE | `PAE = (P_out − P_in)/P_DC × 100 [%]` |
| 펄스 평균/피크 | `P_avg = P_peak × Duty` |
| 정합 불확도 한계 | `≈ 20·log10(1 ± \|Γs\|\|Γl\|) [dB]` |
| 교차상관 이득(위상잡음) | `≈ 5·log10(N) [dB]` |
| 자유공간 경로손실 | `FSPL[dB] = 20log10(d) + 20log10(f) + 32.45` (d in km, f in MHz) |
| EVM ↔ SNR (근사) | `SNR[dB] ≈ −20·log10(EVM)` (EVM은 비율) |
| Cpk | `min[(USL−μ), (μ−LSL)] / (3σ)` |

**검토 시 적용한 원칙**

- 수치와 한계값은 원 규격·응용 노트에 근거가 있는 것만 기재하고, 규제 수치에는 판본 확인 주의를 병기한다.
- 제조사 고유 구현에 의존하는 절차는 "제품 규격/데이터시트를 따른다"로 명시한다.
- 벤치에서 재현 불가능한 서술(측정 수단이 특정되지 않은 지표)은 포함하지 않는다.

> **사용 시 주의** — 본 문서는 일반적 실무 지침이다. 실제 판정 기준, 시험 조건, 규제 한계는 반드시 **해당 제품의 규격서와 적용 판본의 표준 원문**을 근거로 확정해야 한다.
