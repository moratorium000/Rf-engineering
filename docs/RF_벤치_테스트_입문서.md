# 0. 이 문서를 읽는 법

## 0.1 누구를 위한 문서인가

이 문서는 다음과 같은 사람을 위해 썼다.

- 전자공학 전공이 아닌데 RF 시험 업무를 맡게 된 사람
- 전공은 했지만 실험실 장비를 실제로 만져본 적이 없는 사람
- 기존 상세 문서를 펼쳤더니 **용어에서 막혀서** 진도가 안 나가는 사람

그래서 이 문서는 **"아무것도 모른다"를 출발점으로** 삼는다. dB가 뭔지, 임피던스가 뭔지, 왜 50 Ω인지부터 시작한다. 이미 아는 부분은 건너뛰어도 좋다.

## 0.2 이 문서의 약속

- **모르는 단어를 던지지 않는다.** 새 용어가 나오면 그 자리에서 초록색 상자로 설명한다.
- **왜 그렇게 하는지 먼저 말한다.** 절차를 외우게 하지 않고, 이유를 이해하면 절차가 따라오게 한다.
- **비유를 적극적으로 쓴다.** 비유는 정확하지 않다. 하지만 처음에는 정확한 오해보다 부정확한 이해가 낫다. 비유가 깨지는 지점은 그때그때 밝혀 둔다.
- **숫자는 끝까지 계산해서 보여준다.** "계산하면 됩니다"로 끝내지 않는다.

## 0.3 상자 세 가지 읽는 법

이 문서에는 세 종류의 상자가 나온다.

>> **용어 상자** — 새로 나온 단어의 뜻을 여기서 설명한다. 이 상자만 따라 읽어도 용어 사전이 된다.

> **참고 상자** — 알아두면 이해가 깊어지는 배경, 또는 중요한 원칙.

>! **함정 상자** — 처음 하는 사람이 실제로 자주 틀리는 지점. 여기 나온 것만 피해도 사고의 절반은 막는다.

## 0.4 읽는 순서

| 상황 | 권장 경로 |
|---|---|
| 완전 처음, 시간이 있다 | 1부 → 2부 → 3부 → 4부 → 5부 순서대로 |

# 1. RF가 대체 무엇인가

## 1.1 전기 신호와 전파

집에서 쓰는 전기는 콘센트에서 나와 선을 타고 흐른다. 선이 끊기면 전기도 끊긴다. 그런데 휴대폰은 선이 없는데도 통신을 한다. 이 차이가 RF의 출발점이다.

전선에 흐르는 전류의 방향을 아주 빠르게 바꾸면 — 1초에 수억 번, 수십억 번 — 그 전선 주위에 **전자기파**가 생겨 공간으로 퍼져 나간다. 이 현상을 이용해 정보를 실어 보내는 것이 무선통신이고, 이때 쓰는 빠르게 진동하는 전기 신호를 **RF 신호**라고 부른다.

>> **RF (Radio Frequency, 무선 주파수)** — 대략 수백 kHz에서 수백 GHz까지, 안테나를 통해 공간으로 방사될 수 있을 만큼 빠르게 진동하는 전기 신호. 우리말로는 "고주파"라고도 한다. 실무에서는 그냥 "알에프"라고 읽는다.

>> **DUT (Device Under Test, 피시험 장치)** — 지금 우리가 시험하고 있는 대상. 칩일 수도, 보드일 수도, 완제품일 수도 있다. 실무에서 가장 자주 쓰는 약어이므로 이것만은 외워두자. "디유티"라고 읽는다.

## 1.2 주파수, 파장, 대역폭 — 이 셋이면 절반은 온다

### 주파수 (Frequency)

**1초에 몇 번 진동하는가.** 단위는 Hz(헤르츠)다.

- 1 Hz = 1초에 1번
- 1 kHz = 1초에 1,000번 (킬로헤르츠)
- 1 MHz = 1초에 100만 번 (메가헤르츠)
- 1 GHz = 1초에 10억 번 (기가헤르츠)

우리가 다루는 것들의 위치를 감으로 잡아보자.

| 대상 | 주파수 | 감각 |
|---|---|---|
| 사람 목소리 | 100 Hz ~ 3 kHz | 소리 (전파 아님) |
| AM 라디오 | 약 1 MHz | |
| FM 라디오 | 약 100 MHz | |
| LTE / 5G (저대역) | 700 MHz ~ 2.6 GHz | 휴대폰 |
| Wi-Fi / Bluetooth | 2.4 GHz, 5 GHz, 6 GHz | |
| 전자레인지 | 2.45 GHz | Wi-Fi와 같은 대역이라 간섭이 생긴다 |
| 5G 밀리미터파 | 24 ~ 40 GHz | |
| 자동차 레이더 | 77 GHz | |

>! **함정** — "2.4G"라고 하면 2.4 GHz를 뜻하지만, 휴대폰의 "5G"는 5 GHz가 아니라 **5세대(5th Generation)** 라는 뜻이다. 완전히 다른 말이다. 현장에서 "5G 테스트"와 "5기가 테스트"는 다른 작업일 수 있으니 반드시 확인하자.

### 파장 (Wavelength)

**한 번 진동하는 동안 파가 나아가는 거리.** 기호는 λ(람다)를 쓴다.

`파장(m) = 300 / 주파수(MHz)`

| 주파수 | 파장 | 비교 |
|---|---|---|
| 100 MHz | 3 m | 사람 키의 두 배 |
| 1 GHz | 30 cm | A4 용지 긴 변 |
| 2.4 GHz | 12.5 cm | 손바닥 |
| 28 GHz | 1.07 cm | 손톱 |

**왜 파장을 알아야 하나?** 안테나 크기, 회로 배선의 길이, 케이블의 영향이 전부 파장과 비교해서 결정되기 때문이다. 파장의 1/20보다 짧은 배선은 그냥 "선"이지만, 파장에 가까워지면 그 배선 자체가 신호를 반사하고 변형시키는 **부품**이 된다.

> **감각 잡기** — 2.4 GHz의 파장은 12.5 cm다. 보드 위 5 cm짜리 배선은 파장의 40%나 된다. 이 정도면 "선"이 아니라 하나의 회로 소자다. 그래서 RF 보드는 배선 길이와 폭을 밀리미터 단위로 관리한다.

### 대역폭 (Bandwidth)

**신호가 차지하는 주파수의 폭.** 단위는 역시 Hz다.

라디오 방송을 생각해보자. 89.1 MHz 방송국은 정확히 89.1 MHz 한 점만 쓰는 게 아니라, 그 주변으로 약 200 kHz의 폭을 차지한다. 이 폭이 대역폭이다.

>> **대역폭 (Bandwidth, BW)** — 신호가 주파수 축에서 차지하는 구간의 넓이. **정보를 많이 보내려면 넓은 대역폭이 필요하다.** 도로의 차선 수라고 생각하면 된다. 차선이 많을수록 더 많은 차가 지나간다.

| 신호 | 대역폭 | 비유 |
|---|---|---|
| Bluetooth LE | 1 ~ 2 MHz | 1차선 도로 |
| Wi-Fi 802.11n | 20 / 40 MHz | 2 ~ 4차선 |
| LTE | 1.4 ~ 20 MHz | |
| Wi-Fi 6 | 최대 160 MHz | 고속도로 |
| 5G NR (FR1) | 최대 100 MHz | |
| 5G NR (밀리미터파) | 최대 400 MHz | 초광폭 |

## 1.3 왜 RF는 "그냥 전기"와 다르게 다뤄야 하나

여기가 비전공자가 가장 먼저 만나는 벽이다. 천천히 가보자.

### 낮은 주파수에서의 세계

전등을 켜는 회로를 생각하자. 스위치를 누르면 전기가 흘러 전구가 켜진다. 이때 전선의 길이는 (아주 길지 않다면) 별로 중요하지 않다. 1 m를 쓰든 2 m를 쓰든 전구는 똑같이 켜진다. 전선은 그냥 "통로"다.

### 높은 주파수에서의 세계

RF에서는 다르다. 1.2절에서 봤듯 2.4 GHz의 파장은 12.5 cm다. 신호가 케이블을 지나는 동안 이미 여러 번 진동한다. 즉, **케이블의 앞쪽과 뒤쪽에서 신호의 위상이 다르다.** 케이블이 더 이상 단순한 통로가 아니라, 신호가 그 안에서 파도처럼 진행하는 **매질**이 된다.

이렇게 되면 새로운 문제가 생긴다. **파도는 성질이 바뀌는 경계에서 반사한다.**

> **비유: 밧줄 흔들기** — 굵은 밧줄과 가는 밧줄을 이어놓고 굵은 쪽 끝을 흔들어 파를 보내면, 두 밧줄의 이음매에서 파의 일부가 **되돌아온다**. 굵기가 갑자기 바뀌었기 때문이다. 두 밧줄의 굵기가 같으면 파는 반사 없이 그대로 넘어간다.
>
> RF 회로에서 "굵기"에 해당하는 것이 바로 **임피던스**다.

### 임피던스와 50 Ω

>> **임피던스 (Impedance)** — 회로가 전기 신호의 흐름에 대해 보이는 "저항감". 단위는 Ω(옴). 저항과 비슷하지만, 주파수에 따라 값이 달라지고 위상까지 포함하는 더 넓은 개념이다. RF에서는 **"이 지점에서 신호가 느끼는 굵기"** 정도로 이해하면 실무에는 충분하다.

RF 세계에서는 케이블, 커넥터, 계측기, 회로가 **거의 전부 50 Ω으로 통일**되어 있다. 왜 하필 50인가? 동축 케이블에서 최소 손실을 주는 값(약 77 Ω)과 최대 전력 전달을 주는 값(약 30 Ω)의 절충으로 굳어진 역사적 합의다. 중요한 건 **모두가 같은 값을 쓴다는 사실** 자체다.

모두가 50 Ω이면 신호는 반사 없이 흐른다. 어느 한 지점이 50 Ω이 아니면 거기서 반사가 생긴다.

>! **함정** — 오디오/영상용 케이블 중에는 75 Ω짜리가 많다(TV 안테나 케이블 등). 겉모습이 비슷해서 섞여 들어가면 측정이 조용히 틀어진다. 커넥터에 적힌 표기를 확인하는 습관을 들이자.

### 반사가 나쁜 이유

반사가 생기면 세 가지가 동시에 나빠진다.

1. **전력이 목적지에 다 못 간다.** 되돌아온 만큼 손해다.
2. **되돌아온 파가 앞에서 오던 파와 겹쳐서** 위치에 따라 신호가 세지고 약해지는 얼룩(정재파)이 생긴다. 측정값이 케이블 길이에 따라 달라지는 이상한 일이 벌어진다.
3. **되돌아온 전력이 송신기를 때린다.** 심하면 증폭기가 고장 난다.

이 반사의 정도를 나타내는 숫자가 **반사계수, 반사손실, VSWR**이다. 2.3절에서 자세히 다룬다.

## 1.4 무선기기 안에서 벌어지는 일 (블록도 산책)

측정 항목을 이해하려면, 먼저 우리가 무엇을 측정하는지 그림이 있어야 한다. 무선기기 하나를 열어서 신호가 지나가는 길을 따라가 보자.

### 송신기(Transmitter, TX) 쪽

```
  [BASEBAND]  -->  [MIXER]  -->  [FILTER]  -->  [PA]  -->  [SWITCH]  --> [ANTENNA]
   보낼 데이터      주파수 올림     불필요한       전력을      송/수신
   (느린 신호)      (LO 사용)      성분 제거      키움        전환
```

| 블록 | 하는 일 | 쉬운 비유 |
|---|---|---|
| **베이스밴드(Baseband)** | 보낼 데이터를 낮은 주파수의 전기 신호로 만듦 | 편지를 쓴다 |
| **믹서(Mixer)** | 낮은 주파수 신호를 목표 주파수로 끌어올림 | 편지를 봉투에 넣어 주소를 적는다 |
| **LO (Local Oscillator, 국부 발진기)** | 믹서가 쓸 기준 주파수를 만들어 줌 | 주소를 알려주는 사람 |
| **필터(Filter)** | 원하는 주파수만 통과시키고 나머지는 막음 | 체로 거른다 |
| **PA (Power Amplifier, 전력 증폭기)** | 신호를 멀리 보낼 만큼 세게 만듦 | 목소리를 키우는 확성기 |
| **스위치(Switch)** | 안테나를 송신에 쓸지 수신에 쓸지 전환 | 갈림길의 신호등 |
| **안테나(Antenna)** | 전기 신호를 전파로 바꿔 공간에 내보냄 | 편지를 우체통에 넣는다 |

### 수신기(Receiver, RX) 쪽

```
  [ANTENNA] --> [SWITCH] --> [FILTER] --> [LNA] --> [MIXER] --> [FILTER] --> [ADC/DEMOD]
                                          아주 작은   주파수      원하는       데이터로
                                          신호 증폭   내림        채널만       복원
```

| 블록 | 하는 일 | 쉬운 비유 |
|---|---|---|
| **LNA (Low Noise Amplifier, 저잡음 증폭기)** | 안테나로 들어온 아주 약한 신호를 잡음을 최대한 안 더하면서 키움 | 속삭임을 듣는 귀. **여기서 더해진 잡음은 뒤에서 절대 못 지운다** |
| **믹서** | 높은 주파수를 다루기 쉬운 낮은 주파수로 내림 | 봉투를 열어 편지를 꺼낸다 |
| **ADC / 복조기** | 아날로그 신호를 디지털 데이터로 되돌림 | 편지를 읽는다 |

> **여기서 중요한 사실** — 수신기 성능은 **맨 앞단(LNA)이 거의 결정한다.** 앞에서 잡음이 섞이면 뒤에서 아무리 증폭해도 신호와 잡음이 같이 커질 뿐이다. 그래서 4.10절의 "잡음지수"라는 측정이 존재한다.

## 1.5 결국 우리는 무엇을 재는가 — 네 가지 축

RF 시험 항목이 수십 개라 처음엔 압도된다. 하지만 거의 전부 **네 가지 질문** 중 하나다. 이 틀을 잡아두면 새로운 시험을 만나도 자리를 찾을 수 있다.

| 축 | 질문 | 대표 시험 |
|---|---|---|
| **① 얼마나 세게 보내는가** | 출력이 규격대로 나오는가 | 출력 전력, 이득, P1dB |
| **② 정확한 자리에 보내는가** | 남의 주파수를 침범하지 않는가 | 주파수 정확도, 하모닉, 스퓨리어스, ACLR |
| **③ 얼마나 깨끗하게 보내는가** | 신호가 일그러지지 않았는가 | EVM, 위상잡음, IMD |
| **④ 얼마나 잘 듣는가** | 약한 신호를 받아내는가, 방해에 견디는가 | 감도, 잡음지수, 선택도, 차단 |

여기에 **⑤ 준비와 검증**(정합, 경로 손실 교정, 온도 코너)이 뒷받침된다.

>> **왜 ②가 중요한가** — 전파는 모두가 나눠 쓰는 공용 자원이다. 내 기기가 남의 대역에 신호를 흘리면 다른 사람의 통신을 망친다. 그래서 각국 정부(미국 FCC, 유럽 ETSI, 한국 과기정통부 등)가 법으로 한계를 정해두었고, 이를 어기면 **제품을 팔 수 없다.** 하모닉·스퓨리어스 측정이 단순한 품질 확인이 아니라 **법적 요구사항**인 이유다.

# 2. 숫자 읽는 법

RF 실무에서 오가는 대화는 대부분 숫자다. "출력이 20 dBm 나와야 하는데 18.5밖에 안 나와요." 이 문장을 편하게 이해하는 것이 첫 목표다.

## 2.1 dB — RF의 공용어

### 왜 로그를 쓰는가

RF에서 다루는 전력의 범위는 어이없을 만큼 넓다.

- 기지국 송신 전력: 20 W
- 휴대폰 송신 전력: 0.2 W
- 휴대폰이 받아내는 신호: 0.0000000000001 W (10의 마이너스 13제곱 와트)

이 숫자들을 그대로 쓰면 0을 세다가 하루가 간다. 그래서 **로그**를 써서 압축한다. 그 결과가 dB(데시벨)다.

>> **dB (decibel, 데시벨)** — **비율**을 로그로 표현한 것. "몇 배인가"를 압축해서 쓴 것이다. **dB 자체는 절대적인 크기가 아니라 항상 무엇에 대한 비율이다.** "10 dB 크다"는 말은 되지만 "10 dB이다"라는 말은 (기준이 없으면) 성립하지 않는다.

전력 비율을 dB로 바꾸는 식은 이렇다.

`dB = 10 × log10(비율)`

### 외워야 할 것은 딱 세 개

실무에서는 계산기를 두드리기 전에 감으로 맞히는 것이 중요하다. 다음 세 개만 외우면 나머지는 조합으로 나온다.

| 배율 | dB | 외우는 법 |
|---|---|---|
| **2배** | **+3 dB** | "3 dB 올리면 두 배" |
| **10배** | **+10 dB** | "10 dB 올리면 열 배" |
| **1/2배** | **−3 dB** | "3 dB 내리면 절반" |

이것을 더하고 빼면 된다. dB는 곱셈을 덧셈으로 바꿔주기 때문이다.

| 계산 | 과정 | 결과 |
|---|---|---|
| 4배 | 2배 × 2배 = 3 + 3 | +6 dB |
| 8배 | 2 × 2 × 2 = 3 + 3 + 3 | +9 dB |
| 20배 | 10배 × 2배 = 10 + 3 | +13 dB |
| 100배 | 10 × 10 = 10 + 10 | +20 dB |
| 1000배 | 10 + 10 + 10 | +30 dB |
| 1/100배 | −10 − 10 | −20 dB |

> **정확히는** 2배 = 3.01 dB다. 실무에서는 3으로 쓴다. 3번 곱하면 0.03 dB 차이인데, 이 정도는 대부분의 측정 불확도보다 작다.

>! **함정: 전력이냐 전압이냐** — 전력은 `10 × log10`, 전압은 `20 × log10`을 쓴다. 계수가 다르다. RF 벤치에서는 거의 항상 **전력**을 다루므로 `10 log`를 기본으로 생각하되, 반사손실(S11)처럼 전압비로 정의된 값은 `20 log`를 쓴다는 것만 기억해두자. 헷갈리면 "이건 전력 이야기인가 전압 이야기인가"를 먼저 묻는다.

## 2.2 dBm, dBc, 그리고 친척들

dB는 비율이라고 했다. 그러면 절대적인 크기는 어떻게 말하는가? **기준을 정하고 그 기준에 대한 비율**로 말한다. 기준을 dB 뒤에 붙여 표시한다.

>> **dBm** — 기준이 **1 mW(밀리와트)** 인 dB. 즉 절대 전력을 나타낸다. RF에서 가장 많이 쓰는 단위. "디비엠"이라고 읽는다.
>>
>> `0 dBm = 1 mW` 가 출발점이다.

### dBm 감각표 — 이 표는 외우는 게 좋다

| dBm | 실제 전력 | 어디서 보나 |
|---|---|---|
| +43 dBm | 20 W | 기지국 송신, PIM 시험 신호 |
| +30 dBm | 1 W | 큰 증폭기 출력 |
| +20 dBm | 100 mW | 휴대폰 최대 송신 근처 |
| +10 dBm | 10 mW | Wi-Fi 송신 정도 |
| **0 dBm** | **1 mW** | **기준점** |
| −10 dBm | 0.1 mW | 계측기 입력으로 편안한 수준 |
| −30 dBm | 1 µW | 스펙트럼 분석기 믹서 권장 레벨 |
| −60 dBm | 1 nW | 가까이서 받은 Wi-Fi 신호 |
| −100 dBm | 0.1 pW | 휴대폰 수신 감도 근처 |
| −120 dBm | 1 fW | 아주 좋은 수신기의 한계 |

> **읽는 요령** — dBm이 30 줄어들 때마다 전력은 1000분의 1이 된다. 0 dBm(1 mW) → −30 dBm(1 µW) → −60 dBm(1 nW) → −90 dBm(1 pW) → −120 dBm(1 fW). 이 사다리만 기억하면 대부분 암산된다.

### 그 밖의 dB 친척들

| 표기 | 기준 | 어디에 쓰나 |
|---|---|---|
| **dBm** | 1 mW | 절대 전력. 가장 많이 씀 |
| **dB** | (기준 없음, 순수 비율) | 이득, 손실, 차이 |
| **dBc** | 캐리어(주 신호) 전력 | "주 신호보다 얼마나 작은가". 하모닉, 스퓨리어스, 위상잡음 |
| **dBm/Hz** | 1 Hz 대역폭당 전력 | 잡음 밀도 |
| **dBc/Hz** | 캐리어 대비, 1 Hz당 | 위상잡음 |
| **dBµV/m** | 1 µV/m 전계강도 | EMC 방사 측정 |
| **dBi** | 등방성 안테나 | 안테나 이득 |

>! **함정: dBm끼리 더하지 말 것** — dBm은 절대 전력이다. 10 dBm + 10 dBm은 20 dBm이 **아니다**. (실제로는 10 mW + 10 mW = 20 mW = 13 dBm이다.) **dB(비율)는 dBm에 더할 수 있지만, dBm끼리는 더할 수 없다.**
>!
>! - 맞음: 10 dBm 신호를 3 dB 증폭 → 13 dBm ✔
>! - 틀림: 10 dBm + 10 dBm = 20 dBm ✘

### 실무에서 가장 많이 하는 계산

`DUT 출력(dBm) = 계측기가 읽은 값(dBm) + 중간에서 잃은 손실(dB)`

케이블과 감쇠기에서 잃은 만큼을 **더해줘야** 원래 출력이 나온다. 이것이 3.5절 "경로 손실 교정"의 핵심이다.

## 2.3 임피던스, 반사, VSWR

1.3절에서 임피던스가 안 맞으면 반사가 생긴다고 했다. 그 반사를 숫자로 표현하는 방법이 세 가지 있는데, **셋 다 같은 이야기를 다르게 말한 것**이다.

### 반사계수 (Γ, 감마)

**들어간 파 중 얼마가 되돌아왔는가를 비율로 표현한 것.** 0이면 반사 없음(완벽), 1이면 전부 반사(최악).

### 반사손실 (Return Loss, RL)

**반사계수를 dB로 표현한 것.** 헷갈리는 점은 이것이다.

>! **함정: 반사손실은 클수록 좋다** — 이름이 "손실"이라 작을수록 좋아 보이지만 반대다. 반사손실 20 dB는 "되돌아온 파가 들어간 파보다 20 dB(100배) 작다"는 뜻이므로 **좋은 것**이다. 반사손실 3 dB는 절반이 되돌아온 것이므로 **나쁜 것**이다.
>!
>! 기억법: **반사"손실"은 반사가 얼마나 손실됐는가**, 즉 반사가 얼마나 약해졌는가로 읽는다.

### VSWR

>> **VSWR (Voltage Standing Wave Ratio, 전압 정재파비)** — 반사 때문에 케이블 위에 생긴 얼룩(정재파)의 최대와 최소의 비율. 1.0이 완벽(반사 없음), 값이 클수록 나쁘다. "브이에스더블유알" 또는 그냥 "스와"라고 읽는 사람도 있다.

### 셋을 한 표로

이 표는 벤치에 붙여두면 좋다.

| VSWR | 반사계수 \|Γ\| | 반사손실 | 반사된 전력 | 평가 |
|---|---|---|---|---|
| 1.0 | 0.00 | ∞ dB | 0 % | 이론적 완벽 |
| 1.2 | 0.09 | 20.8 dB | 0.8 % | 매우 좋음 |
| 1.5 | 0.20 | 14.0 dB | 4 % | 좋음 |
| **2.0** | **0.33** | **9.5 dB** | **11 %** | **일반적인 합격선** |
| 3.0 | 0.50 | 6.0 dB | 25 % | 아슬아슬 |
| 5.0 | 0.67 | 3.5 dB | 44 % | 나쁨 |
| ∞ | 1.00 | 0 dB | 100 % | 개방/단락 (전부 반사) |

> **실무 감각** — 소비자 무선기기의 안테나는 보통 **반사손실 10 dB 이상(VSWR 2.0 이하)** 을 목표로 한다. 10 dB면 전력의 10%만 되돌아온다는 뜻이다. 완벽하진 않지만 실용적으로 충분하다는 합의다.

## 2.4 잡음, SNR, 그리고 −174라는 숫자

### 잡음은 없앨 수 없다

절대영도가 아닌 모든 물체는 열 때문에 미세하게 전기적으로 떨린다. 이 떨림이 **열잡음**이다. 저항 하나만 있어도 잡음이 나온다. 없앨 수 없고, 다만 최소화할 뿐이다.

상온에서 1 Hz 대역폭당 열잡음 전력은 다음과 같다.

`−174 dBm/Hz`

>> **−174 dBm/Hz** — RF에서 가장 자주 인용되는 숫자. "상온에서 1 Hz의 폭을 가진 잡음의 전력"이다. 이보다 조용한 수신기는 물리적으로 만들 수 없다. **RF 세계의 절대영도 같은 기준선**이라고 생각하면 된다.

대역폭이 넓어지면 그만큼 잡음도 더 들어온다.

`잡음 전력(dBm) = −174 + 10 × log10(대역폭 Hz)`

**계산 예: 20 MHz 대역폭의 잡음 전력**

```
  10 x log10(20,000,000) = 10 x 7.301 = 73.0 dB
  잡음 전력 = -174 + 73.0 = -101 dBm
```

즉 20 MHz짜리 Wi-Fi 채널에는 아무 신호가 없어도 항상 약 −101 dBm의 잡음이 깔려 있다. **수신 감도가 −101 dBm보다 좋을 수는 없다**는 물리적 한계를 이 한 줄이 말해준다.

> **도로 비유** — 대역폭은 차선 수, 잡음은 도로 위 먼지다. 차선을 늘리면 더 많은 차(데이터)가 지나가지만, 그만큼 더 많은 먼지도 들어온다. 속도(데이터율)와 깨끗함(잡음)은 맞바꾸는 관계다.

### SNR

>> **SNR (Signal-to-Noise Ratio, 신호 대 잡음비)** — 신호가 잡음보다 몇 dB 큰가. 이 값이 충분히 커야 데이터를 제대로 복원할 수 있다. 시끄러운 카페에서 대화할 때 상대 목소리(신호)가 소음(잡음)보다 얼마나 큰가와 같다.

변조 방식이 복잡할수록 더 높은 SNR이 필요하다. 이것이 신호가 약해지면 통신 속도가 자동으로 떨어지는 이유다.

| 변조 | 대략 필요한 SNR | 비유 |
|---|---|---|
| QPSK | 낮음 | 큰 글씨로 쓴 편지 |
| 16QAM | 중간 | 보통 글씨 |
| 64QAM | 높음 | 작은 글씨 |
| 256QAM | 매우 높음 | 아주 작은 글씨 — 조금만 흐려도 못 읽음 |

## 2.5 손으로 풀어보는 연습 문제

읽기만 해서는 몸에 붙지 않는다. 다섯 문제를 끝까지 계산해보자. 답은 바로 아래에 있으니 가리고 풀어보기를 권한다.

### 문제 1

증폭기 입력에 −10 dBm을 넣었더니 출력이 +15 dBm이었다. 이득은?

```
  이득 = 출력 - 입력 = 15 - (-10) = 25 dB
```

**답: 25 dB.** 여기서 결과가 dBm이 아니라 **dB**임에 주의하자. 두 전력의 비율이기 때문이다.

### 문제 2

DUT 출력을 재는데, 사이에 케이블(1.5 dB 손실)과 감쇠기(20 dB)가 있다. 스펙트럼 분석기가 −5 dBm을 읽었다. DUT의 실제 출력은?

```
  총 손실 = 1.5 + 20 = 21.5 dB
  DUT 출력 = 읽은 값 + 손실 = -5 + 21.5 = +16.5 dBm
```

**답: +16.5 dBm.** 손실은 **더한다**. 잃어버린 만큼 되돌려주는 것이다.

### 문제 3

+20 dBm은 몇 mW인가?

```
  +20 dBm = 0 dBm + 20 dB = 1 mW x 100배 = 100 mW
```

**답: 100 mW (= 0.1 W).**

### 문제 4

2차 하모닉이 기본파보다 45 dB 작게 측정되었다. 기본파가 +23 dBm일 때, 하모닉의 절대 전력은?

```
  하모닉 = 23 - 45 = -22 dBm
  (상대 표기로는 -45 dBc)
```

**답: −22 dBm, 또는 −45 dBc.** 같은 사실을 두 가지 방식으로 말한 것이다.

### 문제 5

수신기의 대역폭이 1 MHz, 잡음지수가 5 dB, 복조에 필요한 SNR이 10 dB다. 이 수신기의 이론적 감도는?

```
  잡음 바닥  = -174 + 10 x log10(1,000,000) = -174 + 60 = -114 dBm
  수신기 잡음 = -114 + 5 (잡음지수)          = -109 dBm
  필요 신호  = -109 + 10 (필요 SNR)         = -99 dBm
```

**답: 약 −99 dBm.** 실제 측정값이 −99 dBm 근처면 정상, −90 dBm밖에 안 나오면 어딘가 9 dB를 잃고 있다는 뜻이다. **이 계산은 감도 시험에서 "이 정도는 나와야 한다"를 판단하는 기준이 되므로 매우 유용하다.**

> **여기까지 왔다면** — RF 실무 대화의 숫자 부분은 이제 거의 다 읽을 수 있다. 나머지는 장비를 익히는 일이다.

# 3. 장비와 친해지기

## 3.1 장비 6종 세트 — 한 줄 요약

벤치에 처음 앉으면 낯선 상자들이 쌓여 있다. 하지만 자주 쓰는 것은 여섯 가지 정도다. 먼저 한 줄씩 정리하자.

| 장비 | 한 줄로 말하면 | 비유 |
|---|---|---|
| **신호 발생기 (SG)** | 원하는 신호를 만들어 준다 | 목소리를 내는 사람 |
| **스펙트럼 분석기 (SA)** | 신호가 어느 주파수에 얼마나 있는지 보여준다 | 소리를 음정별로 분해해 보는 귀 |
| **전력계 (Power Meter)** | 전력의 절대 크기를 정확히 잰다 | 정밀 저울 |
| **VNA** | 부품이 신호를 얼마나 통과시키고 되돌리는지 잰다 | 초음파 검사기 |
| **오실로스코프** | 신호가 시간에 따라 어떻게 변하는지 본다 | 초고속 카메라 |
| **DC 전원** | DUT에 전기를 공급하고 소비 전류를 잰다 | 전기 계량기 달린 콘센트 |

여기에 상황에 따라 **온도 챔버**(냉장고 겸 오븐), **차폐 박스**(전파를 막는 상자), **통신 테스터**(휴대폰 기지국 흉내를 내는 장비)가 추가된다.

## 3.2 하나씩 뜯어보기

### 3.2.1 신호 발생기 (Signal Generator, SG)

**하는 일**: 지정한 주파수와 전력의 신호를 만들어 낸다.

**설정하는 것 세 가지**

| 설정 | 뜻 | 초보자 주의 |
|---|---|---|
| Frequency | 만들 주파수 | 단위(MHz/GHz) 확인 |
| Level (Amplitude) | 만들 전력(dBm) | **표시값과 실제 나오는 값은 다를 수 있다** |
| RF On/Off | 출력 켜기/끄기 | **기본은 Off. 켜는 걸 잊어서 헤매는 일이 흔하다** |

>> **VSG (Vector Signal Generator, 벡터 신호 발생기)** — 그냥 단일 주파수(CW)가 아니라, Wi-Fi나 LTE 같은 **실제 통신 신호를 흉내 내서** 만들어 주는 신호 발생기. 수신 시험에는 이것이 필요하다.

>> **CW (Continuous Wave, 연속파)** — 변조가 없는, 하나의 주파수만 가진 순수한 신호. "씨더블유"라고 읽는다. 가장 단순한 시험 신호이며, 하모닉 측정이나 트림처럼 신호가 단순할수록 좋은 경우에 쓴다.

>! **함정** — SG의 표시 레벨은 **SG 출력 커넥터에서의 값**이다. 케이블을 지나 DUT에 도달할 때는 이미 줄어 있다. 감도 측정처럼 절대 레벨이 중요한 시험에서는 반드시 3.5절의 경로 손실 교정을 해야 한다.

### 3.2.2 스펙트럼 분석기 (Spectrum Analyzer, SA)

**하는 일**: 가로축이 주파수, 세로축이 전력인 그래프를 그려준다. "어느 주파수에 얼마만큼의 신호가 있는가"를 보여준다.

RF 엔지니어가 가장 오래 들여다보는 화면이다.

**설정하는 것**

| 설정 | 뜻 | 쉬운 설명 |
|---|---|---|
| **Center Frequency** | 화면 가운데 주파수 | 어디를 볼 것인가 |
| **Span** | 화면의 좌우 폭 | 얼마나 넓게 볼 것인가 |
| **RBW** (Resolution Bandwidth) | 분해능 대역폭 | **화면의 "화소 크기"**. 작을수록 세밀하지만 느리다 |
| **VBW** (Video Bandwidth) | 비디오 대역폭 | 그래프를 얼마나 매끄럽게 그릴 것인가 |
| **Reference Level** | 화면 맨 위 전력값 | 세로축의 눈금 위치 |
| **Attenuation** | 입력 감쇠 | **장비를 지키는 안전장치.** 3.3절 참조 |

>> **RBW (Resolution Bandwidth, 분해능 대역폭)** — 스펙트럼 분석기가 두 개의 가까운 신호를 구분해낼 수 있는 최소 간격. 카메라의 초점 같은 것이다.
>>
>> **RBW를 줄이면**: 세밀하게 보이고, 화면의 잡음 바닥이 내려가서 작은 신호가 보인다. 대신 **측정 시간이 크게 늘어난다** [6][10].
>> **RBW를 키우면**: 빠르지만 뭉개져 보이고, 잡음 바닥이 올라간다.

> **왜 RBW를 줄이면 잡음 바닥이 내려가나** — 2.4절에서 잡음은 대역폭에 비례한다고 했다. RBW는 곧 "한 번에 들여다보는 대역폭"이다. 좁게 보면 그만큼 잡음도 적게 들어온다. RBW를 1/10로 줄이면 잡음 바닥은 약 10 dB 내려간다 [10].

> **VBW는 감도를 개선하지 않는다** — VBW는 이미 검출된 신호를 매끄럽게 다듬을 뿐이어서, 잡음 바닥 자체를 낮추지도 주파수 분해능을 바꾸지도 않는다. "화면이 지저분하다"와 "작은 신호가 안 보인다"는 다른 문제이고, 후자는 RBW로 푼다 [7].

>> **DANL (Displayed Average Noise Level)** — 스펙트럼 분석기 자신이 만들어내는 잡음의 바닥 수준. 이보다 작은 신호는 장비가 못 본다. "댄엘"이라고 읽는다.

>> **마커 (Marker)** — 화면의 특정 지점에 찍어서 그 지점의 주파수와 전력을 숫자로 읽게 해주는 커서. `Peak Search` 버튼을 누르면 가장 높은 봉우리로 자동으로 간다. 실무에서 제일 많이 쓰는 기능이다.

### 3.2.3 전력계 (Power Meter) 와 전력 센서

**하는 일**: 전력의 절대 크기를 아주 정확하게 잰다.

**스펙트럼 분석기가 있는데 왜 또 필요한가?** 스펙트럼 분석기는 주파수 정보를 주지만, **절대 전력의 정확도는 전력계가 더 좋다.** 전력계는 국가 표준까지 이어지는 교정 체계를 갖고 있어서, 벤치에서 "전력의 기준"으로 쓴다 [1].

| | 스펙트럼 분석기 | 전력계 |
|---|---|---|
| 보여주는 것 | 주파수별 분포 | 총 전력 하나의 숫자 |
| 절대 정확도 | 보통 | **높음** |
| 주파수 선택성 | 있음 | **없음** (들어온 전력 전부를 잰다) |
| 쓰는 상황 | 스펙트럼을 봐야 할 때 | 전력값이 정확해야 할 때 |

>! **전력계는 주파수를 못 가린다** — 전력계는 센서에 들어온 모든 전력을 합쳐서 잰다. 하모닉이나 잡음이 섞여 있어도 다 포함해서 읽는다. "이 주파수의 전력만" 재고 싶으면 필터를 앞에 달거나 스펙트럼 분석기를 써야 한다.

**꼭 해야 하는 두 가지 준비**

1. **제로잉(Zeroing)** — RF를 넣지 않은 상태에서 "지금이 0이다"를 알려주는 영점 조정. 저울에 아무것도 안 올리고 0을 맞추는 것과 같다.
2. **주파수 입력** — 센서의 감도는 주파수마다 조금씩 다르다. 지금 재는 주파수를 알려줘야 전력계가 보정한다.

### 3.2.4 VNA (벡터 회로망 분석기)

>> **VNA (Vector Network Analyzer)** — 부품에 신호를 넣고, **얼마나 통과했고 얼마나 되돌아왔는지**를 크기와 위상까지 함께 재는 장비. "브이엔에이"라고 읽는다. 여기서 "네트워크"는 인터넷이 아니라 **회로망**(부품들의 연결)을 뜻한다.

**하는 일**: 필터, 케이블, 안테나, 스위치 같은 부품이 신호를 어떻게 다루는지 측정한다 [16].

**S-파라미터 읽는 법** — 이름이 무섭지만 규칙은 단순하다.

>> **S-파라미터** — `S21`처럼 숫자 두 개가 붙는다. 읽는 순서는 **"뒤에서 앞으로"** 다.
>>
>> `S21` = **2번 포트로 나온 것 ÷ 1번 포트로 넣은 것** = 통과 특성
>> `S11` = **1번 포트로 되돌아온 것 ÷ 1번 포트로 넣은 것** = 반사 특성

| 표기 | 뜻 | 실무에서 부르는 이름 |
|---|---|---|
| **S11** | 1번 포트의 반사 | 반사손실, 정합 |
| **S21** | 1번 → 2번 통과 | 삽입손실(수동 부품) 또는 이득(증폭기) |
| **S12** | 2번 → 1번 역방향 통과 | 격리도, 역방향 격리 |
| **S22** | 2번 포트의 반사 | 출력 정합 |

**교정(Calibration)이 반드시 먼저다**

VNA는 쓰기 전에 반드시 교정한다. 이유는 이렇다. VNA가 재는 것은 "VNA 포트에서 본 세상"인데, 우리가 알고 싶은 것은 "DUT 자체"다. 그 사이의 케이블과 커넥터의 영향을 수학적으로 걷어내는 작업이 교정이다.

>> **교정 키트 (Cal Kit)** — 특성을 정확히 아는 표준 부품 모음. 보통 **Short(단락), Open(개방), Load(50 Ω 종단), Thru(직결)** 네 가지가 들어 있다. 앞 글자를 따서 **SOLT 교정**이라고 부른다.
>>
>> 원리는 간단하다. **답을 아는 문제 세 개를 풀려서** 장비가 자기 오차를 알아내게 하는 것이다.

>! **교정 후에 바꾸면 안 되는 것** — 교정이 끝난 뒤 **주파수 범위, 포인트 수, 출력 레벨**을 바꾸면 교정이 무효가 된다. 그리고 **케이블을 움직여도** 교정이 흐트러진다. 교정 전에 설정을 확정하고, 교정 후에는 케이블을 고정하자.

### 3.2.5 오실로스코프

**하는 일**: 가로축이 시간, 세로축이 전압인 그래프를 그린다.

스펙트럼 분석기가 "주파수의 세계"를 본다면, 오실로스코프는 "시간의 세계"를 본다. RF 벤치에서는 다음에 쓴다.

- 송신이 켜지고 꺼지는 타이밍
- 제어 신호(스위치를 켜는 신호 등)와 RF의 시간 관계
- 전원 전압이 순간적으로 떨어지는지
- 소비 전류가 시간에 따라 어떻게 변하는지

### 3.2.6 DC 전원

**하는 일**: DUT에 전기를 공급하고, **얼마나 쓰는지 잰다.**

>! **전류 제한(Current Limit)을 반드시 설정하자** — DUT에 문제가 있으면 전류가 폭주해서 부품이 탄다. 정상 소비 전류의 1.5~2배 정도로 제한을 걸어두면, 문제가 생겼을 때 장비가 전압을 낮춰 보호해준다. **전원을 켜기 전에 설정하는 습관**을 들이자.

>> **효율 (Efficiency)** — 넣어준 DC 전력 중 얼마가 RF 출력으로 나왔는가. 배터리 기기에서 매우 중요하다. 그래서 출력 전력을 잴 때는 **거의 항상 소비 전류도 같이 기록한다.**

## 3.3 장비를 태우는 다섯 가지 방법 (그리고 피하는 법)

신입이 실제로 저지르는 사고들이다. 장비 하나가 수천만 원이고, 수리에 몇 주가 걸린다.

| 사고 | 무슨 일이 벌어지나 | 예방법 |
|---|---|---|
| **1. 스펙트럼 분석기에 큰 전력을 바로 넣음** | 입력단이 타서 장비가 망가진다. 조용히 성능만 나빠지는 경우가 더 무섭다 | **항상 감쇠기를 먼저 달고**, 전력계로 크기를 먼저 확인 |
| **2. DC가 섞인 신호를 넣음** | 계측기 입력이 DC에 취약하다 | **DC 블록**을 사용. 바이어스 티나 능동 DUT 출력에서 특히 |
| **3. 전력이 켜진 상태에서 커넥터를 뺌 (핫 스위칭)** | 순간적으로 전부 반사되어 증폭기와 계측기를 동시에 때린다 | **끄고 → 빼고 → 꽂고 → 켠다.** 예외 없음 |
| **4. 안테나 없이(개방 상태로) 송신** | 갈 곳 없는 전력이 전부 되돌아와 PA를 파괴한다 | 출력에는 **항상 부하(안테나 또는 50 Ω 종단)** 를 연결 |
| **5. 정전기(ESD)** | 반도체가 눈에 안 보이게 손상된다. 당장은 동작하다가 나중에 죽는다 | 접지 손목띠 착용, 도전성 매트 위에서 작업 |

> **황금률** — **모르면 감쇠기를 하나 더 달아라.** 감쇠기 때문에 신호가 작아져서 다시 재는 데 드는 시간은 5분이다. 장비를 태우면 몇 주다.

## 3.4 케이블과 커넥터 — 왜 이게 제일 중요한가

경험 있는 엔지니어들이 입을 모아 하는 말이 있다. **"이상한 측정값의 대부분은 DUT가 아니라 접속부 때문이다."**

### 왜 그런가

RF 신호는 아주 작은 불연속에도 반사를 일으킨다(1.3절). 커넥터가 살짝 덜 조여져 있거나, 안에 먼지가 있거나, 핀이 눌려 있으면 그 지점이 50 Ω이 아니게 되고, 반사가 생기고, 측정값이 흔들린다.

### 지켜야 할 것

| 항목 | 방법 | 이유 |
|---|---|---|
| **체결 순서** | 손으로 가볍게 돌려 접촉시킨 뒤, 토크 렌치로 마무리 | 처음부터 세게 조이면 나사산이 상한다 |
| **회전 방향** | **너트만 돌린다. 본체는 잡고 고정.** | 본체를 돌리면 안쪽 도체가 비틀려 망가진다 |
| **토크 값** | SMA/3.5 mm 계열은 보통 **8 in-lb**, N형은 보통 12 in-lb. 커넥터 규격 확인 [9][22] | 너무 약하면 접촉 불량, 너무 세면 변형 |
| **청소** | 순도 100% 이소프로필 알코올 + 무진 스왑. **면봉 금지** | 면봉 섬유가 중심 핀에 걸린다 |
| **점검** | 처음 쓸 때, 이상할 때, 그리고 **약 100회 체결마다** 핀 깊이 측정(게이징) [22] | 핀이 튀어나오면 상대 커넥터를 부순다 |
| **케이블 취급** | 최소 굽힘 반경을 지키고, 교정 후에는 고정 | 굽히면 위상이 변해 교정이 깨진다 [26] |

>> **토크 렌치 (Torque Wrench)** — 정해진 힘에 도달하면 "딸깍" 소리가 나면서 더 이상 조여지지 않는 렌치. RF 커넥터 체결에 반드시 쓴다. 일반 스패너로 감으로 조이면 사람마다 힘이 달라 측정 재현성이 무너진다.

>! **가장 흔한 신입 실수** — 커넥터를 손으로만 조인다. 그러면 잴 때마다 값이 0.3~1 dB씩 달라진다. 그런데 이 사람은 DUT를 의심하며 몇 시간을 보낸다. **재현성이 의심되면 커넥터를 5번 다시 조이며 재보라.** 값이 흔들리면 DUT 문제가 아니다.

## 3.5 경로 손실 교정 — 이것만은 몸에 붙여야 한다

### 문제 상황

DUT의 출력을 재려고 한다. 그런데 DUT와 스펙트럼 분석기 사이에는 케이블이 있고, 감쇠기가 있고, 어댑터가 있다. 이것들이 신호를 조금씩 잡아먹는다. 분석기가 읽은 값은 **DUT의 출력이 아니라 "여기까지 살아남은 것"** 이다.

```
   DUT  --[케이블 1.2 dB]--[감쇠기 20 dB]--[어댑터 0.3 dB]--> 스펙트럼 분석기
   +16.5 dBm                                                     -5.0 dBm 표시
        <------------------ 총 21.5 dB 손실 ------------------>
```

### 해결 방법

**"DUT를 빼고, 그 자리를 직접 연결해서, 얼마나 잃는지 먼저 재둔다."**

이것이 전부다. 어렵지 않다.

### 단계별 절차

1. **DUT를 빼고**, DUT가 있던 자리의 양쪽 커넥터를 서로 직접 연결한다(Thru 연결).
2. 그 상태에서 손실을 잰다.
   - 방법 A: VNA로 `S21`을 측정한다. 주파수별 손실을 한 번에 얻는다. (권장)
   - 방법 B: 신호 발생기로 알려진 전력을 넣고, 반대쪽에서 전력계로 받아 차이를 계산한다.
3. 측정할 모든 주파수에 대해 손실값 표를 만든다. **손실은 주파수마다 다르다** — 높은 주파수일수록 케이블 손실이 크다.
4. 이 표를 측정 프로그램의 보정값으로 넣거나, 장비의 오프셋 기능에 입력한다.
5. **검증한다.** 알려진 신호를 넣어서 보정 후 값이 기댓값과 맞는지 확인한다. 이 단계를 건너뛰면 부호를 반대로 넣은 실수(더할 걸 뺐다)를 못 잡는다.

>! **부호 실수는 정말 자주 일어난다** — 손실 21.5 dB를 잘못 적용하면 43 dB가 틀린다(21.5의 두 배). 결과가 상식적으로 말이 안 되게 크거나 작으면 부호부터 의심하자.

### 언제 다시 해야 하나

- 케이블이나 감쇠기를 교체했을 때
- 케이블을 옮기거나 다른 경로로 바꿨을 때
- 픽스처를 교체했을 때
- 주기적으로 (많은 현장에서 매 근무조 시작 시 또는 주 1회)

> **왜 이렇게 강조하나** — 이 문서에서 다루는 거의 모든 측정이 경로 손실 교정 위에 서 있다. 출력 전력도, 하모닉의 절대값도, 수신 감도도 전부. **교정이 1 dB 틀리면 모든 결과가 1 dB 틀린다.** 신입이 가장 먼저, 그리고 가장 확실하게 익혀야 할 기술이다.

## 3.6 차폐 박스는 왜 필요한가

수신 감도를 잴 때는 −100 dBm 같은 아주 약한 신호를 다룬다. 그런데 실험실 공기 중에는 Wi-Fi, 휴대폰, 블루투스 신호가 가득하다. 이것들이 DUT에 들어가면 측정이 오염된다.

>> **차폐 박스 (Shield Box)** — 금속으로 만든, 전파가 드나들 수 없는 상자. 안쪽에 전파 흡수체를 붙이면 상자 내부의 반사까지 줄어 측정 재현성이 좋아진다.

**간단한 누설 확인법** — 박스를 닫고 신호 발생기를 **끈** 상태에서 DUT가 패킷을 받는지 본다. 받으면 어딘가 새고 있는 것이다. 뚜껑, 케이블 관통부, 접지가 흔한 원인이다.

## 4.1 출력 전력 (Output Power)

**한 줄로 말하면** — 송신기가 규격대로 세게 보내고 있는가.

### 왜 재는가

너무 약하면 통신 거리가 안 나오고, 너무 세면 배터리를 낭비하고 법적 한계를 넘는다. **모든 송신 시험의 출발점**이며, 다른 시험들도 대부분 "최대 출력 상태에서" 수행하므로 이 값이 먼저 확정되어야 한다.

### 어떻게 재는가

```
   DUT --[ATT]--> POWER METER     (정확한 절대값이 필요할 때)
   DUT --[ATT]--> SPECTRUM ANALYZER  (스펙트럼도 함께 보고 싶을 때)
```

1. 경로 손실 교정을 먼저 한다(3.5절). **이것 없이는 의미 없는 숫자가 나온다.**
2. 전력계를 제로잉하고 측정 주파수를 입력한다.
3. DUT를 원하는 채널·전력 설정으로 송신시킨다.
4. 값이 안정될 때까지 기다린 뒤 읽는다.
5. 낮은/중간/높은 채널에서 반복한다.

>> **채널 (Channel)** — 통신 표준이 미리 나눠놓은 주파수 칸. 예를 들어 2.4 GHz Wi-Fi는 1번~13번 채널이 있다. 시험은 보통 **저·중·고 세 채널**에서 한다. 전 채널을 다 하기엔 시간이 너무 걸리고, 양 끝과 가운데가 최악 조건인 경우가 많기 때문이다.

### 숫자 읽는 법

`DUT 출력(dBm) = 계측기 읽은 값(dBm) + 경로 손실(dB)`

2.5절 문제 2를 다시 보면 좋다.

### 처음 하는 사람이 틀리는 곳

>! **① 안정화를 기다리지 않는다** — 송신을 켜면 증폭기가 뜨거워지면서 출력이 몇 초에서 수십 초 사이에 조금씩 변한다. **언제 읽을 것인지를 정해두고 매번 같게** 해야 한다. 어떤 날은 3초, 어떤 날은 30초에 읽으면 데이터가 흔들린다.
>!
>! **② 변조 신호를 CW용 방식으로 잰다** — Wi-Fi나 LTE처럼 순간순간 세기가 변하는 신호는 평균 전력을 제대로 재는 센서나 설정이 필요하다. 잘못된 센서로 재면 값이 체계적으로 틀어진다 [18].
>!
>! **③ 감쇠기 값을 보정에 안 넣는다** — 20 dB 감쇠기를 달아놓고 보정을 잊으면 결과가 20 dB 틀린다. 100배 차이다.

**상세판 대응**: 4.3절

## 4.2 주파수 정확도와 Trim

**한 줄로 말하면** — 신호가 정확히 약속된 주파수에 있는가. 그리고 개체마다 다른 오차를 보정해 넣는 작업이 Trim이다.

### 왜 재는가

송신기와 수신기가 서로 다른 주파수를 보고 있으면 통신이 안 된다. 라디오 주파수를 살짝 잘못 맞추면 잡음만 들리는 것과 같다.

그런데 주파수를 만드는 부품(**수정 진동자**)은 개체마다 미세하게 다르다. 같은 부품을 사도 하나는 조금 빠르고 하나는 조금 느리다. 부품값을 더 정밀하게 만들면 비싸진다. 그래서 **싼 부품을 쓰고, 공장에서 개체마다 보정값을 넣어주는** 방식을 쓴다. 이것이 Trim이다.

>> **Trim (트림)** — 개체마다 다른 오차를 **측정해서, 보정값을 계산해서, 제품 안의 메모리에 기록하는** 작업. 제품이 스스로 자기 오차를 알고 보정하게 만드는 것이다.
>>
>> **불량을 골라내는 시험이 아니라, 제품을 규격 안으로 만들어 넣는 공정**이라는 점에서 다른 시험과 성격이 다르다.

>> **ppm (parts per million, 백만분율)** — 100만분의 1. 주파수 오차를 표현할 때 쓴다. 2.4 GHz에서 1 ppm은 2,400 Hz다. 오차를 절대값(Hz)이 아니라 비율(ppm)로 말하는 이유는, 주파수가 높아지면 같은 비율이라도 절대 오차가 커지기 때문이다.

>> **수정 진동자 (Crystal, XO)** — 일정한 주파수로 진동하는 수정 조각. 모든 무선기기의 "시계" 역할을 한다. 온도 보상 기능이 있는 것을 **TCXO**라고 부른다.

### 어떻게 재는가

```
   DUT --[ATT]--> SPECTRUM ANALYZER / FREQUENCY COUNTER
                  (10 MHz 기준 클럭을 정확한 기준원에 물려둘 것)
```

1. DUT를 시험 모드로 만들어 **무변조 신호(CW)** 를 내보내게 한다.
2. 실제 주파수를 잰다.
3. 목표 대비 오차를 ppm으로 환산한다.
4. 보정 코드를 조정한다. (내부 커패시터 값을 바꿔 수정의 진동 속도를 미세하게 당기거나 늦춘다)
5. 오차가 목표 범위에 들어올 때까지 3~4를 반복한다.
6. 최종 코드를 메모리에 저장한다.
7. **리셋한 뒤 다시 읽어서** 값이 제대로 들어갔는지 확인하고, 주파수를 재측정한다.

**계산 예: ppm 환산**

```
  목표 주파수 : 2,440,000,000 Hz (2.44 GHz)
  측정 주파수 : 2,440,004,880 Hz
  오차        : 4,880 Hz

  ppm = 4,880 / 2,440,000,000 x 1,000,000 = 2.0 ppm
```

### 숫자 읽는 법

Trim 후 보통 **수 ppm 이내**(예: ±2~3 ppm)로 맞춘다. 이를 재려면 계측기 자체의 주파수 정확도가 **±0.5 ppm 수준**은 되어야 한다 [37].

>> **10 MHz 기준 클럭 (Reference Clock)** — 모든 RF 계측기 뒤에는 `10 MHz REF IN/OUT` 단자가 있다. 여기를 케이블로 서로 연결하면 모든 장비가 같은 시계를 쓰게 된다. **주파수를 재는 시험에서는 필수다.** 자기 시계가 틀린 사람이 남의 시계를 검사할 수는 없다.

### 처음 하는 사람이 틀리는 곳

>! **① 수정 부품에 오실로스코프 프로브를 직접 댄다** — 프로브 자체가 용량을 더해서 발진 주파수를 바꿔버린다. 재는 행위가 대상을 바꾸는 것이다. **클럭 출력 핀이나 RF 신호로 재야 한다** [37].
>!
>! **② 저장 후 검증을 건너뛴다** — 메모리에 썼다고 적용된 것이 아니다. 리셋 후 다시 읽어 확인해야 한다. 이 단계를 빼먹으면 "공장에서는 통과했는데 필드에서 다 불량"인 사고가 난다.
>!
>! **③ 장비 예열을 안 한다** — 계측기의 기준 발진기도 켜자마자는 정확하지 않다. 제조사가 권하는 예열 시간(보통 30분 이상)을 지키자.

**상세판 대응**: 4.1절

## 4.3 하모닉 (Harmonics)

**한 줄로 말하면** — 내가 쓰는 주파수의 정수 배(2배, 3배…)에 원치 않는 신호가 얼마나 나오는가.

### 왜 생기는가

증폭기는 이상적으로는 신호를 그대로 키워야 하지만, 실제로는 완벽히 비례하지 않는다(**비선형성**). 세게 밀면 파형의 꼭대기가 눌린다. 눌린 파형은 원래 주파수만으로는 표현할 수 없고, **2배, 3배 주파수 성분이 저절로 생겨난다.**

> **음악 비유** — 스피커 볼륨을 너무 올리면 소리가 찢어진다. 이때 원래 음에 없던 배음이 생겨 듣기 싫어진다. 하모닉이 정확히 그 현상이다.

>> **하모닉 (Harmonic, 고조파)** — 기본 주파수(f0)의 정수 배 주파수 성분. 2f0을 2차 하모닉, 3f0을 3차 하모닉이라 한다. 2.4 GHz로 송신하면 4.8 GHz, 7.2 GHz에 원치 않는 신호가 새어 나온다.

### 왜 재는가

- **법적 요구사항.** 4.8 GHz는 다른 서비스가 쓰는 대역일 수 있다. 정부 규제 한계를 넘으면 제품 판매 허가가 안 난다 [32][47].
- 내 기기 안의 다른 수신기를 방해할 수 있다.

### 어떻게 재는가 — 여기에 중요한 요령이 있다

```
   DUT --> [ATT] --> [HPF or NOTCH : fundamental reject] --> SPECTRUM ANALYZER
```

**왜 필터를 다는가?** 이것이 하모닉 측정의 핵심이다.

기본파는 아주 세고 하모닉은 아주 약하다. 이 둘을 같이 스펙트럼 분석기에 넣으면, **분석기 내부의 회로가 강한 기본파에 눌려서 스스로 하모닉을 만들어낸다.** 그러면 우리는 DUT의 하모닉이 아니라 **분석기의 하모닉을 보게 된다.**

그래서 기본파만 막아주는 필터(HPF 또는 노치 필터)를 앞에 달아, 분석기에는 하모닉만 들어가게 한다.

>> **HPF (High Pass Filter, 고역통과 필터)** — 높은 주파수만 통과시키고 낮은 주파수는 막는 필터. 기본파(낮음)를 막고 하모닉(높음)을 통과시킨다.
>>
>> **LPF (Low Pass Filter, 저역통과 필터)** — 반대로 낮은 주파수만 통과. 하모닉 측정에서는 **신호 발생기 쪽에** 달아서, 발생기 자체의 하모닉이 DUT로 들어가는 것을 막는 데 쓴다.
>>
>> 두 필터의 **용도가 정반대**이니 혼동하지 말자.

>! **필터의 손실을 보정해야 한다** — 필터도 통과 대역에서 얼마간 손실이 있다. 이 손실을 VNA로 미리 재두고 결과에 더해줘야 한다. 안 하면 하모닉을 실제보다 작게 보고한다.

### 진짜인지 가짜인지 판별하는 법 — 반드시 익힐 것

화면에 하모닉이 보인다. 이게 DUT 것인가, 분석기가 만든 것인가?

> **판별 절차**
> 1. 스펙트럼 분석기의 **입력 감쇠(Attenuation)를 10 dB 올린다.**
> 2. 화면의 하모닉 레벨(dBm)을 다시 본다.
>
> **결과 해석**
> - 값이 **그대로** → DUT의 진짜 하모닉이다.
> - 값이 **내려갔다** (2차는 약 10 dB, 3차는 약 20 dB) → **분석기가 만든 가짜다.** 감쇠를 더 올리거나 필터를 써야 한다.

이 방법 하나만 알아도 초보자가 가장 자주 하는 오측정을 막을 수 있다.

### 숫자 읽는 법

두 가지 방식으로 표현한다.

- **dBc**: 기본파보다 몇 dB 작은가 (설계 품질 지표)
- **dBm**: 절대 전력 (법규 한계와 직접 비교)

**계산 예**

```
  기본파      : +23.0 dBm
  2차 하모닉  : -22.0 dBm
  상대값      : -22.0 - 23.0 = -45 dBc
```

### 처음 하는 사람이 틀리는 곳

>! ① 필터 없이 측정하고 "하모닉이 심하다"고 보고한다 (사실은 분석기 왜곡)
>! ② 필터 손실 보정을 잊는다
>! ③ 최대 출력이 아닌 상태에서 측정한다 — **하모닉은 보통 최대 출력에서 가장 나쁘다.** 최악 조건에서 재야 한다
>! ④ 낮은 채널만 재고 끝낸다 — 채널마다 다르다

**상세판 대응**: 4.5절

## 4.4 스퓨리어스 (Spurious Emission)

**한 줄로 말하면** — 하모닉을 포함해, **내가 쓰기로 한 대역 밖으로 새어 나가는 모든 신호**.

### 하모닉과의 관계

하모닉은 스퓨리어스의 **한 종류**다. 스퓨리어스에는 하모닉 외에도 이런 것들이 포함된다.

| 종류 | 어디서 오나 |
|---|---|
| 하모닉 | 증폭기 비선형성 |
| 믹서 산물 | 믹서에서 주파수를 올릴 때 생기는 부산물 |
| 클럭 하모닉 | 보드 위 디지털 회로의 클럭이 새어나옴 |
| LO 누설 | 국부 발진기 신호가 출력으로 흘러나옴 |
| 전원 스위칭 산물 | DC-DC 컨버터가 만드는 성분 |

### 어떻게 재는가

원리는 하모닉과 같지만 **범위가 훨씬 넓다.** 예를 들어 30 MHz부터 최고 기본 주파수의 10배(또는 40 GHz)까지 전 구간을 훑는다 [32].

구간이 넓어서 한 번에 못 보므로, 여러 구간으로 나눠 순차적으로 스윕한다. 봉우리가 발견되면 그 지점만 좁게 확대해서 정확히 잰다.

> **필요 조건** — 스펙트럼 분석기의 잡음 바닥이 **규제 한계선보다 최소 6~10 dB 아래**에 있어야 판정이 가능하다. 잡음에 묻혀 안 보이는 것을 "없다"고 할 수는 없기 때문이다.

>> **전도(Conducted) 측정과 방사(Radiated) 측정**
>>
>> - **전도 측정**: 안테나 커넥터에 케이블을 직접 연결해서 잰다. 간단하고 재현성이 좋다.
>> - **방사 측정**: 안테나가 실제로 공중에 뿌리는 것을 **무향실**(전파가 반사되지 않도록 벽면 전체에 흡수체를 붙인 방, 4.16절)에서 잰다. 케이스 틈이나 케이블로 새는 것까지 잡아낸다. 시간과 비용이 많이 든다.
>>
>> 사내에서는 전도 측정으로 걸러내고, 최종 인증은 공인 시험소의 방사 측정으로 한다.

### 처음 하는 사람이 틀리는 곳

>! ① **송신 안 할 때는 안 재고 끝낸다** — 대기 상태나 수신 상태에서도 LO 누설 등이 나올 수 있다. 규격에서 따로 요구하는 경우가 많다.
>! ② 프리앰프를 켜놓고 최대 입력을 초과시킨다 — 프리앰프를 켜면 감도는 좋아지지만 견딜 수 있는 최대 입력이 낮아진다.

**상세판 대응**: 4.6절

## 4.5 이득과 압축 (Gain, P1dB)

**한 줄로 말하면** — 증폭기가 얼마나 키워주는가, 그리고 어디까지 키울 수 있는가.

### 이득 (Gain)

```
  이득(dB) = 출력(dBm) - 입력(dBm)
```

단순하다. 넣은 것보다 얼마나 커져 나왔는가.

### 압축 (Compression)

증폭기는 무한정 키울 수 없다. 입력을 계속 올리면 어느 순간부터 출력이 비례해서 안 늘어난다. **한계에 부딪히는 것**이다.

> **비유** — 수도꼭지를 계속 돌리면 물이 더 나오지만, 어느 지점부터는 아무리 돌려도 더 안 나온다. 배관의 한계다.

>> **P1dB (1 dB 압축점)** — 이득이 원래(작은 신호일 때) 값보다 **1 dB 떨어지는 지점의 출력 전력**. "증폭기가 편안하게 낼 수 있는 최대치"의 실용적 기준으로 쓴다. "피원디비"라고 읽는다.

### 왜 중요한가

압축 영역에서 동작하면 신호가 일그러진다. 그러면 다음이 동시에 나빠진다.

- 하모닉이 늘어난다 (4.3절)
- 인접 채널로 신호가 번진다 (4.7절 ACLR)
- 변조 품질이 떨어진다 (4.8절 EVM)

**즉, P1dB를 알아야 "어디까지 밀어도 되는지"를 안다.**

### 어떻게 재는가

```
   SG --[ATT]--> DUT --[ATT]--> POWER METER or SA
```

1. 경로 손실 교정.
2. 아주 작은 입력(예: −20 dBm)에서 이득을 잰다. 이것이 **소신호 이득**.
3. 입력을 **1 dB씩** 올리며 매번 출력을 기록한다.
4. 이득이 떨어지기 시작하면 0.25~0.5 dB로 더 잘게 올린다.
5. 이득이 소신호 이득보다 1 dB 낮아진 지점의 **출력**이 P1dB다.

**계산 예**

```
  소신호 이득 : 25.0 dB  (입력 -20 dBm -> 출력 +5.0 dBm)

  입력 -2 dBm -> 출력 +22.6 dBm -> 이득 24.6 dB  (0.4 dB 압축)
  입력  0 dBm -> 출력 +24.0 dBm -> 이득 24.0 dB  (1.0 dB 압축)  <-- 여기
  입력 +2 dBm -> 출력 +25.1 dBm -> 이득 23.1 dB  (1.9 dB 압축)

  => P1dB = +24.0 dBm (출력 기준)
```

### 처음 하는 사람이 틀리는 곳

>! **① 소신호 이득을 이미 압축된 지점에서 잰다** — 시작 입력이 너무 크면 기준 자체가 낮게 잡혀서 P1dB가 실제보다 높게 나온다. 충분히 낮은 입력에서 시작하자.
>! **② 계측기가 먼저 압축된다** — 출력이 커지면서 스펙트럼 분석기가 먼저 눌린다. 그러면 DUT가 압축된 것으로 오해한다. **출력 쪽 감쇠기를 충분히** 넣자.
>! **③ 자기가열을 무시한다** — 계속 세게 밀면 증폭기가 뜨거워져 성능이 변한다. 입력을 올리며 잰 곡선과 내리며 잰 곡선이 다르면 열 때문이다.

**상세판 대응**: 4.4절

## 4.6 상호변조 왜곡 (IMD, IP3)

**한 줄로 말하면** — 신호가 **두 개 이상** 동시에 들어왔을 때, 그 둘이 섞여서 생기는 엉뚱한 신호.

### 왜 하모닉과 따로 보나

하모닉은 필터로 지우기 쉽다. 2배, 3배 주파수는 원래 신호에서 멀리 떨어져 있기 때문이다.

그런데 두 신호 f1, f2가 동시에 들어오면 `2f1 − f2` 와 `2f2 − f1` 이라는 성분이 생기는데, 이것들은 **원래 신호 바로 옆에 떨어진다.** 필터로 못 지운다. 그래서 훨씬 골치 아프다.

**숫자로 보자.**

```
  f1 = 2400 MHz,  f2 = 2405 MHz  (5 MHz 떨어진 두 신호)

  3차 상호변조 성분:
    2 x 2400 - 2405 = 2395 MHz   <- f1 바로 왼쪽 5 MHz
    2 x 2405 - 2400 = 2410 MHz   <- f2 바로 오른쪽 5 MHz
```

원래 신호 양옆에 딱 붙어서 나타난다. 필터로 지우려면 원래 신호까지 지워진다.

>> **IMD (Intermodulation Distortion, 상호변조 왜곡)** — 두 개 이상의 신호가 비선형 소자를 함께 지날 때 서로 섞여 생기는 새로운 주파수 성분.
>>
>> **IP3 (Third-order Intercept Point, 3차 차단점)** — 소자의 선형성을 나타내는 **가상의** 전력값. 실제로 그 전력을 낼 수 있다는 뜻이 아니라, "이 소자가 얼마나 선형적인가"를 하나의 숫자로 비교하기 위한 지표다. **높을수록 좋다.** 입력 기준은 IIP3, 출력 기준은 OIP3.

### 어떻게 재는가

```
  SG1 --[BPF]--[PAD/ISOLATOR]--+
                               +--[COMBINER]--> DUT --[ATT]--> SA
  SG2 --[BPF]--[PAD/ISOLATOR]--+
```

두 대의 신호 발생기로 주파수가 조금 다른 두 신호(**투 톤**)를 만들어 합쳐서 넣는다.

`IIP3(dBm) = 입력 전력(dBm) + ΔP(dB) / 2`
(ΔP = 기본파와 3차 성분의 dB 차이)

**계산 예**

```
  각 톤의 입력 : -20 dBm
  화면에서 기본파 : -20 dBm, 3차 성분 : -70 dBm
  차이 (delta P)  : 50 dB

  IIP3 = -20 + 50/2 = -20 + 25 = +5 dBm
```

### 처음 하는 사람이 틀리는 곳

이 시험은 셋업 실수가 결과를 통째로 망친다. 응용 노트가 지적하는 두 가지가 대표적이다 [24].

>! **① 두 신호 발생기 사이의 격리 부족** — 한쪽 SG의 출력이 다른 SG 안으로 역류하면, **SG 내부에서** 상호변조가 생긴다. 그러면 DUT가 아니라 SG를 측정하게 된다. 각 SG 뒤에 6~10 dB 패드나 아이솔레이터를 넣자. 격리가 부족하면 **최대 20 dB까지 틀릴 수 있다** [24].
>!
>! **② 신호원의 하모닉/잡음을 안 막는다** — 각 경로에 대역통과 필터를 넣는다.
>!
>! **③ 측정계 자체를 검증 안 한다** — **DUT를 빼고 같은 셋업으로 재보라.** 이때 나오는 3차 성분이 DUT 측정값보다 최소 10 dB 낮아야 신뢰할 수 있다.
>!
>! **④ 기울기 확인을 안 한다** — 입력을 1 dB 올리면 3차 성분은 **3 dB** 올라가야 한다. 기울기가 3이 아니면 뭔가 잘못된 것이다(이미 압축됐거나 측정계 왜곡).

**상세판 대응**: 4.7절

## 4.7 ACLR (인접 채널 누설비)

**한 줄로 말하면** — 내 신호가 **옆 채널로 얼마나 번져 나가는가.**

### 왜 재는가

주파수는 여러 사업자와 기기가 나눠 쓴다. 내 신호가 옆 채널로 새면 옆집 통신을 방해한다. **아파트 층간소음 같은 것**이다.

> **비유** — 형광펜으로 한 칸에 색칠했는데 잉크가 번져서 옆 칸까지 물들었다. 얼마나 번졌는가를 재는 것이 ACLR이다.

>> **ACLR (Adjacent Channel Leakage Ratio, 인접 채널 누설비)** — 내 채널의 전력 대비, 옆 채널에 새어 나간 전력의 비율(dBc). ACPR이라고도 한다. **음수로 나오고, 절대값이 클수록 좋다.** 예: −45 dBc가 −35 dBc보다 좋다.

### 왜 번지는가

주된 원인은 **증폭기의 압축**이다(4.5절). 세게 밀수록 파형이 일그러지고, 일그러진 파형은 원래 대역 밖으로 스펙트럼이 퍼진다. 이를 **스펙트럼 재성장(spectral regrowth)** 이라 한다.

즉 **출력을 키우면 ACLR이 나빠진다.** 이 맞바꿈이 송신기 설계의 핵심 고민이다.

### 어떻게 재는가

1. 스펙트럼/신호 분석기에서 해당 통신 표준의 ACLR 측정 기능을 선택한다. (표준마다 재는 대역폭과 오프셋이 정해져 있으므로 **직접 만들지 말고 표준 측정 기능을 쓴다** [14])
2. DUT를 규정된 신호로 최대 전력 송신시킨다.
3. 위·아래 인접 채널의 값을 읽는다.

### 처음 하는 사람이 틀리는 곳

>! **분석기 자신의 성능이 DUT보다 나쁘면 측정이 무의미하다.** 확인법: **입력 감쇠를 5~10 dB 바꿔본다.** ACLR 값이 따라 변하면 분석기의 왜곡이 섞인 것이다. 값이 그대로여야 DUT를 재고 있는 것이다.

**상세판 대응**: 4.8절

## 4.8 EVM (변조 정확도)

**한 줄로 말하면** — 보낸 신호가 **얼마나 정확한 모양인가.** 신호 품질의 종합 성적표.

### 성상도부터 이해하자

디지털 통신은 정보를 신호의 **위상과 크기 조합**에 실어 보낸다. 이 조합들을 평면에 점으로 찍은 그림이 **성상도**다.

>> **성상도 (Constellation Diagram, 컨스털레이션)** — 보낼 수 있는 신호 상태들을 평면 위의 점으로 표시한 그림. 별자리처럼 보여서 붙은 이름이다. 예를 들어 QPSK는 점이 4개, 16QAM은 16개, 256QAM은 256개다.
>>
>> **점이 많을수록** 한 번에 더 많은 정보를 보내지만, 점 사이가 촘촘해져서 **조금만 흐트러져도 옆 점과 헷갈린다.**

>> **EVM (Error Vector Magnitude, 오차 벡터 크기)** — 받은 점이 있어야 할 자리에서 **얼마나 벗어났는가**를 백분율(%) 또는 dB로 나타낸 값. **작을수록 좋다** [13][28].
>>
>> 과녁에 화살을 쐈을 때 정중앙에서 벗어난 거리라고 생각하면 된다.

### 왜 EVM이 유용한가

**EVM은 거의 모든 문제에 반응한다.** 잡음, 압축, 위상잡음, I/Q 불균형, 주파수 오차 — 무엇이 나빠지든 EVM이 나빠진다. 그래서 "일단 EVM을 재본다"가 좋은 출발점이 된다.

그리고 **성상도의 모양이 원인을 알려준다.** 이 표가 EVM 디버깅의 핵심이다.

| 성상도에서 보이는 모습 | 의심할 원인 |
|---|---|
| 점들이 사방으로 고르게 퍼짐 | 잡음이 많음 (SNR 부족) |
| 점들이 **원을 그리며 번짐** | 위상잡음 |
| 성상도 전체가 **한쪽으로 밀려남** | LO 누설 / DC 오프셋 |
| 성상도가 **찌그러진 타원** | I/Q 불균형 |
| **바깥쪽 점만** 안으로 말리고 돌아감 | 증폭기 압축 |
| 성상도가 **천천히 회전** | 주파수 오차 |

> **이 표를 외워두면** 성상도 한 장만 보고도 어디를 봐야 할지 방향을 잡을 수 있다. 상세판 4.9.2절에 같은 내용이 있다.

### 처음 하는 사람이 틀리는 곳

>! **입력 레벨을 최적화하지 않는다** — 분석기에 들어가는 신호가 **너무 크면 분석기가 눌려서**, **너무 작으면 잡음 때문에** EVM이 나빠진다. DUT는 멀쩡한데 측정 때문에 나쁘게 나오는 것이다.
>!
>! **해결법**: 입력 감쇠를 ±5 dB씩 바꿔가며 EVM이 가장 좋게 나오는 지점을 찾는다. 이것을 **레벨 스윕**이라 하며, 습관으로 만들자.

**상세판 대응**: 4.9절

## 4.9 수신 감도 (Sensitivity)

**한 줄로 말하면** — 얼마나 **약한 신호까지** 받아낼 수 있는가.

### 왜 중요한가

감도가 통신 거리를 결정한다. 감도가 3 dB 좋아지면 이론적으로 통신 거리는 약 1.4배 늘어난다. 사용자가 체감하는 "이 제품은 잘 터진다"의 실체다.

### 어떻게 정의하는가

"약한 신호를 받는다"는 말을 숫자로 만들려면 **합격 기준**이 필요하다. 표준마다 다르다.

>> **BER (Bit Error Rate, 비트 오류율)** — 보낸 비트 중 몇 개가 틀렸는가. 0.1%면 1000개 중 1개가 틀렸다는 뜻.
>>
>> **PER (Packet Error Rate, 패킷 오류율)** — 보낸 패킷(데이터 묶음) 중 몇 개가 실패했는가.
>>
>> **처리율 (Throughput)** — 실제로 전달된 데이터의 양. LTE나 5G는 "최대 처리율의 95% 이상"을 기준으로 감도를 정의한다 [49].

| 표준 계열 | 합격 기준 |
|---|---|
| GSM / W-CDMA | BER (예: 0.1%) [49] |
| LTE / 5G NR | **최대 처리율의 95%** [49] |
| Bluetooth | BER 또는 PER (릴리스별 시험 규격에 정의) [39][58] |
| 자체 프로토콜 / IoT | PER (예: 1% 또는 10%) |

### 어떻게 재는가

```
  VSG (wanted signal) --[ATT]--> DUT ANTENNA PORT
                                    (전체를 차폐 박스 안에)

  DUT <--- UART / USB ---> PC   (패킷 카운터, 시험 모드 제어)
```

1. **경로 손실 교정을 정확히 한다.** 감도 측정의 정확도가 여기서 결정된다.
2. DUT를 수신 시험 모드로 진입시킨다. (패킷 수신 개수를 세고 리셋할 수 있어야 한다)
3. 신호 발생기로 충분히 큰 레벨을 보내 정상 수신을 확인한다. (연결 확인)
4. 레벨을 1 dB씩 낮추며 오류율을 관찰한다.
5. 합격 기준을 막 넘어서는 지점을 찾는다. 근처에서는 0.2~0.5 dB로 잘게 조정한다.
6. 각 레벨에서 **충분히 많은 패킷**을 보낸다.

>> **왜 패킷을 많이 보내야 하나** — PER 1%를 판정하려면 최소 수천 개의 패킷이 필요하다. 100개만 보내면 오류가 1개 나와도 "1%"고 0개 나와도 "0%"라 구분이 안 된다. 경험칙으로 **목표 오류율의 역수의 10~100배**를 보낸다. (1% 판정이면 1,000~10,000개)

### 결과가 맞는지 확인하는 법

2.5절 문제 5에서 배운 계산을 쓴다.

```
  이론 감도 = -174 + 10 x log10(대역폭) + 잡음지수 + 필요 SNR
```

측정값이 이 계산과 몇 dB 안에서 일치하면 정상이다. 크게 나쁘면 어딘가 문제가 있다.

### 처음 하는 사람이 틀리는 곳

감도 측정은 **틀리기 가장 쉬운 시험**이다. 순서대로 확인하자.

>! **① 경로 손실 보정 오류** — 가장 흔하다. 0.5 dB 틀리면 결과가 0.5 dB 틀린다.
>!
>! **② 차폐 누설** — 확인법: **박스를 닫고 신호 발생기를 끈 상태**에서 DUT가 패킷을 받는지 본다. 받으면 새고 있는 것이다.
>!
>! **③ 신호 발생기의 잡음** — SG는 원하는 신호만 내지 않는다. 넓은 대역에 걸쳐 미세한 잡음도 함께 낸다. 이 잡음이 수신 대역에 떨어지면 DUT가 아니라 SG 때문에 감도가 나빠진다. SG 출력을 스펙트럼 분석기로 확인해보자.
>!
>! **④ 신호 발생기를 너무 낮은 출력으로 쓴다** — SG는 아주 낮은 출력에서 정확도가 떨어진다. **고정 감쇠기를 넣어서 SG는 비교적 높은 출력으로 동작**시키는 것이 정확하다. 예: DUT에 −100 dBm을 주고 싶으면 SG를 −40 dBm으로 두고 60 dB 감쇠기를 쓴다.

**상세판 대응**: 4.10.2절

## 4.10 잡음지수 (Noise Figure, NF)

**한 줄로 말하면** — 이 부품이 신호를 지나가게 하면서 **잡음을 얼마나 더 보태는가.**

### 왜 중요한가

1.4절에서 봤듯, 수신기 성능은 맨 앞단이 결정한다. **앞에서 더해진 잡음은 뒤에서 절대 못 지운다.** 잡음지수는 이 "잡음을 얼마나 보태는가"를 재는 지표다.

> **비유** — 복사기로 문서를 복사할 때마다 조금씩 흐려진다. 잡음지수는 "이 복사기가 한 번 복사할 때 얼마나 흐려지는가"다. 첫 번째 복사기가 많이 흐리게 만들면, 그 뒤에 아무리 좋은 복사기를 놓아도 원본은 못 돌아온다.

>> **잡음지수 (NF)** — 입력의 SNR과 출력의 SNR의 비를 dB로 나타낸 것. **0 dB가 이론적 완벽**(잡음을 전혀 안 더함)이고, 값이 작을수록 좋다. 좋은 LNA는 1~2 dB, 일반적인 수신 경로 전체는 3~8 dB 정도다.

### 어떻게 재는가 — Y-factor 법

가장 널리 쓰이는 방법이다 [2][3].

>> **잡음원 (Noise Source)** — 켜면 큰 잡음을, 끄면 상온 수준의 잡음을 내는 교정된 장치. 이 두 상태의 차이가 **ENR**이라는 값으로 성적서에 적혀 있다.

1. DUT 입력에 잡음원을 연결한다.
2. 잡음원을 **켠 상태(Hot)** 의 출력 잡음 전력을 잰다.
3. 잡음원을 **끈 상태(Cold)** 의 출력 잡음 전력을 잰다.
4. 두 값의 비율이 **Y**다.

```
  NF(dB) = ENR(dB) - 10 x log10(Y - 1)
```

**직관** — 잡음을 안 더하는 좋은 DUT는 입력 차이가 출력에 그대로 드러나서 Y가 크다. 잡음을 많이 더하는 DUT는 자기 잡음에 묻혀 두 상태의 차이가 작아지고 Y가 작아진다. **Y가 클수록 NF가 좋다.**

### 처음 하는 사람이 틀리는 곳

>! **① 계측기 자체 교정을 건너뛴다** — 측정 전에 잡음원을 계측기에 직접 연결해서 계측기 자신의 잡음을 먼저 재둬야 한다(2단 보정). 안 하면 계측기의 잡음까지 DUT 것으로 계산된다.
>!
>! **② 입력 쪽 손실을 무시한다** — DUT 앞에 있는 케이블이나 어댑터의 손실은 **잡음지수에 1:1로 그대로 더해진다.** 0.5 dB 손실이 있으면 NF가 0.5 dB 나빠져 보인다. 입력 쪽은 최대한 짧고 손실 없이.
>!
>! **③ 주변 간섭이 들어온다** — 잡음지수 측정은 아주 약한 잡음을 재는 것이라 외부 신호에 극도로 민감하다. 측정 전에 스펙트럼으로 간섭이 없는지 확인하자.

**상세판 대응**: 3.5절, 4.10.3절

## 4.11 선택도와 차단 (Selectivity, Blocking)

**한 줄로 말하면** — 시끄러운 곳에서도 원하는 소리를 들을 수 있는가.

### 감도와 무엇이 다른가

- **감도**: 조용한 방에서 속삭임을 들을 수 있는가
- **선택도/차단**: **옆에서 누가 크게 떠들 때도** 그 속삭임을 들을 수 있는가

실제 사용 환경은 조용하지 않다. 지하철에서 수십 대의 휴대폰이 동시에 송신한다. 그래서 이 시험이 필요하다.

>> **ACS (Adjacent Channel Selectivity, 인접 채널 선택도)** — 바로 옆 채널에 강한 신호가 있을 때 견디는 능력 [49].
>>
>> **차단 (Blocking)** — 좀 더 멀리 떨어진 주파수의 강한 신호에 견디는 능력 [49].

### 어떻게 재는가

```
  VSG (wanted, 약한 신호)  --[ATT]--+
                                    +--[COMBINER]--[ATT]--> DUT
  SG  (interferer, 강한 신호)--[BPF]--+
```

신호 발생기 두 대를 결합기로 합쳐서 넣는다 [49].

1. 원하는 신호를 규정 레벨(보통 감도보다 조금 높은 값)에 고정한다.
2. 방해파를 규정 주파수 간격에 놓는다.
3. 방해파 레벨을 올리며 오류율이 기준을 넘는 지점을 찾는다.

### 처음 하는 사람이 틀리는 곳

>! **방해파 신호원의 잡음이 원인인 경우가 매우 흔하다** — 방해파 SG는 지정한 주파수뿐 아니라 넓은 대역에 미세한 잡음을 뿌린다. 그 잡음이 **원하는 신호가 있는 채널에 떨어지면**, DUT는 멀쩡한데 시험이 실패한다.
>!
>! **확인법**: 방해파 경로에 대역통과 필터를 넣고 다시 재본다. 결과가 좋아지면 SG 잡음이 범인이었다.

**상세판 대응**: 4.10.4절

## 4.12 정합 측정 (S11 / VSWR)과 VNA 실습

**한 줄로 말하면** — 신호가 반사 없이 잘 흘러 들어가는가.

이미 2.3절에서 개념을, 3.2.4절에서 장비를 봤다. 여기서는 실제로 하는 순서를 정리한다.

### 안테나 정합을 재는 순서

1. VNA를 켜고 **주파수 범위, 포인트 수, 출력 레벨**을 확정한다.
2. **1포트 교정**을 한다. 교정 표준(Short, Open, Load)을 **안테나가 연결될 바로 그 지점**에 차례로 체결한다 [33].
3. 교정을 검증한다. 50 Ω 종단을 달았을 때 반사가 아주 작게 나오는지 확인.
4. 안테나를 연결하고 `S11`을 본다.
5. 로그 크기 화면에서 반사손실을, 스미스 차트에서 임피던스를 함께 본다.

>> **스미스 차트 (Smith Chart)** — 임피던스를 원형 그래프 위에 표시하는 도구. 처음 보면 복잡하지만, 실무에서는 **"가운데(중심점)에 가까울수록 정합이 좋다"** 만 알아도 절반은 쓴다. 중심점이 50 Ω이다.

### 숫자 읽는 법

2.3절의 표를 다시 쓴다. 일반적으로 **반사손실 10 dB 이상(VSWR 2.0 이하)** 을 목표로 한다.

### 처음 하는 사람이 틀리는 곳

>! **① 교정 후 설정을 바꾼다** — 주파수 범위나 포인트 수를 바꾸면 교정이 무효다.
>! **② 케이블을 움직인다** — 교정 후 케이블 위치가 바뀌면 위상이 변해 결과가 달라진다. 고정하자.
>! **③ 조립 상태를 확인 안 한다** — 안테나는 주변에 금속이나 손이 가까이 오면 정합이 크게 변한다. **실제 사용 형태(케이스 조립, 배터리 장착)** 에서도 재봐야 한다.
>! **④ 케이블에 타고 흐르는 전류를 무시한다** — 작은 안테나를 잴 때 케이블 바깥쪽으로 전류가 흘러 케이블 자체가 안테나처럼 동작할 수 있다. 페라이트 클램프를 끼워보고 결과가 변하면 이 문제다.

**상세판 대응**: 4.2.3절

## 4.13 Load Pull (부하 당기기)

**한 줄로 말하면** — 증폭기가 **최고 성능을 내는 부하 임피던스**를 실험으로 찾아내는 작업.

### 왜 필요한가

지금까지 "모든 것을 50 Ω으로 맞춘다"고 했다. 그런데 전력 증폭기는 예외다.

전력 증폭기 안의 트랜지스터는 50 Ω을 볼 때 최고 성능을 내지 않는다. **최대 출력을 내는 부하**와 **최고 효율을 내는 부하**가 다르고, 둘 다 50 Ω이 아니다. 그래서 트랜지스터와 50 Ω 세상 사이에 **정합 회로**를 넣어 변환해준다.

문제는 **"그럼 그 최적 부하가 얼마인가?"** 다. 계산만으로는 정확히 알 수 없다. 그래서 **직접 여러 값을 넣어보며 찾는다.** 이것이 Load Pull이다 [17][50][51][52].

>> **Load Pull** — DUT가 보는 부하 임피던스를 **튜너**라는 장치로 이리저리 바꿔가며("당기며") 매번 성능을 측정해, 최적점을 지도로 만드는 측정. "로드 풀"이라고 읽는다.
>>
>> **튜너 (Tuner)** — 임피던스를 원하는 값으로 바꿔주는 장치. 안에 금속 프로브가 있고, 모터로 위치를 움직이면 임피던스가 변한다.

> **비유** — 스피커를 사서 방 어디에 놓을지 정할 때, 계산으로는 답이 안 나오니 여기저기 옮겨보며 제일 좋은 자리를 찾는다. Load Pull이 그 작업의 정밀 버전이다.

### 어떻게 재는가

```
  SG --> [SOURCE TUNER] --> [COUPLER] --> DUT --> [COUPLER] --> [LOAD TUNER] --> [LOAD]
                                                                     |
                                                      스미스 차트 격자점을 하나씩 스윕
  DC SUPPLY (V, I) ------> P_DC  =>  효율 계산
```

1. DUT를 안전한 조건에서 켜고, 발진하지 않는지 스펙트럼으로 확인한다.
2. 부하 튜너를 스미스 차트 위의 여러 점으로 순차적으로 옮긴다.
3. 각 점에서 출력 전력, 이득, DC 소비 전력을 측정한다.
4. 결과를 스미스 차트 위에 **등고선**으로 그린다.

### 결과 읽는 법

지도의 등고선처럼, "출력이 같은 점들"을 이은 선과 "효율이 같은 점들"을 이은 선이 그려진다.

**핵심**: 두 등고선의 **중심이 서로 다르다.** 최대 출력 지점과 최고 효율 지점이 일치하지 않는다. 설계자는 제품 성격에 따라 그 사이 어딘가를 고른다. (배터리 기기면 효율 쪽, 기지국이면 출력 쪽으로 치우친다.)

### 처음 하는 사람이 틀리는 곳

>! **① 발진(오실레이션)을 놓친다** — 튜너가 만드는 극단적인 임피던스는 증폭기를 불안정하게 만들어 스스로 발진하게 할 수 있다. **매 측정점마다 스펙트럼을 확인**하거나 발진 검출 로직을 넣자. 모르고 지나가면 데이터가 전부 쓰레기가 된다.
>!
>! **② 조건을 기록 안 한다** — "입력 전력 고정"과 "압축량 고정"은 완전히 다른 조건이고, 결과 지도도 전혀 다르다. **조건을 명시하지 않은 Load Pull 데이터는 비교할 수 없다.**
>!
>! **③ 열을 무시한다** — 고전력을 계속 넣으면 뜨거워져서 나중 측정점이 앞의 점과 다른 조건이 된다.

**상세판 대응**: 4.11절

## 4.14 위상잡음 (Phase Noise)

**한 줄로 말하면** — 신호의 주파수가 얼마나 **미세하게 떨리는가.**

### 무엇인가

이상적인 신호는 주파수 축에서 폭이 없는 하나의 선이어야 한다. 하지만 실제 발진기는 미세하게 흔들려서, 선 주변에 **치맛자락처럼 퍼진 잡음**이 생긴다.

> **비유** — 완벽한 메트로놈은 정확히 같은 간격으로 똑딱거린다. 실제 메트로놈은 아주 조금씩 빨라졌다 느려졌다 한다. 위상잡음은 그 흔들림의 크기다.

>> **위상잡음** — 캐리어(주 신호)에서 일정 거리(오프셋) 떨어진 곳의, 1 Hz 폭 안의 잡음 전력을 캐리어 대비로 표현한 값. 단위는 **dBc/Hz**. 예: "1 MHz 오프셋에서 −120 dBc/Hz".

### 왜 중요한가

- 성상도의 점들이 **원을 그리며 번지게** 만들어 EVM을 나쁘게 한다(4.8절 표 참조).
- 수신기에서는 강한 옆 채널 신호의 위상잡음이 내 채널로 흘러들어 감도를 떨어뜨린다.

### 어떻게 재는가

| 방법 | 설명 |
|---|---|
| **직접 스펙트럼법** | 스펙트럼 분석기로 캐리어와 오프셋 지점의 잡음을 재서 뺀다. 간단하지만 **분석기 자신의 위상잡음이 DUT보다 좋아야** 유효하다 [11] |
| **교차상관법** | 두 개의 독립된 경로로 동시에 재고 상관을 취해, 장비 자체의 잡음을 지운다. 감도가 크게 좋아진다 [12] |

### 처음 하는 사람이 틀리는 곳

>! **① 장비의 바닥을 먼저 안 잰다** — 계측기 자신의 위상잡음보다 낮은 값은 못 잰다. DUT를 연결하기 전에 계측기 바닥을 먼저 확인하자.
>! **② 전원과 진동을 무시한다** — 위상잡음 측정은 전원 잡음과 기계적 진동에 극도로 민감하다. 화면에 50/60 Hz나 그 배수의 뾰족한 봉우리가 보이면 전원 문제다.

**상세판 대응**: 4.12절

## 4.15 온도 · 전압 코너 시험

**한 줄로 말하면** — 춥거나 덥거나 배터리가 닳아도 제대로 동작하는가.

### 왜 필요한가

실험실은 항상 25 °C에 안정된 전원이다. 하지만 제품은 겨울 야외에서도, 여름 차 안에서도, 배터리가 거의 다 닳은 상태에서도 동작해야 한다.

**상온에서만 통과하는 설계는 반드시 필드에서 실패한다.**

>> **코너 (Corner)** — 동작 조건의 극단. 온도의 저온/고온, 전압의 최저/최고 등. 성능이 가장 나쁠 만한 조합을 "최악 코너(worst corner)"라 한다.

### 어떻게 하는가

전기적 특성 시험은 통상 **저온·상온·고온 3점** 이상에서 수행한다 [38].

| 축 | 예시 |
|---|---|
| 온도 | −40 / +25 / +85 °C (제품 규격에 따름) |
| 전압 | 최저 / 정격 / 최고 (예: 3.0 / 3.6 / 4.2 V) |
| 채널 | 저 / 중 / 고 |

### 처음 하는 사람이 틀리는 곳

>! **① 챔버 표시 온도 = DUT 온도라고 생각한다** — 챔버가 −40 °C를 표시해도 안의 물체가 그 온도가 되려면 시간이 더 걸린다. **안정화 시간(soak time)** 을 규정하고 지키자. 실무에서는 설정 도달 후 수십 분에서 2시간을 둔다.
>!
>! **② 챔버 통과 케이블의 손실 변화를 무시한다** — 케이블 손실은 온도에 따라 변한다. 저온에서 잰 값이 실제로는 케이블 때문에 달라진 것일 수 있다. 가능하면 **각 온도에서 경로 손실을 다시 재거나**, 온도별 보정표를 만든다.
>!
>! **③ 결로** — 저온 시험 후 상온으로 돌아올 때 물방울이 맺힌다. 질소 퍼지나 건조 공기를 쓰고, 충분히 건조된 뒤 전원을 넣는다.

**상세판 대응**: 4.16절

## 4.16 OTA (공중 방사 시험)

**한 줄로 말하면** — 케이블을 꽂지 않고, **안테나까지 포함한 실제 성능**을 재는 것.

### 왜 필요한가

지금까지의 시험은 대부분 안테나 커넥터에 케이블을 꽂고 했다. 그런데 실제 제품에는 안테나가 붙어 있고, 커넥터가 아예 없는 경우도 많다. 그리고 안테나 성능과 케이스의 영향까지 합친 것이 **사용자가 실제로 겪는 성능**이다.

>> **OTA (Over-The-Air)** — 케이블 연결 없이 공중으로 신호를 주고받으며 하는 측정.
>>
>> **TRP (Total Radiated Power, 총 방사 전력)** — 제품이 **모든 방향으로** 내보내는 전력의 총합. 송신 쪽 종합 성적.
>>
>> **TIS (Total Isotropic Sensitivity, 총 등방성 감도)** — 모든 방향에서의 수신 감도를 종합한 값. 수신 쪽 종합 성적.

### 어떻게 하는가

**무향실**에서 한다.

>> **무향실 (Anechoic Chamber)** — 모든 벽면에 전파 흡수체(뾰족한 스펀지 모양)를 붙여, 전파가 반사되지 않게 만든 방. 마치 제품이 아무것도 없는 공중에 떠 있는 것처럼 만들어 준다 [43].

제품을 여러 각도로 돌려가며 사방에서 측정하고, 그 결과를 구면 전체에 대해 합산한다. 측정 방법과 계산식은 CTIA 시험 계획서 등에 표준화되어 있다 [43][44].

### 처음 하는 사람이 틀리는 곳

>! **① 케이블을 연결한 채로 잰다** — 케이블이 안테나처럼 동작해서 방사 패턴을 왜곡시킨다. 배터리 동작 + 무선 제어 또는 광섬유 링크를 쓴다.
>! **② TIS가 얼마나 오래 걸리는지 모른다** — 각 측정 방향마다 감도를 찾아야 하므로 시간이 매우 오래 걸린다. 일정을 잡을 때 반드시 감안하자.

**상세판 대응**: 4.18절

# 5. 첫 출근부터 첫 달까지

## 5.1 첫날 — 아무것도 망가뜨리지 않기

첫날의 목표는 성과가 아니다. **장비와 나 자신을 지키는 것**이다.

### 도착해서 할 일

1. **벤치 구경하기.** 어떤 장비가 있는지, 각각 뭐 하는 물건인지 3장을 보며 확인한다.
2. **장비 이름과 모델을 적어둔다.** 나중에 매뉴얼을 찾을 때 필요하다.
3. **누구에게 물어보면 되는지 확인한다.** 장비 담당자, 시험 절차 담당자.
4. **비상 정지와 전원 위치를 확인한다.**

### 절대 하지 말 것 (외울 것)

>! **① 무엇이 나오는지 모르는 케이블을 스펙트럼 분석기에 꽂지 않는다.**
>! **② 전력이 켜진 상태에서 커넥터를 빼지 않는다.**
>! **③ 출력에 아무것도 안 달린 채로 송신을 켜지 않는다.**
>! **④ 남이 교정해둔 VNA의 설정을 건드리지 않는다.** (교정이 날아간다)
>! **⑤ 잘 모르겠으면 물어본다.** 물어보는 데 드는 5분이 장비 수리 3주보다 싸다.

### 첫날에 해보면 좋은 것

- 신호 발생기로 CW를 만들고, 케이블로 스펙트럼 분석기에 연결해서 화면에 봉우리 하나를 띄워본다.
- 주파수를 바꿔보고, 레벨을 바꿔보고, Span과 RBW를 바꿔가며 화면이 어떻게 변하는지 관찰한다.
- 마커를 찍어서 숫자를 읽어본다.

이 간단한 실습 하나로 3장의 절반이 몸에 붙는다.

## 5.2 첫 주 — 손에 익히기

| 순서 | 익힐 것 | 확인 방법 |
|---|---|---|
| 1 | 커넥터 체결 (토크 렌치 사용) | 5번 재체결하며 재도 값이 0.1 dB 안에서 유지되는가 |
| 2 | 전력계 제로잉과 측정 | 알려진 소스를 재서 기댓값과 맞는가 |
| 3 | 스펙트럼 분석기 기본 설정 | 원하는 신호를 화면 가운데 적절한 크기로 띄울 수 있는가 |
| 4 | 경로 손실 교정 | 직접 해보고, 검증까지 해봤는가 |
| 5 | 하모닉 진짜/가짜 판별 | 감쇠 +10 dB 실험을 해봤는가 |
| 6 | 측정 기록 남기기 | 남이 내 기록만 보고 재현할 수 있는가 |

> **경로 손실 교정을 스스로 할 수 있게 되는 순간**이 신입에서 벗어나는 첫 관문이다. 이것 하나로 대부분의 측정에 참여할 수 있다.

## 5.3 첫 달 — 혼자 할 수 있어야 하는 것

- 출력 전력 측정 (채널별, 기록 포함)
- 주파수 오차 측정
- 하모닉 측정 (필터 사용, 보정 포함)
- S11/VSWR 측정 (VNA 교정 포함)
- 간단한 수신 감도 측정
- 이상한 값이 나왔을 때 **계측계를 먼저 의심하는 습관**

## 5.4 측정 기록은 이렇게 남긴다

### 왜 중요한가

3개월 뒤에 "그때 그 데이터 뭐였지?"라는 질문이 반드시 온다. 그리고 그때 기록이 부실하면 처음부터 다시 해야 한다.

### 반드시 남길 것

| 항목 | 이유 |
|---|---|
| 날짜, 시각, 측정자 | 기본 |
| DUT 식별번호 | 어느 개체인지 |
| 시험 조건 (채널, 전력 설정, 온도, 전압) | 재현의 전제 |
| 사용 장비 모델과 **시리얼 번호** | 나중에 장비 문제로 밝혀질 때 소급 확인 |
| 경로 손실 교정 값과 교정 시각 | 가장 자주 문제가 되는 부분 |
| **보정 전 원시값과 보정 후 값 둘 다** | 보정을 잘못했을 때 되돌릴 수 있다 |
| 합격/불합격뿐 아니라 **실제 측정 숫자** | 합불만 남기면 추세 분석이 불가능하다 |
| 특이사항 (케이블 교체, 재측정 이유 등) | 미래의 나를 구한다 |

>! **합격/불합격만 기록하지 말자** — "통과"만 적힌 데이터로는 "요즘 값이 한계선에 점점 가까워지고 있다"는 신호를 못 읽는다. 숫자를 남기면 문제가 터지기 전에 보인다.

## 5.5 선배에게 묻기 전 스스로 하는 5분

이상한 결과가 나왔을 때, 물어보기 전에 이 다섯 가지를 확인하면 절반은 스스로 해결된다. 그리고 나머지 절반도 훨씬 좋은 질문이 된다.

| 확인 | 방법 |
|---|---|
| **1. 상식적인 숫자인가?** | 2.5절 같은 계산으로 대략 얼마가 나와야 하는지 먼저 따져본다. 10배(10 dB)나 100배(20 dB) 차이면 보정 실수일 가능성이 높다 |
| **2. DUT 없이도 그런가?** | DUT를 빼고 케이블만 연결해서 재본다. 이때도 이상하면 DUT 문제가 아니다 |
| **3. 다시 꽂아도 그런가?** | 커넥터를 다시 조이고 5번 재본다. 값이 흔들리면 접속부 문제 |
| **4. 케이블을 흔들면 변하는가?** | 변하면 케이블/커넥터 불량 |
| **5. 교정은 유효한가?** | 경로 손실 교정을 언제 했는지, VNA 교정이 살아 있는지, 전력계 제로잉을 했는지 |

**그래도 모르겠으면 이렇게 물어보자.**

> "○○ 측정에서 ×× dBm이 나와야 할 것 같은데 △△ dBm이 나옵니다.
> 경로 손실은 오늘 아침에 재서 21.5 dB로 보정했고,
> DUT를 빼고 재보니 정상이었고,
> 커넥터 5번 재체결해도 값이 안정적입니다.
> 어디를 더 봐야 할까요?"

이렇게 물으면 선배가 5분 만에 답을 준다. "이상해요"라고만 하면 선배도 처음부터 다 확인해야 한다.

# 6. 막힐 때 보는 곳

## 6.1 "숫자가 이상해요" 흐름도

순서대로 따라가자. 위에서부터 확인하는 것이 중요하다.

```
  [1] 계산상 기대값과 몇 dB 차이인가?
       |
       +-- 10 dB / 20 dB 같은 딱 떨어지는 차이 --> 보정값 누락 또는 부호 반대 의심
       +-- 2배(3 dB) 근처                    --> 전력/전압 계수 혼동 의심
       +-- 애매한 차이                        --> [2]로
       |
  [2] DUT를 빼고 재보면 정상인가?
       |
       +-- 비정상 --> 계측계 문제. 케이블/감쇠기/장비 확인
       +-- 정상   --> [3]으로
       |
  [3] 커넥터 5회 재체결 시 값이 안정적인가?
       |
       +-- 흔들림 --> 접속부 문제. 토크, 청소, 게이징
       +-- 안정   --> [4]로
       |
  [4] 입력 감쇠를 10 dB 바꾸면 값이 변하는가?
       |
       +-- 변함   --> 계측기 왜곡 또는 압축. 감쇠 조정
       +-- 안 변함 --> [5]로
       |
  [5] 교정이 유효한가? (경로손실 시각, VNA 교정, 전력계 제로잉)
       |
       +-- 무효   --> 재교정
       +-- 유효   --> 이제 DUT를 의심해도 좋다
```

## 6.2 신입이 실제로 하는 실수 20가지

체크리스트로 쓰자.

| # | 실수 | 결과 |
|---|---|---|
| 1 | 신호 발생기의 RF 출력을 안 켬 | 아무것도 안 보임 |
| 2 | 경로 손실 보정을 안 함 | 결과가 손실만큼 통째로 틀림 |
| 3 | 보정 부호를 반대로 넣음 | 손실의 2배만큼 틀림 |
| 4 | 감쇠기 값을 보정에 미반영 | 20 dB(100배) 오차 |
| 5 | 전력계 제로잉 안 함 | 저전력 측정이 부정확 |
| 6 | 전력계에 측정 주파수를 입력 안 함 | 센서 보정이 안 됨 |

### 꼭 외울 공식 다섯 개

```
  1) 이득(dB)      = 출력(dBm) - 입력(dBm)

  2) DUT 출력      = 계측기 읽은 값(dBm) + 경로 손실(dB)

  3) 잡음 바닥     = -174 + 10 x log10(대역폭 Hz)   [dBm]

  4) 이론 감도     = 잡음 바닥 + 잡음지수 + 필요 SNR  [dBm]

  5) 파장(m)       = 300 / 주파수(MHz)
```

## F. 한 장 요약 (인쇄해서 벤치에 붙이기)

### 측정 전 5초 점검

```
  [ ] 장비 예열됐나
  [ ] 10 MHz 기준 클럭을 물렸나
  [ ] 경로 손실 교정이 유효한가 (언제 쟀나)
  [ ] 전력계 제로잉했나 / 측정 주파수 입력했나
  [ ] 감쇠기를 달았나 (계측기 최대 입력 확인)
  [ ] 미사용 포트를 50 옴으로 종단했나
  [ ] 커넥터를 토크 렌치로 조였나
  [ ] 신호 발생기의 RF 출력을 켰나
  [ ] 시험 조건(채널/전력/온도/전압)을 기록할 준비가 됐나
```

### 절대 하지 말 것

```
  1. 모르는 신호를 스펙트럼 분석기에 바로 꽂기
  2. 전력 켜진 상태로 커넥터 빼기 (핫 스위칭)
  3. 출력에 부하 없이 송신 켜기
  4. 남이 교정해둔 VNA 설정 건드리기
  5. 커넥터 본체 돌려서 조이기
```

### 숫자 감각

```
  +3 dB = 2배      +10 dB = 10배      +20 dB = 100배      +30 dB = 1000배

    0 dBm = 1 mW      -30 dBm = 1 uW      -60 dBm = 1 nW      -90 dBm = 1 pW

  VSWR 2.0 = 반사손실 9.5 dB = 반사 전력 11%   <- 흔한 합격선
```

### 꼭 쓰는 공식

```
  이득(dB)   = 출력(dBm) - 입력(dBm)
  DUT 출력   = 계측기 읽은 값(dBm) + 경로 손실(dB)
  잡음 바닥  = -174 + 10 x log10(대역폭 Hz)          [dBm]
  이론 감도  = 잡음 바닥 + 잡음지수 + 필요 SNR        [dBm]
  IIP3      = 입력 전력 + (기본파 - IM3) / 2         [dBm]
  파장(m)    = 300 / 주파수(MHz)
```

### 값이 이상할 때 순서

```
  1) 계산상 기대값과 몇 dB 차이인가?  (10/20 dB면 보정 실수 의심)
  2) DUT 빼고 재도 이상한가?          (이상하면 계측계 문제)
  3) 커넥터 5회 재체결해도 흔들리나?  (흔들리면 접속부 문제)
  4) 입력 감쇠 10 dB 바꾸면 변하나?   (변하면 계측기 왜곡)
  5) 교정이 유효한가?                (아니면 재교정)
  -> 여기까지 다 통과해야 DUT를 의심한다
```

### 진짜 신호인지 판별 (하모닉·스퓨리어스)

```
  스펙트럼 분석기 입력 감쇠를 +10 dB 한다
    -> 값 그대로면        : DUT의 진짜 신호
    -> 값이 내려가면      : 분석기가 만든 가짜. 감쇠를 더 올리거나 필터 사용
```

### 물어보기 전 이렇게 정리한다

```
  "OO 측정에서 XX dBm이 나와야 할 것 같은데 YY dBm이 나옵니다.
   경로 손실은 (언제) 재서 (얼마)로 보정했고,
   DUT를 빼고 재보니 (결과)였고,
   커넥터 5번 재체결해도 (안정/불안정)합니다.
   어디를 더 봐야 할까요?"
```
